# Original239 → COL XR conservative taxonomy bridge

All239 original names were matched through the official strict/verbose API in the same current COL XR namespace as the exact-island recording panel. Raw responses, request URLs, retrieval times and hashes are archived in `official_taxonomy_raw_responses.tar.gz` with deterministic archive metadata.

`original239_to_colxr_bridge.csv` preserves submitted names, original numeric identities/status, current usage/accepted keys, match diagnostics/classification, competing concepts, and both old/new collision flags. Current keys are strings.230 names pass the conservative current-join screen;224 also have eligible original numeric occurrence keys. These are taxonomic join permissions, not proof of local host presence or unchanged biological host concepts.

`original24_pilot_taxonomy_overlap.csv` and `expanded96_taxonomy_overlap.csv` keep the pilot and expanded recording audits separate. The expanded manifest identifies105 eligible original-panel taxa among650 current species keys;14/96 islands have >=3 eligible original-panel species in each period. No original unresolved numeric records are backfilled.

`existing_host_evidence_grain_audit.json` records earlier regional, country, administrative and point-proximity evidence, source identities and the missing coordinate-level inputs needed for an actual island join. Some earlier fine-scale co-occurrence summaries exist; they do not establish feeding and cannot be assigned to these physical islands without source coordinates.

See [the results report](../../../provenance/archive/host_hindcast/ISLAND_EXPANSION_RESULTS_20261029.md) for methods, limitations and replay commands. No national host status was assigned to individual islands.
