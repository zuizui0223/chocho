# Post-source CMIP6 physical-cell validity audit (explicit design deviation)

2026-10-28. The first full-source monthly CMIP6 read was fixed for historical `12 × single-band TIFF` vs future `1 × 12-band TIFF` layout and passed seven offline tests. The next [source run #40611699378](https://github.com/zuizui0223/chocho/actions/runs/40611699378) downloaded and inspected all 18 original climate source archives, correctly extracted both Tmax/Tmin for all eight future scenarios, and found **one** monthly temperature pair out of **836** fixed source 10-minute climate pixels with **Tmin > Tmax** in the *IPSL-CM6A-LR / SSP5-8.5 / 2081–2100 / December* input. No nonfinite, below −90°C or above 75°C cases were reported, and all other 8 periods passed the physical Tmin≤Tmax source check. This is a **source-data physical inconsistency**, not a biological or statistical result, and must not be repaired by swapping/matching variables or forcing Tmax/Tmin to be equal.

The original prospective source contract rejected any physically inconsistent source pixel. To obtain a fully comparable sensitivity analysis rather than silently deleting an errant future-only pixel, the following **post-source QA modification is explicitly recorded before any future ecological output is published**:

- Validate 12×(Tmin,Tmax) monthly samples for baseline 1970–2000 plus eight original CMIP6 GCM×SSP×period combinations.
- Compute the **intersection of physically valid 10-minute climate pixels across ALL NINE panels**. Any source pixel with a monthly nonfinite value, Tmin>Tmax, Tmin<−90°C or Tmax>75°C in any panel is removed from baseline **and every future scenario**, not just the failing one. Do not impute physical values.
- Report all excluded source-pixel **counts and types** by GCM×SSP×period, and the number of original author 100km source hexes lost. No original source observation ID, hex ID or geographic coordinates may be exported.
- Because this is an unregistered source-QC sensitivity choice, **fail closed if more than 1% of original 10-minute source climate pixels** are excluded (or fewer than the original >=30 source hexes survive). This threshold is chosen to bound the visible source-defect impact, not to optimize any future effect estimate. The resulting model remains *exploratory*, never a confirmatory causal climate–host population prediction.
- No changes to original 11.5/33°C, 323 GDD, SSPs, GCMs, time periods, sampled original source records or leaf persistence scenarios.

Re-run all original source archives and compute physical masking **before** scoring any GDD or host leaf scenarios. The last action was stopped before writing any thermal outcome. This QA addendum is a transparent post-source correction and must not be backdated into the original prospective protocol.
