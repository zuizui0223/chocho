# Source-era compatibility amendment: near-future same-model anchor instead of 1970–2000 delta on recent Daymet

**2026-10-28. Post-source conceptual quality correction before reporting ecological future outcomes.** PR #95's original protocol proposed adding WorldClim 2041/2081 minus WorldClim **1970–2000** monthly anomalies to observed **2018–2025** Daymet. That procedure risks **double-counting historical warming between 1970–2000 and the observed 2018–2025 weather**, and cannot be reported as a credible 2050/2090 change relative to actual recent leaf-monitoring dates. Even if its resulting data were statistically reproducible, the epoch transfer premise would be wrong.

## Replacement, deliberately narrower hypothesis
Use the same original WorldClim v2.1 10-minute downscaled GCM/SSP/Tmin/Tmax product with **2021–2040** reference (available for both MIROC6 and IPSL-CM6A-LR × SSP1-2.6 and SSP5-8.5). Define, for **each** GCM×SSP, separately by each month:
`delta_mean_temperature(month) = 0.5 × [(tmin_future(month)−tmin_2021to2040(month)) + (tmax_future(month)−tmax_2021to2040(month))]`.

Apply this same delta to both original Daymet daily Tmin and Tmax on **the original 2018–2025 observational dates**, preserving the source daily diurnal range. Recompute the 30-day mean and frost count; original precipitation, original monitoring dates/host labels and all site weights remain fixed. Scenario periods remain **2041–2060 and 2081–2100** with two original GCMs and two SSPs, eight combinations. Original 18 WorldClim ZIPs from the previous PR #90 remain SHA-verified; the **additional 8 source ZIPs** for four 2021–2040 GCM×SSP×Tmin/Tmax baselines must have source URL, source size and SHA256 newly verified and included in the derived aggregate artifact.

## What is and is not claimed
The 2021–2040 period is a **20-year modeled near-future average**, not the actual 2018–2025 daily climate at NPN sites. Applying the delta to 2018–2025 Daymet is an explicit **near-future-anchored, diurnal-range-preserving sensitivity**; it does NOT supply an exact 2050 or 2090 daily temperature chronology. Different GCM/SSP near-future reference periods have their own climate states, so the resulting contrasts are relative climate responses conditional on each scenario, not common-standardized cumulative anthropogenic warming from one exact modern observation baseline. The change from 1970–2000 to 2021–2040 should not be treated as a fully quantified historical observed correction.

Preserve all the originally fixed source cohort identity and quality gates, model with no retraining on future climate, physical common site support, historical 1–99% feature domain ≤10% extrapolated site-equal source visits, winter ≥10 original sites and ≥100 original visits, and **no future plant response causality**. Any invalid monthly pixel or anomalous source should fail closed, not be temperature-imputed. The historical 1970–2000 archive still establishes source identity but is NOT the climate-delta comparison anchor.

**Scientific status:** this is an explicitly **posthoc revised climate transport model**, not the originally frozen prospective design. Report the new 2021–2040-anchored result only under this amended label. Do not promote any output from previous 1970–2000-anchored source Action to an ecology finding. Keep the original GEB submission and `main` unchanged.
