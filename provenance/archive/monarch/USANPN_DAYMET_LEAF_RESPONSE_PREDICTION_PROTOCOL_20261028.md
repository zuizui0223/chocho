# Pre-weather-outcome contract: can real annual temperature/precipitation predict observed milkweed Leaves?

**Date**: 2026-10-28. Independent exploratory follow-up stacked on chocho PR #92. Research question is **predicting recorded plant live-leaf status on held-out monitoring sites**, not estimating a climate-induced change in monarch abundance, a native/alien plant benefit, or a reproductive generation.

## Original observations
- Exactly the six Asclepias species and 2018–2025 original NPN `Leaves` phenophase ID 488, prior complete 27,057 unique plant×date status records. Use frozen `USANPN_MILKWEED_STATUS_2018_2025.json` receipt's per-year response SHA256 as the guard. Keep existing source coordinate conflict rule (station location stable within 0.03°).
- Field status 1 = at least one live unfolded leaf on that individually monitored plant, 0 = explicitly checked and absent; missing/unobserved or unresolved status is **not** 0. Same-plant same-day duplicate collapsed; ambiguities removed using the original parser. Original site/plant IDs, observer names and coordinates live only in transient CI memory.

## Annual weather sources and source-first stage
- NASA/ORNL Daymet Single Pixel Extraction Web Service API `https://daymet.ornl.gov/single-pixel/api/data`: tmin °C, tmax °C, prcp mm/day, years 2018–2025, nearest 1-km meteorology; [official service](https://daymet.ornl.gov/web_services), [DOI](https://doi.org/10.3334/ORNLDAAC/2361). API may require Earthdata authorization and may return protected data; a source failed/unauthorized response is an **access failure**, not evidence of missing plant/climate association.
- First run a public coordinates-only Daymet health probe before requesting any original site. Never print protected locations. Then download bounded, rate-limited site-level source weather ONLY if the service permits access. A complete dataset must verify 8 requested years, 365 daily values per year under Daymet calendar; leap day conventions are explicitly audited, not silently shifted.
- Site sampling frame fixed **before viewing weather or response outcomes** using only **observation effort**: ≥20 unique observation dates, ≥2 calendar years, ≥4 calendar months, valid Daymet North America domain (14.5–52°N and −131 to −53°W), stable site coordinates. Rank eligible sites by observation-day count descending, then (source species, station ID) only for deterministic tie-breaking. Take up to **12 sites per species** first, then fill to **72 union-unique sites**, using only effort. No ranking by presence/absence, temperature, host nativeness or future simulated success.

## Pre-specified source-time features and nested prediction
- One score row per unique original monitored plant×date status; per-site equal total weight, so multiple repeated photos from one site do not dominate.
- Response: observed explicit `Leaves` yes/no on monitoring date (not host stem absence). Baseline features: categorical plant species, annual seasonal sin/cos first and second harmonics of calendar day, station latitude/longitude, and year linear. Do not use site identity as a covariate.
- Weather adds **past 30 days inclusive** of weather only: 30-day mean daily `(tmin+tmax)/2`, 30-day precipitation total, and count of days with minimum temperature below 0°C. No future observations/leaf statuses used to calculate predictors; if weather prior window incomplete, fail that site×record without inventing 0.
- Freeze standardized input scaling (all numerical features standardized by *training folds only*), C=0.1 L2 logistic regression with a common library version, and **five deterministic held-out-site folds**, all records of the same NPN monitoring station in the same fold. Five held-out folds with each ≥5 different source sites and both positive and negative leaf statuses, and ≥30 independent climate-site units in total, are required; otherwise comparison is not identifiable. Predefined primary metric = site-equal held-out log-loss difference (baseline minus weather). Brier improvement is secondary. Require **positive held-out log-loss improvement in at least 4/5 folds AND positive overall**; report unadjusted magnitude, not a causal p-value. Check removal of precipitation and temperature feature groups as source-only ablations if and only if primary gate qualifies.
- Report absolute prediction metrics and site/species/region coverage, no relative increase in monarch generations or number of leaves. Repeated plant visits and geography remain correlated; held-out sites reduce but do not eliminate covariate shifts, correlated neighbors or nonrandom site selection.
- **Future leaf trajectory not fitted from monthly CMIP6** unless independent predictive value is demonstrated and the feature/epoch/grain transfer is explicitly checked. Daily Daymet weather does not equal 20-year monthly WorldClim climatologies. No implicit use of 30-day frost counts in future monthly data.

## Source output and privacy
Only write source status, query counts, aggregated sample sizes by species/month/region, crossvalidated site-equal logloss/Brier and source archive SHA256. No site IDs, coordinates, station labels, individual IDs, raw observation rows, raw Daymet daily weather, or per-site predictions exported. NASA/ORNL and USA-NPN attribution included.

**Failure policy**: If external Daymet access is blocked or observed sampling conditions lack support, preserve explicit blocker in a draft branch/PR and do not fabricate future plant phenology outputs. The original GEB manuscript, `main`, and source-verified CMIP6 PR #90/#92 remain untouched.
