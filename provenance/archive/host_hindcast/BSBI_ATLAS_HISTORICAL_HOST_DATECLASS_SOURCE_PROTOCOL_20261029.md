# Independent historical host-resource source: BSBI Plant Atlas 2020

**2026-10-29, source-first feasibility contract.** The scientific target is a held-out UKBMS historical **visit-specific butterfly detection** forecast from an *earlier documented larval host geography*, beyond the actual contemporaneous weather and source survey design. This is a follow-up to PR #97, separate from the original frozen GEB paper.

## Exact independent plant source (never reconstitute host geography from late observations)

[Stroh, Walker, Humphrey, Pescott & Burkmar 2024, BSBI Plant Atlas 2020 ten-kilometre occurrence maps](https://doi.org/10.5281/zenodo.10998003). Original 10×10 km hectad **taxon × historical date-class** data for 3,497 wild-plant taxa, publisher file `PA2020_10by10kmSquareData.zip`, **MD5 66a8bb4305df484839587b5fe8acf1d2** (on publisher page). Source release cites CC BY/related terms; original data rows cannot be silently declared managed and are not duplicated into Git.

BSBI's national wild-plant recorder surveys **exclude crops and garden plants** in the atlas's main wild occurrence map, and include certain planted trees/shrubs found growing outside gardens. Therefore published BSBI `introduced` or `not_native` is NEVER proof of cultivation, irrigation, human maintenance or current larval accessibility. Primary estimand is dated *wild host association*, not the hypothesized managed-host rescue. Further independently dated cultivated/crop species-by-site records would be necessary to identify maintenance.

## Fixed analysis steps and fail-closed gates

1. **Original source schema first.** Download only the publisher's fixed 10.4 MB ZIP, verify exact MD5. Audit ZIP safe member names, bounded uncompressed size (<=3 GB), source filenames, columns, date-class names and record count. No original plant×hectad records, precise UKBMS site identities or field observers in Git or artifacts. A dataset browser HTML or a compressed file with unexpected structure fails.
2. **Historical eligibility.** Distinguish data dated **1950–1969**, **1970–1986**, **1987–1999**, **2000–2019**, or whatever date classes the original file ACTUALLY declares. For the UKBMS early training **1981–1995**, a plant class ending **1986 or earlier** is a *certainly prior* host presence. The 1987–1999 class overlaps the forecast training period and is NOT admitted to the strict early-history predictor. **2000–2019 is never allowed in early predictors.** If historical classes are too broad to guarantee that cut, only use pre-1970 documented presences or fail the temporal information gate. Presence-only records have uncertain absences and cannot imply no host.
3. **Original geography.** Map BSBI hectad cells to the previously frozen 15–19 UKBMS LTMN georeferenced 1981–1995 and 2005–2021 routes; use original British National Grid 10 km square location, not a within-country uniform random assumption. Hectad/survey station points are private internal and not exported. Require >=10 independent routes with valid 10 km host source cells, >=5 distinct 10 km cells, ≥8 historical source periods if doing longitudinal inference; otherwise report insufficient spatial replication.
4. **Taxonomic mapping.** Freeze the exact original chocho 27 UK butterfly source accepted names, and host-plant list from the existing frozen GEB source/manifest. Resolve BSBI plant names to accepted larval hosts *before* looking at later butterfly detections or data-driven correlations. Report unresolved host taxa, synonyms, 10-km cell effort, and any source genus-only ambiguity. No counting a random non-host plant as a target host.
5. **Counterfactual contest only after historical overlap.** M0 = survey/DOY/geography/historical NASA POWER time-matched weather. M1 = M0 + pre-1987 documented wild larval host status/density, adjusted for botanical survey effort; nonhost plant placebo and geographic split. Compare original heldout 2005–2021 UKBMS **visit detections**, not GBIF era count or taxon-level retrospectively averaged climate. A strictly stronger prediction is required before claiming wild hosts facilitate/hinder climate tracking. Lack of host record is an *unknown* when botanical effort is insufficient, not a true absence.
6. **Sample support and novelty:** The historical records alone do NOT establish range tracking, climate mediation, host plant use or larval reproduction. No negative, positive or causal result is announced at source-only stage. Do not pool UK small-site estimates into the worldwide 239-species GEB resource numbers.
