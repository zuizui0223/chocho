# Historical wild-host versus climate-only pilot — frozen model contest before scores

**2026-10-29. Exploratory model contract after observing only historical *source quality/coverage*, not original held-out host-model scores.** Parent NASA POWER climate-only model and 25/27 original UKBMS detection changes were previously observed, so this is not an independent confirmatory pre-registration.

## Primary UKBMS response, epoch and covariates
- Exactly the 19 original UKBMS LTMN transects eligible by original April–September **1981–1995 and 2005–2021** recording effort, 27 fixed original chocho insect taxa, same verified source original visits and positive species count rows. For each focal butterfly, the original visit must record at least three OTHER confidently identified butterfly species. Focal not listed means a visit-specific nondetection **conditional on broad recorded survey**, NEVER biological absence.
- Use exact visit date ERA–NASA POWER 1981–2021 daily temperature (past 30 day mean) and precipitation (log1p 30-day sum) as the climate baseline. This earlier model **failed** its prospective weather skill test: test log loss 0.410004 (calendar/species/geo/year) versus 0.418668 (+actual historical NASA weather), only 1 of 5 independent site+era folds better. This is a fixed negative original finding, not retuned to later outcomes.
- Repeat same original L2 C=0.1 logistic with training-only StandardScaler and per-transect×butterfly-equal training weights, training years 1981–1995, heldout years 2005–2021, with the same per-site×species equal log-loss/Brier. Site tests use five source-site-independent folds (freeze site hashing seed 20261029). Site covariates may include only original latitude/longitude to represent spatial baseline. No source station ID predictor.

## M0/M1 specificity and botanical survey effort
- **M0** = species onehot, two DOY harmonic pairs, original coordinates, calendar year, 30-day historical NASA T and precipitation, **PLUS** log1p(# ALL documented BSBI wild plants **pre-1970** in the same exact 10km hectad). The botanical richness is an imperfect effort proxy, not a standardized plant survey denominator.
- **M1** = all M0 features plus exactly ONE source-specific term: log1p(# documented **accepted larval-host plant species** pre-1970 in the source exact BSBI 10km hectad, from original frozen HOSTS/WCVP 27 butterfly links). Source 0 = *no documented pre1970 accepted host positive in that hectad*, never verified biological host absence. 1987–99/2000–2019 plant records are **never** introduced to any training or forecast feature; no lookahead.
- **Loose placebo controls** = nine fixed SHA-seeded sets of exact BSBI plants **excluding the focal butterfly's ORIGINAL accepted known hosts**, approximately matching each butterfly's number of matched host candidates within the 176 source-host BSBI taxon pool. The placebo does not match plant prevalence/phylogeny and is **not a valid exchangeability null**. Scores are descriptive evidence about specificity, not p values.
- Positive evidence gate fixed: ≥10 independent original sites/≥5 BSBI 10 km cells/≥15 exact host species and ≥8 focal butterfly taxa with real between-site historical host count variation; **overall heldout M1 log-loss improvement positive, ≥4/5 independent site-fold improvements, and M1 better than every one of nine loose placebo host features**. Even if this gate passes, it only supports **out-of-time predictive value of dated wild host geography**, not temperature-mediated range tracking or a causal effect of human maintained hosts.

## Mandatory negative-control and interpretation firewall
- Do not use Plant Atlas source flags 0 as confirmed plant absence. Recovered plant recorded outside garden/crop context is not human maintenance. WCVP potential global HOSTS link is not a guaranteed local larval feeding link.
- Human cultivated/irrigated/artificial plant availability is **not** measured by BSBI; no claim of managed-host rescue. The source panel 19 historical sites across only 16 BSBI cells is small and spatially correlated. The 27 original focal butterfly species share habitat, host genera, butterfly taxonomies and survey heterogeneity.
- NASA POWER ~50km weather fields cannot resolve fine-scale microclimates and original weather augmentation failed temporal transfer. A later M1 gain could arise from habitat, geographic species composition, botanical survey effort, recording/phenology differences, residual habitat management or host reporting biases.
- Explicit species-wide source score summaries, source MD5/SHA, per-site-fold scores and all 9 placebo aggregate scores may be committed. Original UKBMS transect IDs, plant×hectad source rows, host interaction edge rows and actual site locations are only in ephemeral GitHub Action.
