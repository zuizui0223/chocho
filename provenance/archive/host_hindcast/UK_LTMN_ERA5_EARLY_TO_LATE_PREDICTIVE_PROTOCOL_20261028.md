# UK repeated transect 1976–1995 → 2005–2021 butterfly historical weather hindcast

**28 Oct 2026, exploratory study frozen AFTER source visit-event and species changes were inspected and BEFORE annual ERA5 weather at the source transects and out-of-time model performance.** This is a **baseline validation study**, NOT yet a host-mediated warming test, and **not a preregistered confirmatory test**. Original GEB and main stay frozen.

## Sources and strict cohort

- Exactly **19** original geocoded independent transects fixed by ≥10 original visits and ≥3 original years EACH in 1976–1995 and 2005–2021, and original source EAST/NORTH converted EPSG:27700→4326 only in CI memory. No new/selected sites using butterfly outcomes.
- Exactly **27** crosswalked original chocho species common names, including 2 without enough prior detection, kept in the fixed training source; report 25 information-qualified species independently, not only whichever yields climate skill.
- Exact site/day/month/year/START_TIME visit versus count join. Restrict to Apr–Sept original UKBMS standard season; for focal species require ≥**3 other identified butterfly taxa** on that visit (independent of focal positive), excluding moths, ambiguous and all-zero source rows, as original preweather source protocol. If absent, model only *nondetection conditional on that qualified original visit*; neither true local absence nor extirpation. Source targeted survey contamination remains possible, and excluded no-butterfly walks produce some selection bias.
- Real original 1976–2021 daily ERA5 reanalysis provided via Open-Meteo historical API `https://archive-api.open-meteo.com/v1/archive`, fixed `models=era5`, temperature_2m_mean °C and precipitation_sum mm. The 46-year 16,802-day calendar was verified at an independent public reference point on GitHub Action, before querying any original source transect coordinate. Daily covariates are 30-day *past* temperature mean and precipitation sum, with no observed future climate data used to define early features. Each of 19 source point requests requires 16,802 daily pairs, 95% valid original days. If source missing or model version changes, fail closed.

## Frozen test
- Training 1976–1995, test 2005–2021 (1996–2004 not used in primary). No fitting on test years.
- M0 **historical non-climate comparator**: species one-hot (original 27), two first/second annual sin/cos DOY harmonics, transect original lat/lon, linear calendar year. No source site ID in predictors. These covariates capture fixed regional and seasonal differences but year extrapolation may itself be unreliable.
- M1 **historical weather comparator** = M0 + past 30-day ERA5 mean T + log1p 30-day precipitation total. No host plant predictor. Add no future values or current climate snapshot. 30-day climate calculated on observation calendar date only.
- Logistic L2 (scikit-learn 1.5+, `C=0.1`, `lbfgs`, 1,000 iterations) for both, scalar fit only on **training** for train numeric columns; categorical species mapping fixed by source. Train weights give equal total original *transect×species* weight (rather than equal photographs/visits).
- Primary evaluation: out-of-time **mean site×species-equal** held-out 2005–2021 log-loss; M1−M0 score **improvement positive means lower M1 loss**. Brier secondary. Preserve 19 site repeated geography and 27 named species; test detection and nondetection labels both exist by crosswalk/visit protocol.
- Spatial guard (postsource but frozen before model outcomes): five deterministic site groups, train only early era on other sites, test only late era on truly held-out sites; each fold must have ≥3 sites, both detected and nondetected butterfly visits. Across 5 folds require ≥4 positive heldout site-group score improvements and positive site×species weighted aggregate to describe spatial/temporal generalization. A failure prevents claiming a climate-only validated predictive baseline.
- Check model canonical output source taxon keys, annual response effort, 30-day weather no future days, zero Source 0 not biological absence. A + logloss gain does not identify climatic causality due to habitat change, spatial autocorrelation and model misspecification.

## Why NOT include introduced-host expansion in this first model
- chocho's global `introduced_added_units` computed from contemporary resources (2010–2025) is temporally **future information** relative to 1976–1995. Inserting it into the early-era prediction would be data leakage and still not identify human maintenance at local UK transects.
- Site `HABITAT1` is current broad habitat, not historically dated host plant identity. It can be used as a sensitivity/guard variable only after documented static interpretation; never as a proxy proving cultivated hosts.
- To compare M0 vs M0+host robustly, source a **dated host species presence/use/management panel for at least the same 19 sites or local spatial grid** in the training era, alongside non-host plant and surveying effort controls. The actual user hypothesis (human-maintained hosts enable tracking of warming) is NOT tested until that independent host panel exists.

## Interpretation and data sharing
ERA5 reanalysis 0.25° grid ≠ microclimate of a 2–4km transect. Historical line of observed UKBMS visit records includes potentially bad-weather visits not flagged in this extract. Detection on a butterfly walk is not local population occupancy, colonisation, plant use or larval recruitment. Future CMIP6 is not eligible on this baseline by itself.

No source transect IDs, easting/northing, individual dates, observers or raw butterfly records released to Git/artifacts; only source SHA digests, 27-species aggregate score summaries, site-group fold metrics and audited scientific limitations.
