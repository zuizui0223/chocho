# UKBMS original dataset historical sampling-event audit — before source queries

Date 2026-10-28. This is a source-capability check, **not** an ecology result or confirmation of any butterfly range change.

- Fixed GBIF UK Butterfly Monitoring Scheme (UKBMS) occurrence dataset registration `1e266c3d-92ef-4d5a-8e4a-c04742c772c3` from the GBIF publisher page (`doi:10.15468/gmqvmk`). Do not substitute GBIF datasets after looking at historical counts.
- Source queries only: original GBIF dataset metadata; country GB, coordinate-available record facets by **YEAR** in source windows 1970–1990 and 2010–2024; historic and late ABSENT source record counts with the same filters; tiny fixed first-12 record sample per period for *field-availability audit only*. Limit source sample individual records to in-memory schema checks, never export original occurrence IDs, station IDs, exact coordinates, original dates, observer name, photographs, events, or individual row values.
- Report total indexed source records, yearly facets, source sample counts of fields `eventID`, `samplingProtocol`, `locationID`, `individualCount`, `occurrenceStatus`, `eventDate`, `basisOfRecord`, plus documented presence of explicit negative/absence records if any.
- An `eventID` or transect-like samplingProtocol in sampled occurrences does **NOT** establish known **survey visits with zero focal butterfly detections**. An occurrence-only dataset cannot supply that denominator by definition. UKBMS raw weekly transect visits/zero counts and consistent visit-site histories might require licensed UKBMS/EIDC records. The source gate for a valid dynamic occupancy hindcast is fixed site×visit history, repeat survey dates, effort and explicit non-detection or ascertainable all-species-event lists; a few sample field names are strictly a transport feasibility check.
- Never treat current WCVP introduced-wild host distribution as dated historically cultivated host abundance. No climate-only/host+climate model will be claimed until historical source host and survey support are independently resolved.
