# UK 19 repeatedly visited and geocoded transect target-species detection panel

**Date 2026-10-28. Exploratory event-denominator analysis, NOT a retrospective host-mediated climate prediction yet.** Frozen after validating original public UK LTMN visit/calendar, XLS schema and original LTMN georeference in the previous source-only stage, and before inspecting any named butterfly temporal differences. Original LTMN source OGL access/attribution https://publications.naturalengland.org.uk/publication/5692468885979136.

## Temporal source unit
- Same original SHA-verified 23,867 true survey-event visits and 156,447 positive named-taxon weekly count rows. Observed UKBMS source span 1973–2021, but restrict canonical UKBMS program to **1976–2021**, April–September weeks. 80 original common names include moths, ambiguous IDs, and five `No butterflies seen`; neither every common name nor source count row means an independent butterfly species.
- Site geography: original LTMN site-crosswalk xlsx SHA e38853b775ecadf39332a8412e2a4a2fa3c83512cf7218e4f1eda172dd83c9cd, 83 source rows/80 distinct geocoded transects. Exactly **19 original comparable transects** meet early 1976–1995 AND late 2005–2021 (original upper source year 2021) each ≥10 visits spread over ≥3 distinct years, and have usable BNG easting/northing at a stable transect ID. Source identity and these 19 sites are fixed **by visit effort alone**, prior to species outcome inspection. Every selected site is repeated across both eras.
- Exact event join key (source-verbatim): `UKBMS_SITENO, DAY, MONTH, YEAR, START_TIME`; count rows with mismatched time/date are excluded, never projected onto nearby visits.
- `VISIT_TOTAL` is positive when a focal species is detected. The LTMN count table records no explicit `VISIT_TOTAL=0` species rows. UKBMS official FAQ confirms traditional Pollard Walk records full visits even if zero butterflies are seen; all-species traditional transects should be distinguished from species-targeted protocols. Thus a focal species absent from a genuine standard all-taxa walked transect has **visit-specific non-detection**, not proven species absence/colonisation. This pilot conservatively qualifies an event for each focal species only if ≥3 **other** named, unambiguous butterfly species (not counting the focal one) have positive counts on that exact verified visit. This is an empirically conditional target-group sampling denominator, **not a certified completely all-species checklist**. It deliberately drops no-butterfly visits rather than coding zeros without validation. Check ≥5-other-species stricter sensitivity and ≥1-other-species broader comparator after primary.
- Match exactly the original chocho 239 species manifest and immutable 27 unambiguous UK common↔scientific-name crosswalk known before outcomes. UKBMS `Wall`/*Lasiommata megera* is excluded since source original 239 manifest had TAXON_UNRESOLVED accepted GBIF key. UKBMS `Wood White`/*Leptidea sinapis* carries possible cryptic-complex taxonomy, flagged rather than proof of species diagnosis. Exclude other ambiguous, moth and source `Unknown` names. Keep source-zero target species in full denominator; don't invent late source populations.

## Outcome definitions and primary information gate
- By species, within each selected original transect count qualified standard-source visits and confirmed named-species detections in 1976–1995 and 2005–2021. Primary descriptive metric: site-equal difference in detection probability *conditional on verified source survey* (late−early), where within-transect fraction is number of visits where focal species was explicitly counted divided by eligible source visits.
- Require for interpretability ≥**10 distinct repeated transects** with ≥**10 qualified visit events per era** (for the particular focal name), and ≥**20 explicitly positive butterfly visit detections in either era**. These thresholds are set before opening named outcomes. If a focal species fails, mark descriptive-only / insufficient support, not no-change or true absence.
- Do not compute climate-tracking effect yet. No site-specific annual historical T, newly available host species, planted vs native host time series, or habitat-management transitions are in this pilot. Static chocho `introduced_added_units` and `host_family_count` are fixed resource opportunities, **not historical local plant presence, cultivation nor management**. Never infer human-maintained hosts from the LTMN `HABITAT1/2` fields; those describe site habitat.
- Independent E-OBS/ERA5 actual annual weather and contemporaneously dated local hosts must be required before model M1/M2 can make host-effect claims. This source pilot may estimate changes in conditional detection, **not realized colonization, population growth, host mediated warming, or validated CMIP6 futures**.
- Original source site IDs, exact visit dates, coordinates, recorder names and per-visit butterfly records remain in process memory only; public output only per-species/epoch across-site counts and explicitly non-causal caveats. Include mandated UKBMS OGL attribution.

**Comparative ecological aim, not executed yet**: use field-calibrated butterfly host records to test whether historic host resources add heldout predictive skill beyond climate+effort+habitat. The previous 73-case climate null in PR #88 showed geographic sorting explains the apparent climate novelty; do not reverse that conclusion.
