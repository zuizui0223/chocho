## Models and scoring
For all original qualified species×walk labels, use the same source-based target-group denominator (3 nonfocal butterflies detected) and fixed original transect IDs (never a predictor), original species one-hot, two DOY harmonic pairs, original site latitude/longitude and linear calendar year. Numeric features standardized only on training.

- **M0-calendar-effort**: original source species, DOY, coords, year and `log1p(all BSBI plant taxa recorded by 1986 at same 10km hectad)`; this controls variable plant-recording completeness, not measured detailed plant effort.
- **M0-climate-effort**: M0-calendar-effort + actual past-30d NASA POWER meanT and log1p precipitation. This historical climate model failed the earlier 1981–95→2005–21 out-of-time validation and is retained as a comparator, not promoted to proven forecast.
- **M1-host**: M0-climate-effort + `log1p(count of distinct original accepted larval-host plant taxa recorded at that source hectad by 1986)`; zero means **no earlier documentary atlas evidence**, never plant absence.
- **M2-host×T**: M1 plus `host_count_log × actual 30d mean T`, a planned non-linear/interactive predictive diagnostic, not a fitted mechanism.
- **Placebo nonhost**: M0-climate-effort + a per-species equal-count set of independently sampled **nonhost** BSBI taxa, each matched to that focal original host's prior-1987 geographic prevalence over the original 16 UKBMS 10km plant hectads. Use deterministic seed 20261029 and exactly **19** fixed placebo draws. This is a descriptive placebo score distribution, not a genuine ecological null p-value.

All models: scikit-learn L2 logistic C=0.1, train-site×species equal total sample weight, compare **mean site×species-equal 2005–2021 log-loss**. Positive `score(M0)-score(M1)` means host information improves prediction. Brier score secondary. Report M1 vs BOTH M0 options: modest gain over a failed weather model **does not** qualify as independent forecasting skill if it remains worse than M0-calendar. No hypothesis changes after inspecting scores.

Spatial replication: group by **source BSBI 10km hectad** rather than transect, with five deterministic disjoint hectad groups, no one plant grid in both training and test; each held-out group contains >=2 10km hectads and both butterfly detection classes, train only original early era in remaining groups, predict only late walks in held-out plant hectads. A strong predictive source gate requires **positive M1 vs BOTH M0 comparators in >=4/5 fully held-out hectad folds**, positive overall, and M1's aggregate improvement larger than at least 18/19 matched nonhost placebo gains. If gate fails, report no robust historical host forecasting gain; never select a different best model posthoc.

## Scientific limits
Original author HOSTS host records compiled contemporaneously (2020s) may include host relationships documented after 1986; they are **not original verified 1986 larval utilization** and therefore even early plant maps do NOT prove wholly historical accepted larval host-use knowledge. Source botanical grid records are site-environment evidence, not specific visited plant stems, host quality or larval recruitment. 10km source cells are coarse, 19 UK routes mostly overlap 16 plant grid cells, NASA climate grid is even coarser; maintain this nonindependence.

Even a predictive gain is not evidence that hosts **shifted through time** or that human maintenance **caused** faster butterfly climate tracking. No dated planted/managed host resource is present. If host effects pass, the next, separate test is species-specific historical host taxa adoption/management data and true source-domain temporal tracking; otherwise do not run CMIP6 future forecast.
