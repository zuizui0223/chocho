# One global H3 grid to bridge chocho and dated ecological observations

**2026-10-29 — geography-only source-first implementation.** No butterfly occurrence, WCVP introduced status, future outcome, management class, year of introduction or MODIS habitat result has been inspected or inferred as a new ecological effect. This is a *fixed spatial key and geometry audit*.

## Main decisions

- **H3 resolution 4** as a primary 1,770.35 km² average-area hex (~26.10 km average edge); H3 res5 may be added later as a resolution robustness check, not blended into the main grain.
- **Global unique spatial key**: textual `h3_r4`; time axis **calendar `year`**, separate from static geography. A species×hex×year panel should be built by cross-joining an exposure frame only after verified source butterfly sampling opportunities; failure to record a species in GBIF is not absence.
- **Exactly the original 369 WGSRPD Level 3 polygons** used by chocho WCVP/HOSTS from original author-only source artifact: GitHub Actions run #39006554609 (SHA256 `408cb206d7ce4056cee1fbf614762e1a6efb3db4650ff7c2663a7d6d6003e323`), safely extracted `inputs/level3.geojson`; validate its SHA256 against the earlier independently audited `data/exploratory/gbif_country_20261020/country_wgsrpd_summary.json`. Do not silently substitute a newer botanical spatial edition. The publicly documented original geometry source is [TDWG WGSRPD repo](https://github.com/tdwg/wgsrpd) and official standard [TDWG](https://www.tdwg.org/standards/wgsrpd/); do not redistribute the source-author archive or its raw shapes.
- **Enumerate all 288,122 r4 cells globally**, intersect actual equal-area cell geometry with original botanical region polygon, retain cells with nonzero verified land overlap, *including coastal islands whose grid centre falls offshore*. Original H3 centre `cell_to_latlng` is a separate, optional centre region indicator. Dateline aliases are explicitly handled; no source geometry or exact GBIF record locations leave the Action.
- **Both spatial lookup versions retained**: `center_wgsrpd3` (empty if centre offshore/ambiguous), `dominant_area_wgsrpd3`, fractional area of each intersecting WGSRPD3 source region and mapped-source land fraction of entire H3 hex. Preserve crossing boundaries, source overlap-excess, unmatched/ambiguous; do not normalize source membership to 100% of a mixed land-ocean hex.
- Area fractions use existing chocho choice **EPSG:6933** and force-over longitude handling; Antarctic/polar geometry must be explicitly audited, not assumed accurate. Any source source-polygon gap or physical coverage inconsistency is a failure of the geometry bridge, not evidence that a host plant is absent.
- Public-derived outputs are only compressed `h3_r4 ↔ WGSRPD3` cell table, compressed `h3_r4×region` area intersections and source manifest SHA256. No raw author-only geometries are re-published. Every downstream region-level WCVP/HOSTS value is a broad **botanical resource prior**, not locally verified plant occurrence.

## Scientific hard separations for next panels

1. **Static resource status** (`source_wgsrpd3_native`, `source_wgsrpd3_introduced`) comes only from the original WCVP×HOSTS species×WGSRPD3 footprint and has **no establishment or planting date**. If a cell spans different statuses, do not majority-vote away the minority; preserve source area fractions and mark ambiguous mixed-status cells separately. Use an unknown/source-missing category rather than a false biological zero.
2. **Plant environmental preference** is empirical only after GBIF source observation coordinates are matched to era-correct MODIS cover with a survey-effort-matched plant/nonhost background. Raw percent of a plant's photographs in cropland is **not a habitat-use probability**, since crop cells are frequently visited and sampled; negative controls and era-specific source are essential. Habitat quality, local plant abundance, cultivation, host leaf use and butterflies produced remain unmeasured.
3. **Remote sensing** land cover and NDVI can provide annual land condition on the same H3 grid. Explicit temporal limits: MCD12Q1 begins around 2001; MOD13 begins around 2000. They cannot backfill **1976–1995** host land-cover changes without independent historical land-cover archives. No retroactive early-period values inferred from 2010–2025 covariates.
4. **Dated butterfly counts** are from the LTMN 19-route repeated survey-visit source when available, not GBIF presence-only. For global GBIF, indexed record counts by grid×year are **target-group reporting effort proxies**, not measured absence or colonization.
5. **Time-split prediction**: pre-era observations, climate and independently established host exposure only in early training; test later real butterfly verified visit/detection and heldout geography. Exclude climate-opportunity tautology and require future-era survey effort controls. Simulate CMIP6 only if a historical host model beats climate-only and independent matched nonhost/land-cover baselines.

### Explicit disjoint area-membership bridge after original source overlap audit

The first SUCCESS global source run processed 288,122 global H3 cells and 89,161 cells with actual botanical land, 98,529 source region overlap rows, 369/369 WGSRPD3 regions, and 146.47 million km² of source mapped land. **3,864 cells have a positive source-region overlap** (1,358 exceed one percentage point of an H3 area, 9 exceed 20 percentage points) because original botanical regional polygons overlap near borders. Simply adding regional fractions would inflate local available land. Therefore a third derived table now partitions each cell into *disjoint membership atoms*: `h3_r4 × wgsrpd3_members` (`AAA`, `BBB`, `AAA|BBB`, etc.) with `cell_fraction` and `mapped_land_fraction`. Every point of a cell is counted once, even if multiple original source polygons cover it. Species-specific native or introduced resource opportunity can later sum the areas of qualifying atoms **once**, while separately retaining cross-region ambiguous statuses. Do not interpret this correction as evidence of actual local host occupation. Every atom area must reconstruct the exact source union of land in its H3.
