# Isolation × islands × ports: source-first geography and identification gates

2026-10-29. New exploratory spatial continuation from source-geography-only PR #100, **separate** from verified-recording-forecast PR #101 and the frozen GEB manuscript/main.

## Scientific question, not yet a conclusion
Does the ecological importance of independently observed larval host resources for butterfly historical range-tracking differ between (a) connected mainland, (b) isolated islands without major ports and (c) islands near established maritime ports, AFTER sampling effort, coastline exposure, island area, climatic conditions and botanical data coverage are compared? This requires explicit **historical, independently verifiable host availability** and butterfly visits to infer an interaction. Current crosswalk provides only spatial support.

## Exact source layers to lock before ecological outcomes
1. [Natural Earth 10m **land**](https://www.naturalearthdata.com/downloads/10m-physical-vectors/), source archive `https://naturalearth.s3.amazonaws.com/10m_physical/ne_10m_land.zip`, site-wide source SHA256, version and topology to be recorded on retrieval. A 10m generalized land polygon is a cartographic approximation, not a high-resolution island census. Large land polygons may be pre-split; **do not** declare each source feature to be a separate physical island until a dissolve/connected-component identity check passes against known landforms. Island classes cannot be made from land polygon shape counts alone.
2. [UN OCHA World Port Index 2025-11](https://gis.unocha.org/server/rest/services/Hosted/global_world_seaport_index_202511/FeatureServer/0) (NGA WPI source). Verify service metadata, source feature count, spatial reference and complete paginated point source (only site/source metadata exported; ports are public). The ports are **location of reference harbors, not actual trade flows, vessel trajectories, ship calls, founding pathways, or port-open dates**.
3. Previously completed original chocho PR #100 **all 288,122 H3 resolution 4 cells**, original **369 WGSRPD3 geographic regions**, 89,161 land-intersecting cells, **102,660 mutually disjoint region-membership atoms**, exact source SHA-verified original plant geography. The current public independent audited area-atom table is a geographic crosswalk, not validated local host presence.

## Spatial exposures and validity, to be estimated only after source passes
- island area and coast: use dissolved true connected landmasses; mainland designation requires fixed continent seed points and sanity checks including Greenland, Madagascar, Borneo, Galápagos, Hawaii, Izu and Okinawa; **Australia and Greenland must not be classified by arbitrary >1e6 km² size alone**.
- source-isolation: nearest true continental mainland coast geodesic distance. Ocean, reef, antimeridian, sea channel, poor topology and source ambiguity flagged. Source sea gap is NOT effective travel cost for a flying butterfly, especially at a 26km-edge H3 r4 scale.
- port: nearest reported WPI port geodesic distance and port count within 50km/100km, optionally per true island and H3 cell. **A port is only a fixed location**; not species-specific arrivals, human maintenance or known trade exposure. Compare with generic coastal proximity and urban/crop observation effort controls, and make a coastal pseudoport/placebo test if later fitting butterfly outcomes.
- Never use H3 center-only for nearshore/embedded small islands: 7,922 source botanical H3 cells have a center outside mapped botanical land despite positive area. Use land-contact footprint or flag unrepresentative centroid. All H3 r4 region overlaps must be processed through **disjoint atoms**, not summed raw intersections where 3,864 H3 cells overlap original region polygons.
- Island/port exposure must have data coverage and resolution audited **before** any interaction regression, and large regional WCVP host status must not be treated as the H3 cell actually containing an accepted larval host.

## Two separate response cohorts
A. PR #101: **155 species, 4,617 source forecast cells** with original **10km** spatial analysis and normalized GBIF recording probability. No original row-level analysis data / fitted model in public repo snapshot; scripts refer to locally retained parquet and access-controlled host source. An H3 r4 region table CANNOT simply be joined as if it were a 10km cell. Requires original 10km geometry or exact area-share bridge to H3, then rerun original out-of-time and spatial holdout models. The verified ~4.1% and 3.0% MSE gains are for static host information, not host×ports/isolation.
B. PR #84–86: **18 exact butterfly species/35 POSITIVE alien establishment recipient-area cells**. Establishment negatives and original intercepted species-linked pre-foundation shipments do not exist in adequate numbers; source-positive-only cells must never be coded as invasion successes against the other 221 chocho species as failures. South African port/lab data: 175 Lepidoptera-positive samples among 15,848 TESTED inspections but only two exact original-239 butterfly names, both previously regionally recorded; no species×arrival×subsequent-establishment endpoint.

## Pre-registered scientific falsification gates for future modeling
- 10km to H3/landmass geometry overlap with verified source and ≥90% original source area represented (no center-only island disappearance), 2-source port geolocation QC when independent WPI available.
- At least **20 independent island species×recording-place panels** with both baseline and later detection effort, verified actual contemporary plant host and independent nonhost background, plus a mainland reference. Otherwise use source-descriptive island support only.
- Historical host management and port trading dates must precede response era; present 2025 port map and contemporary WCVP introduced ranges are not historical timed exposures.
- Compare distance-to-coastline, nearest recorded port distance, island size, sea gap and habitat/observation effort under a prespecified held-out geography, **not** mere correlation of coastal butterflies and port locations. Require a post-outcome independent new site/period validation and a nonhost-placebo.
- Do not merge a source-only geospatial audit into GEB main or claim island/port mechanisms prior to independent real butterfly validation.
