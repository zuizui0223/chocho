# Manuscript figure source artifacts

## Current v0.2 figure surface

The submission-facing figures are generated by `scripts/render_butterfly_specialization_v02_figures.py`: three main figures plus Supplementary Figure S1. The renderer consumes git-tracked frozen figure-source tables and current result receipts. The exact release commit is the archival identity for this source surface.

Current figure-source tables include:

- `data/frozen/figure_sources/anthropogenic_species_metrics.csv`
- `data/frozen/figure_sources/occurrence_resource_validation_species.csv`
- `data/frozen/figure_sources/climate_distance_sensitivity_species.csv`

Current figure-relevant receipts include the host-contribution concentration, matched/host-bias diagnostics, occurrence null/robustness, ceiling/regional sensitivity and climate-effect JSON files under `provenance/reviewer_defenses/results/`.
