# chocho — 肯定的実測と未支持仮説の統合台帳（2026-10-31）

**統合規則**：実測・計算・予測で支持された主張を保存する。探索的関連はそのまま探索的な証拠として記録し、未支持・不明は肯定的な因果結論に昇格させない。独立したGEB原稿は変更しない。

## 1. 凍結済み独立GEB主張（`main` に既存）
- **潜在的資源地理**：239蝶種中206種で、既知寄主を固定したまま外来寄主の地域分布を加えると資源機会が増える。蝶×地域の追加は **+54.9%**、作物を除いても **+46.0〜47.0%**。拡大の半分を **38寄主植物種**が担う。[既存README](../../README.md)。
- **境界**：種の分布拡大・個体数・寄主の現地利用・送粉や群集の変化を直接観測した結果ではない。食性幅との関連が弱いことは正確なゼロの証明ではない。

## 2. 新たに統合する予測での肯定的結果（PR #101）
- **既知種の予測改善**：候補225種中155種・時間外評価208,482組で、気候・土地被覆に寄主資源情報を加えると MSE約**4.1%改善**。未学習空間ブロックで**3.00%**、学習地点100km以上の事後的部分集合で**2.74%**改善。記録日数・候補半径・最大提供者除外・位置精度の4感度条件で同方向。
- **境界**：標準化した索引記録確率であり、真の占有ではない。未学習種への転移は未支持。区間は固定予測・種×空間ブロック再抽出で、再学習の不確実性を含まない。[155種検証報告](results/host_forecast_validation_20261029/forecast_validation_results_ja.md)。

## 3. 島・港の実測として統合できる結果（PR #104；因果解釈なし）
- **原座標の島時系列**：2011–2022年の島上初索引記録**12,028件・205種・2,656島**。前後の他蝶観測機会を条件付けた500km以上ギャップ**164件**のうち**104件**は最も近い過去索引記録地も島。供給源・分散距離とは呼ばない。[原座標検証](results/original_island_continuity_20261030/global_original_island_continuity_results_ja.md)。
- **植物とチョウの島間組成**：51島・1,275非独立ペアで、現代の港外来寄主候補類似度と新規蝶記録の類似度の Spearman ρ=**0.300**、距離・従前蝶相を除く記述的偏順位相関**0.215**。植物の観測年代は蝶記録より後を含む。[島間組成](results/island_host_network_20261030/island_host_network_results_ja.md)。
- **時系列の確定**：51島・1,163共有新規蝶種ペアから、2001–2010年の適合寄主が両島で記録されたのは**5件**。非公開原年表で5件の両島初年を復元、短距離の時間的連鎖は**3蝶リンク＝2島ペア**。先の島の再記録から次島の初記録までの順序は確認したが、生物学的な中継は未実証。[年表実測](results/maritime_host_steppingstone_20261030/original_year_chain_empirical_results_ja.md)。
- **港周辺の景観**：WorldCover 2021の同島・非港沿岸対照と比べ、港近傍1kmの市街地分類点が**+21.9ポイント**（島単位95%再標本化区間+18.2〜+25.8）。外来寄主の同定ではない。[景観比較](results/coastal_port_vegetation_20261030/coastal_control_vegetation_results_ja.md)。

## 3b. 2001–2010年の植物種キー×港×年を実測して統合（PR #105・#106）

- **再取得・元ソース照合**：2019年のWorld Port Index原ID・国を **23港／9島ですべて一致確認**し、GBIFから2001–2010年の **230港年セル・9,788植物種キー×港×年ファセット行**を取得。種キー同一性・ソースZIPのSHA-256・元集計件数との不一致をすべて保存した（旧集計との完全一致とは主張しない）。[全港実測](results/historical_host_controls_20261031/daily_botanical_all23ports_20261031.json)。
- **記録数を最大にする1港と、植物種の観測被覆を混同できない**：島81の記録最多港1518は171種キー付き記録のうち **4植物種キー**しかなく、同島の全9港（種キー検出8港）のユニオンは **142種キー**。最多植物種の港1523は **52種キー**。島276でも単港584種キーと全4港962種キーでは大きく違う。これは生物学的植物相ではなく、GBIF索引被覆の監査。[分類群被覆比較](results/historical_host_controls_20261031/port_rank_taxonomic_coverage_results_ja.md)。
- **島ペアで前期植物種キーの共通性は実際に検出可能**：優先5島ペアの早期共有植物種キーは81–214で **47**、821–951で **58**、276–321で **85**、169–715で **571**、715–1577で **241**。この共有数は **幼虫寄主の同一性・当時の外来性・実際の輸送経路**を表さない。[全23港ユニオン](results/historical_host_controls_20261031/all23_botanical_taxon_union_results_ja.md)。
- **既知寄主2種の厳密な時間的先行を確認**：*Medicago sativa* の受理植物種キー9151957（島169では2002年、島276では2001年に初索引）と *Alnus incana* の受理植物種キー9148577（島276では2001年、715では2002年）をGBIFで完全一致・信頼度100にて照合した。既存の *Colias croceus*、*C. hyale*、*Nymphalis antiopa* の**3リンク・2島ペア**では、対応寄主の最初の索引年が蝶の最初の索引年より **14〜19年早い**。これは既知の種×島記録の先行性であり、現地摂食・導入・生存・島間中継の証拠ではない。[元年表×種キー照合](results/dated_focal_host_taxonomy_20261031/focal_historical_host_results_ja.md)。
- **証拠階層は据え置く**：元データの再照会による「植物種が該当港の検索域に早期に索引されていた」という支持を統合し、寄主資源による定着の因果効果や寄主不在対照には昇格しない。外来性の当時の島別分類、港外の植物記録、未選択の種×島×年の寄主適合性は未完成。

## 4. 未支持・未検証を正確に保持
- 先行適合寄主の5/1,163という一致率は、科構成を保つ帰無期待を明確に上回らない。港外来寄主割合×港距離の調整後区間も0を含む。未記録植物は不在としない。
- 先行島の複数年蝶記録を付加した未学習年予測では、log-lossの改善が時間窓で安定しない（2018–2022年のベースライン**0.31467**、先島の長期再記録**0.32508**、直近5年再記録**0.31220**）。[時間外検証](results/maritime_host_steppingstone_20261030/near_island_host_opportunity_holdout_results_ja.md)。
- **海上輸送による本研究の寄主植物移入→島での繁殖資源増加→チョウの定着→次の島への供給**は未実証。現代の港近傍記録、単なる初記録順、他の蝶の記録量からは判断しない。

## 5. 統合後の主線
**最優先**：植物の *種×元座標×記録年×当時の島別外来性×港／非港* を蝶種×島×年に接続し、同じ観測機会で「先行適合寄主が検出された群」と「未検出／分類不能群」を区別する。後者を寄主不在に置き換えない。自然飛翔・大陸直行・貨物に随伴する蝶の移動は競合する仮説として明示する。GEB本論文と探索支線の主張を混同しない。
