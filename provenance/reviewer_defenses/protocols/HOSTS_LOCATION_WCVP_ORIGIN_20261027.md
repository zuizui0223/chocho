## Source-blind geography label rules
- Reuse source-frozen 257-label classification: exact country/territory strings only, and independently declared subnational-to-TDWG codes such as Hawaii→HAW or West Malaysia→MLY, **only if those exact codes exist in the pinned TDWG geography AND intersect the named parent ISO country's disjoint atoms**. If invalid, remain unscorable. Do not map East Malaysia, Sabah, Sarawak, Java or Ryukyu without independently verified one-to-one geometric lookup.
- All broad Nearctic, Oriental, Palaearctic, East Africa, New World, Old World, Europe, British Isles, etc are a separate geographic missing/ambiguous class. All interceptions, provisonal "(prov)" or historic/political unsafe string labels are not field-host-use evidence.
- Country-to-TDWG disjoint atom status: an atom is NATIVE only when all of its botanical region members are native-accepted WCVP for the plant, INTRODUCED only when all are extant non-doubtful introduced and none native, UNLISTED only when all lack WCVP extant non-doubtful plant records; otherwise AMBIGUOUS. Country uncovered area is UNKNOWN, not UNLISTED.
- Primary source classification, preselected: whole-country land-area shares ≥95% NATIVE / INTRODUCED / UNLISTED, with pinned crosswalk mapped area coverage ≥95%. Remaining countries are MIXED_OR_PARTIAL or UNSCORABLE_COUNTRY_GEO. Independently repeat with ≥80% plant-status dominance while keeping source geography completeness requirement at 95%. No guessing an origin from crop names. WCVP UNLISTED is not by itself proof of cultivation, absence or host naturalization.
- Exact validated subregional TDWG code is status NATIVE / INTRODUCED / UNLISTED under the same original WCVP source, rather than using the whole parent country's plant status.

## Ecological observation and counting units
- First count every raw HOSTS insect-species × plant-species × Location **row**, preserve its raw multiplicity (literature/duplication). Main unit then collapse to unique accepted butterfly-species × WCVP-accepted plant-ID × original Location triples. Multiple citations for the same triple count once.
- Distinguish primary focal 239 species and all raw HOSTS lepidopteran taxa (the latter are NOT automatically confirmed as butterfly species). Only claims for the 239 are primary. Source unmatched taxonomic pair, ambiguous WCVP exact accepted taxon, unknown source Location and country WCVP-mixed are separate denominators.
- For each introduced-location triple, mark the exact same species×host accepted pair as ALSO_DOCUMENTED_IN_A_NATIVE_PLANT_AREA or NO_NATIVE_AREA_HOST_USE_REPORT_IN_PINNED_HOSTS. No native-area report ≠ novel larval host adoption. Also report distinct species/plant pairs, and genus/plant-family/source-label influence without releasing raw copyrighted interaction matrices.
- Missing 239 butterfly native-range chronology, invasive consumer-native versus introduced ranges, controlled host quality or larval reproduction means this result cannot quantify true ecological niche evolution, host-switching events, fitness, butterfly expansion, or 'following a transported host'.

## Quality/decision
Fail the analysis if source identity/area-atom source integrity or original 239 panel verification drifts. Report source classification completeness, all 257 Location labels as denominator, WCVP-unlisted and country-mixed cases explicitly, 95 vs 80 geographic sensitivity, and native-area-report absence as DOCUMENTATION INCOMPLETENESS. No raw original WCVP/HOSTS rows, exact insect×plant×location triples, source locations or geographic polygons distributed in artifacts; export only original-source aggregate statistics and SHA fingerprints.

A robust mechanistic test requires independent dated consumer invasion/native boundaries and a native-use detection model adjusted for HOSTS historical regional recording effort; do not infer a percentage of true host-adoption events from introduced-area-only source reports.
