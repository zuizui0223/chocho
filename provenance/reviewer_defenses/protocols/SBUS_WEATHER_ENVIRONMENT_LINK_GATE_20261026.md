# Stage E0 — Independently measured weather versus host-sharing butterfly count synchrony

**2026-10-26. Predeclared before downloading any gridded weather values or fitting weather-adjusted synchronization effects.** Distinct from the frozen GEB submission `main` and PRs #38/#70. Prior work already inspected 3 correlated spatial/temporal adult-data endpoints. All new source tests are **posthoc exploratory potential falsification**, not an attempt to manufacture confirmatory significance.

## Starting biological question
Can the observed within-Illinois-site annual adult butterfly-count-rate cofluctuation among species sharing documented larval host plants be accounted for by common exogenous yearly/weather variation, rather than a uniquely host-mediated demographic interaction?

The original adult count data by Henry et al. 2025 (doi:10.1038/s41597-025-05513-8, Figshare `10.6084/m9.figshare.27934602.v1`, CC BY 4.0, exact source ZIP MD5 3161b1c8802a0d67771b2044e18da928) are independent of original `chocho` HOSTS literature. Illinois eligible original sites/year panel 121 × 851, original 39 retained adult species and **640 originally qualified temporal species pairs**, 62 recorded-host-sharing pairs, 578 nonsharing. Following a 600-minute maximum site-survey duration in the original Henry usage notes, the temporal mean host-sharing-minus-nonsharing correlation is **+0.14332588463806942**. In 2 independent family×plant-family degree-preserving host-network draws (199 each), this near-boundary original uncorrected value was approximately +0.1432 vs expected medians +0.0886/+0.0889 (nominal exploratory right tails .03). This is **not multiplicity-confirmed** across the original three metrics, nor causal evidence of competition.

## Source E0: identify actual weather observation linkage
- Survey site location data come only from the *original* Henry Figshare `complete-share.csv`, `site,lat,lon,lat-lon precision`, never a geolocation inferred from the user's own location. Do not export site coordinates, site codes, observation records or exact pair identities to GitHub. A source audit of site coordinate quality must be carried out BEFORE choosing spatial weather resolution.
- Independent first-choice daily gridded weather: NASA/ORNL DAAC Daymet single-pixel service (`https://daymet.ornl.gov/single-pixel/api/data`; documentation https://daymet.ornl.gov/web_services and dataset doi:10.3334/ORNLDAAC/2129), 1 km daily gridded `tmax,tmin,prcp,srad`. The first transport test uses Illinois *public non-survey* coordinate `lat=40,lon=-89`, years 2015 and an upper response cap 200 kB. HTTP 200 CSV with valid `year,yday` numeric daily rows is mandatory. Any Earthdata login/auth gate returns `WEATHER_SOURCE_ACCESS_UNAVAILABLE` and must NOT be circumvented.
- Predeclared independent lower-resolution backup: Open-Meteo Historical Weather (ERA5-Land; https://open-meteo.com/en/docs/historical-weather-api) noncommercial/research access conditional on its current terms; no substitution without explicit separate data-source record, then 11-km climatic inference only. No live default API weather should be treated as station observation.
- If fewer than **80% of originally qualified 121 sites** have a single consistent high-precision latitude/longitude mapping, or source documentation indicates centroids instead of survey points, do not implement local weather adjustment. Return `SITE_WEATHER_JOIN_NOT_IDENTIFIABLE` and stop. For privacy only summary proportion/missingness and approved source citations are persisted.

## Source E1: the fixed biological test ONLY if E0 source gate succeeds
- Extract daily Daymet values for the **same 121 source sites** and all original eligible site×years (2000–2020), no extra species or locations. Query seasonal **March–June** (butterfly spring development), **July–September** (adult summer activity), or whole-year annual summaries; designate spring and summer as distinct prespecified seasonal covariates, **not measured host plant phenology**.
- Temperature exposure = mean daily `(tmax+tmin)/2`; precipitation = cumulative daily `prcp`; solar radiation = sum of `srad×dayl` if `dayl` available (otherwise source-standard mean `srad` and report change). Require ≥90% valid daily observations per site-year per season; otherwise that site-year is weather-missing and its species pairs are not considered weather-corrected. Do NOT carry forward from another date.
- Weather values must be anomalized within each exact site across its included years; the same site-year weather values are common to all butterflies at that site, and direct shared response can induce synchronous adult fluctuations even if no competition. Keep location-year and the source visit-intensity model distinct.
- Keep the original fixed **640 species pairs** and original site/year adult records. The weather-corrected scalar for each pair is Pearson correlation between each partner's residualized within-site yearly log(1+adult count per hour) after removing pooled within-site spring and summer weather anomalies. Estimate two species-specific slopes within that pair across sites; exclude only weather-absent site×years, recording if any pair loses original support below n=30 or five co-recorded sites; if the originally fixed pair roster cannot all be maintained, label `NOT_IDENTICAL_ECOLOGICAL_SAMPLE` rather than silently selecting a favorable cohort.
- Recompute **shared-minus-nonsharing mean pair correlation** using the same literature-host graph, compare to the same 199 fixed-degree host-graph randomizations used for the 2026-10-26 adult cofluctuation study. Null graph assignment does not move field counts or weather anomalies. Two new independently seeded random host networks may be requested only if original source absent; always record whether null and ecological graph cohort identical.
- Independently compare an even simpler common-year-only adjustment removing a global calendar-year indicator from each species' site-demeaned adult rates. This has no new weather requirement, and its adjusted cofluctuation is a sensitivity, not a direct meteorological effect or confirmation.
- Main decision **falsification**: attenuation after environmental adjustment indicates that original synchrony could reflect a shared abiotic forcing; persistence does not identify host-mediated mechanism because weather is only one environmental dimension and host biomass, host plant phenology, life stage, adult detectability and phylogeny remain unmeasured.
