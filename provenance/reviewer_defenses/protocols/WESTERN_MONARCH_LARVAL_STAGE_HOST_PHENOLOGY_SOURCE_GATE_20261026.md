# Fixed source-first Western monarch host phenology → observed juvenile stage structure (26 October 2026)

**Scope:** an independent source-first exploratory butterfly-resource analysis, isolated from existing frozen GEB manuscript and Illinois adult monitoring. This is **NOT** a re-claim of published west-coast monarch migration/breeding GAM results.

## Why this independent dataset
Diethelm, Schultz, McKnight et al. (2026), **Spatiotemporal patterns of breeding challenge the successive broods model in a migratory butterfly**, Dryad dataset published **2026-10-08**, DOI `10.5061/dryad.4j0zpc8q5`. Public dataset version includes `MS_western_monarchs_Oikos_2024.csv` (≈2.39MB) with *actual* eggs and L1–L5 larvae on seven accepted *Asclepias* taxa, contemporaneous counts of vegetative/flowering/fruiting/senescent stems, transect ID, year (2017–2019,2023–2024), region, survey round and survey type. This source is independent of HOSTS/WCVP potential-region reconstruction. Original authors already reported spatiotemporal phenology and per-stem larval abundance; **we do not claim those as novel**.

## New biological question fixed BEFORE looking at original file rows
**Does host-plant phenological state change the geographic relationship between the number of oviposition opportunities (eggs recorded) and representation of later juvenile developmental stages (L3–L5 counts), conditional on available stems and sampling time?** This operationalizes `host present` versus `stage-resolved realized use`, but counts at one survey are **not tracked individual egg-to-adult survival**, and the phenomenon need not be caused by host quality.

Primary prespecified source variable definitions:
- Accepted seven milkweed code pairs: ASCO *Asclepias cordifolia*, ASCR *A. cryptoceras*, ASER *A. eriocarpa*, ASER2 *A. erosa*, ASFA *A. fascicularis*, ASIN *A. incarnata*, ASSP *A. speciosa*.
- Records are originally transect slices/plots, **NOT 1 independent butterfly**. Sum source rows first to `Transect_ID×Region×Year×Survey_Round×Survey_Type×milkweed plant code` if surveyed quadrat/transect area is disjoint; check duplicate/same-slice keys, and avoid equating different source sampling methods. Compare survey methods in separate panels.
- Stage counts: `Eggs` (current eggs), `L1+L2` (small caterpillars), `L3+L4+L5` (older caterpillars). These are snapshot counts, **not measured transitions or survival**. Empty eggs, dead individuals, duplicate pupae columns are not added. Cross-check source Sum_Eggs/Sum_Lk for integrity only; do not double count.
- Available host stems per species = `ASXX_Total_Available_Stems`; senescent share = `ASXX_Senescent / (ASXX_Vegetative+ASXX_Flowering+ASXX_Fruiting+ASXX_Senescent)` if sum positive and category totals consistent with reported plant stem total. Alternatively, green share=(vegetative+flowering+fruiting)/all. **Zero available stems are not zero exposure** and never entered as independent negative plant use; contradictory rows are source/QC errors, not biological "resource traps".
- Same survey round can be broad March–November (~25 days) and regions differ climatically; DOY and original year×region must be held explicit, not interpreted as an experimentally randomized plant state.
- Important plant-stage interaction: whether **a positive number of L3–L5 larvae** occurs on plant taxon i at a survey, conditional on host *available stems* count. Separately present egg presence under same strata, not as comparison implying individual fate. A botanical senescent-stage interaction in a regression would only be a stage-structured field occupancy association.

## Source gate: required before fitting ANY biology
1. Use anonymous documented Dryad v2 API and **exact** current version `10.5061/dryad.4j0zpc8q5` downloaded as ZIP. Cap ZIP at 12MB, verify CRC, record exact archive SHA256, key filename and per-file SHA256 and size; archive may redirect; record source URLs and HTTP code. Do not use user login. If API returns a web HTML instead of the data, record `SOURCE_NOT_VERIFIED`.
2. Independently inspect native CSV exact header, row counts, sampling method, unique region/year/site/transect ID counts, date/doy parsing, seven plant codes and availability/count fields; record per-column missingness and fraction zero. Do NOT upload row-level survey site names, coordinates, dates, transect IDs, or individual original observations to GitHub.
3. The following thresholds must all be met before claiming a meaningful stage-resource comparison: ≥15 unique transects, ≥3 of 5 years, ≥2 *Asclepias* species each found on ≥15 transect-round sampling units, ≥30 transect-round units with positive **L3–L5**, ≥30 with eggs, ≥100 valid plant taxon×sampling units with available stems, and source sampling methods and exposure definitions must be unambiguous.
4. Check source `Sum_Eggs,Sum_L1..L5` vs 7 accepted plant-specific counts for every row. If mismatches >1% of nonmissing valid comparison rows, mark **NONIDENTIFIABLE** until documented. Check plant category total vs available stems and surveyed-stem semantics; if more than 1% contradictory ratios, do not fit stage models as if those were biological states. Missing source fields are not assumed zero.
5. If original large-scale study already directly tests older larval representation conditional on milkweed senescence, mark **REANALYSIS_OF_PRIOR_FINDING**, not an independent novelty.

## Planned analysis after source gate (separate prerecord BEFORE fitting)
One primary plant-stage contrast on transect-round summed data, restricted to one comparably standardized transect method and *positive available milkweed stems*. Use binomial any-L3–L5 positive (resource production proxy) versus green/senescent stem fraction, offset/log stem availability as exposure/control, and fixed year×region and host taxon, time-of-year DOY. Cluster error at original transect, not plant×slice pseudo-replication. Describe egg detection as a secondary stage-proxy; NEVER report it as transition survival or egg loss without tracking individuals. A within-transect multi-host matched analysis is eligible only if ≥30 transect-round units include ≥2 concurrently available milkweed species and ≥20 older larvae events overall. A matched same-survey contrast, if eligible, must preserve the original same-transect sample in null.

## Explicit interpretive boundaries
This dataset predominantly records native western *Asclepias* species. It **cannot estimate an effect of newly introduced alien milkweed establishment**, or global butterfly expansion, because original host arrival timing and alien plant status are not experimentally varied. Observing larvae on a host **proves current stage-specific occupancy**, but not that eggs surveyed earlier survived into those individuals. Both stages and plant age respond to weather, predators, migration, sampling windows and season. Causal recruitment requires tracked egg-to-adult fate or experiment.

A separately published Sept 2026 Dryad IMMP California BLM dataset `10.5061/dryad.mkkwh718x` may offer **independent sites and years (2021–2022)** for later validation; it cannot be declared a replication without same-variable source-schema/permission gate. Keep one primary work goal and save all first-stage source diagnostics, including failure, on this analysis branch.
