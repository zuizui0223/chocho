# 239-butterfly GBIF occurrence versus added larval host resources
**Exploratory source-frozen design, 19 October 2026.** No individual-paper review. Question: **Do real butterfly occurrence samples preferentially coincide with newly available host-plant resource regions after geographic, climatic, and other-focal-butterfly observer-effort constraints?** All final estimands are associations in sampled occurrences, not colonisation, host acceptance or insect recruitment.

## Input universe (fixed before seeing new GBIF outcomes)
- Source-verified author-only WCVP/HOSTS with 1,027 BCE additional accepted host links across 81 butterflies, frozen 239 butterfly species, 365 WGSRPD3 regions with CHELSA bio1+bio12 and original plant-native and introduced maps; maintain exact totals 29,852 native / 44,819 contemporary / 14,967 introduced added *geographic* species×region cells. Author-only geometry derived from pinned TDWG Level3 GeoJSON. Do not upload raw WCVP/TDWG arrays.
- GBIF Occurrence REST API, public searches only, no authenticated bulk-download claims. Taxonomy match MUST be strict, species rank, canonical exact (or single unambiguous accepted fallback if implemented), with GBIF accepted taxon key. Exclude unresolved/ambiguous species; no invented records.
- Two time windows: **2010–2017**, **2018–2025** (avoid incomplete 2026). Max **two systematic 300-record pages per butterfly per window**, 1,200 sourced occurrence rows/species; at most **239×1,200** sampled records, not the complete global GBIF archive. Explicitly report all search total counts, incomplete windows, offset-cap truncation and whether the 239-species panel was fully resolved. The GBIF search API's documented 300/page and first-100,000 ordinal limit require a cap; if a temporal search has >100,000 records, record saturation and use only the retrievable first 100,000, no implicit claim of a random representative sample.
- Filters: `hasCoordinate=true`, `hasGeospatialIssue=false`, `occurrenceStatus=PRESENT`, original event year window, `taxonKey` exact-match GBIF species record with `speciesKey` consistency, and zero/invalid coordinates excluded. Exclude `FOSSIL_SPECIMEN`, `LIVING_SPECIMEN`, `MACHINE_OBSERVATION` records if non-faunistic? Primary keep faunistic HUMAN_OBSERVATION, PRESERVED_SPECIMEN, OCCURRENCE, OBSERVATION and MACHINE_OBSERVATION; report basis counts and perform HUMAN_OBSERVATION+PRESERVED_SPECIMEN sensitivity on the exact retrieved sample. Do not infer reproduction from location.
- Map points via fixed source TDWG Level3 polygons with Shapely STRtree; report points outside polygons, ambiguous overlapping polygons, duplicate GBIF ids, and butterflies with insufficient observations. No inferred region for unmapped coordinates. Output only species×region×window non-sensitive derived counts and original GBIF IDs? Do not upload raw coordinates. Save reproducible query metadata, exact request URL parameters, counts, retrieval timestamp, GBIF recommended citation acknowledgment without falsely inventing a GBIF download DOI. No hidden retry gap: species-level incomplete windows must be marked and removed from confirmatory contrast, not treated as no butterflies.

## Primary ecological comparison (paired species×region)
For butterfly i and region j:
- `N_ij` = recorded native-host resource supports the region, `A_ij` = added introduced-host support and no native host (direct accepted host union), `U_ij` = region outside both native and contemporary host support. Candidate comparisons use **only `N_ij=0`**, with known climate and native-host analogue (BIO1/BIO12 both inside native-host 5–95% bounds; sensitivity 10–90%), and with independent focal panel sampling-effort proxy `E_{-i,j}`: **number of *other* focal butterfly species with >=1 mapped GBIF occurrence** in the same region and time window. Its calculation excludes the target species (avoid circularity).
- Primary effort gate `E_{-i,j}>=3`; sensitivity thresholds 1 and 5, and if fewer than 50 informative species×Level1 strata report NOT IDENTIFIABLE. Do not reinterpret sampled absence as true absence.
- Geographic matching: condition on butterfly species × WGSRPD **Level1 recipient region**, holding observed target-butterfly positive region counts in each stratum, total effort-supported candidate regions, and number of introduced-host added resource regions fixed. Under a uniform conditional allocation of the added-host label among candidate cells in each stratum, `E[overlap]=K×A/N` (hypergeometric). Compare observed sampled positive region×species overlap with summed expectation. This benchmark preserves broad continent and per-species sample intensity; it does **not** preserve original host-plant identities, fine climatic variation, regional area or dataset-specific observer effort.
- Extra climate matching: split candidate within Level1 by continent-local CHELSA BIO1/BIO12 2×2 bins (the 4 climate bins are defined from all 365 source regions BEFORE comparison). Include only strata with both exposed and comparison regions; report positive/negative regional examples without selection by sign. This is a sensitivity against the primary climate-analogue-only matched benchmark.
- Count bootstrap CI from genus-resampled butterfly clusters, 2,999 replicates, and structural null Monte Carlo from stratified hypergeometric draws, 9,999 draws with deterministic seeds. Emphasize both are *sample- and null-model-dependent*, not causal observational inference.
- Report outcomes for all 239, resolved taxa, detected species, eligible species, regions with zero sampling effort, 2 time windows separately and pooled (pooled combined, not chronological colonization), specimen/observation type sensitivity and missingness. All raw data derived for each group needed for audit (n samples N, K, A, overlap, source resolution). If too many unreliably resolved or absent resources, do not claim validated global occupancy relationship.

## Negative gates
No true absence, no occupancy probability estimated from GBIF alone, no butterfly larval recruitment/host quality, no chronological introduced plant date, no equal-area region weighting, no independent regional observer survey effort, no causal species relocation claim. The time windows give a robustness comparison of *samples*, not temporal butterfly expansion because current plant sources are not time-dated and GBIF indexing changed over time. At least one strong false-positive is possible for cultivated/greenhouse plant georeferences. Unresolved taxon and incomplete GBIF pagination lower generality. Do not reuse the 32-species initial exploratory positive validation as an independent holdout after inspecting it.
