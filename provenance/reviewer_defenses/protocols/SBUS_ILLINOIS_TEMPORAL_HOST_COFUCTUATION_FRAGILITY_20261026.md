# Post-result fragility gate for borderline temporal butterfly host-sharing co-fluctuation
**26 October 2026.** Fixed **AFTER** examining first 199 host-network null results, but **BEFORE** performing the alternative-seed, jackknife or weight-based calculations below. They are exploratory tests of a potentially fragile secondary signal, not confirmatory registration or a new endpoint hunt.

## First frozen result and why a new check is needed
The original Illinois source-locked co-detection test held **121 sites, 851 site×years and 39 butterflies**, giving **741 fixed species pairs (65 exact-host-sharing)**. Contemporaneous detection φ shared minus nonshared was +0.025756, INSIDE the 199-network null interval +0.016601 to +0.045741 (no excess; exploratory right tail 0.78). The secondary Jaccard was +0.015950, also inside null. The **SECONDARY** within-site annual log(count/hour) fluctuation correlation was positive across 640 originally pair-qualified butterfly pairs (62 sharing, 578 nonsharing): observed shared-minus-nonshared +0.1432306, just above the first 199-network null 97.5% quantile +0.1430430, exploratory right-tail ~0.03. This result was found after inspecting three related metrics and is not independently corrected for multiple comparisons. Simple Bonferroni correction of .05/3 = .0167 would not accept p=.03 as confirmatory even with independent field randomization (which these network nulls are NOT).

## Three fixed fragility checks, no parameter retuning
1. **Second independent source network seed**: reuse the identical original 640 fixed species pairs and each pair's observed within-site normalized count correlation. 199 newly restarted family × plant-family accepted-host bipartite degree-preserving graph swaps, seed `20261027+7919×replicate` (compared with original `20261026+7919×replicate`). Exact original 239 butterfly and accepted-plant graph, 5×E swap proposals, accepted≥100, viable edge turnover≥10%, at least 190 qualifying replicates, both comparison groups≥20 in every qualifying graph. Do not collapse/combine seeds before checking between-seed median/range stability. Record observed vs second null and both empirical right tail proportions with the **fixed same pair roster**.
2. **Site-cluster leave-one-out**: recompute all 640 temporal pair correlations excluding one of 121 monitored Illinois sites at a time, using each pair's site-demeaned log(1+adult count/hour) cross-product, x² and y² sufficient statistics. Retain the **same originally 640 eligible pairs** and fixed shared/nonshared group labels. If a site deletion makes any originally qualifying pair's denominator mathematically undefined, mark that site as not evaluable rather than omitting its pair. Report min/median/max of observable same-pair contrasts and the fraction retaining the original positive sign. This tests source dependence on one particular monitored site, not spatial representativeness.
3. **Pair contribution/rare-pair influence**: recompute original shared-minus-nonshared mean correlation weighted by the number of jointly eligible (both-ever-seen-site) site×year comparisons per fixed pair; also recompute the unweighted contrast after omitting each of 39 eligible butterfly species in turn (keeping other same original pairs). Report direction/ranges and the pair-weighted same-second-seed null interval. A sign reversal or null-range overlap prevents upgrading the result. Weighting by number of overlap site-years changes estimand and is explicitly *posthoc*.
4. No test on additional taxa, alternative seasons, climate bins, count normalizations, degree-preservation rules or p-value thresholds. No site-specific data or pair identities leave the workflow; only grouped statistics and null draw values are archived.

## Biological decision
Only if the first and second independent sources robustly exceed the fixed source network null, the leave-site-out distribution is stable, and inference is not driven by rare pairs may the secondary signal be described as **provisional within-site synchronous adult detection/effort-normalized rate association among literature host-sharing butterflies**. It still cannot establish larval competition, local host occupancy, causal resource filtering or host-introduction-mediated abundance increases because habitat, weather, detectability, phylogeny and host biomass were not independently controlled. Under a borderline or nonqualifying outcome, label `NOT_ESTABLISHED`, close the analysis rather than searching an extra trait threshold. GEB PR #38/70 remain unchanged.
