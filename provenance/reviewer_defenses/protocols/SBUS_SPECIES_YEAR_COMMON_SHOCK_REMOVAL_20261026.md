# Stage E1a — Calendar-year common-response falsification, after E0 (2026-10-26)

**Protocol status:** specified after observing first 199+199 Illinois host-sharing adult temporal cofluctuation nulls, and AFTER E0 revealed **121 monitoring sites but only 14 publicly resolved rounded geographic positions**. This is a posthoc sensitivity, not a confirmatory test.

## Why calendar-year rather than a 1-km weather model
Daymet API for public demonstration coordinate (40N,89W) returned 365 authentic daily 2015 records for tmax/tmin/prcp/srad, but original Henry Illinois survey sites are rounded to only **14 distinct public coordinate pairs across 121 sites**, all annotated `Nearest 1`. These coordinates should never be treated as independently surveyed site-specific 1km weather points. E0 direct site-weather effect is **NOT IDENTIFIABLE**. No point-to-site Daymet matching in E1a.

The alternative independent source-light test is therefore **a shared annual shock correction** using the original observational *butterfly monitoring time series themselves*. This is a conservative negative control for common year effects but **does not actually isolate meteorological variables, host plant phenology or density interactions**.

## Locked estimand and correction
1. Preserve the original Henry Figshare source archive DOI `10.6084/m9.figshare.27934602.v1`, exact MD5 `3161b1c8802a0d67771b2044e18da928`, original 239 butterfly names/accepted HOSTS accepted plant links and eligibility rules. Primary source: Illinois 121 original monitored sites, 851 site×years, 39 positive-prevalence eligible butterflies, **640 originally eligible temporal species pairs (62 recorded-host-sharing)**, mean shared−nonsharing adult annual rate correlation **+0.14323064389607087**.
2. For each accepted butterfly species in the fixed originally eligible 39-species co-detection panel and for each Illinois site where the butterfly was ever seen positive, calculate each eligible year log(1 + reported adult count/recorded survey hour), using the same original site-year implied-zero convention; center within that butterfly's own site over available years. No changing observed counts, survey duration or thresholds.
3. For each butterfly species × calendar year, form the average **across other eligible monitoring sites** of these site-demeaned anomalies. Remove the mean from the focal site's own anomaly only when at least **5 contributing sites total**, so ≥4 are out of sample. For fewer than 5 source sites in a species-year, remove zero and record non-adjusted cell count. This is a leave-one-site-out species-specific regional year effect; it may remove shared true biological responses as well as weather.
4. Center the corrected butterfly anomalies once more within species×site. For exactly the same fixed 640 unordered butterfly pairs and same shared site-year source rows and pair eligibility already checked, calculate the pooled within-site annual Pearson correlation using zero-imputed species values **only at sites where that focal butterfly was ever seen**. Any zero variance or missing pair triggers a source failure, not pair-dropping. Report proportion of annual site×species values adjusted and the original/corrected mean correlation shared and nonsharing.
5. Null on the **same fixed pair roster**: 199 independently restarted butterfly×host plant swaps restricted to butterfly family × plant family (seed `20261026+7919×rep`; 5×E swap proposals). Every recorded host bipartite degree, butterfly host family and adult source row stays fixed. Require ≥190/199 runs with ≥100 accepted swaps, ≥10% viable originally changed host edges, and both shared/nonsharing groups ≥20. Report the old/corrected observed-minus-network-null median, central 95% null interval and descriptive right-tail only.
6. **Do not promote an ecological signal** based on nominal tail fractions: three endpoints have already been examined in the parent source analysis; temporal endpoint was secondary and a source-network randomization is not an experiment. The key outcome is whether the `+0.143` pattern disappears or attenuates after species-specific common calendar-year forcing is reduced. If it persists, site-level seasonal weather and botanical biomass remain unmeasured; correlation can be due to geographical clusters, phylogeny, monitoring and species-specific temporal response.
