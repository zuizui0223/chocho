# Source-method-only QA — implausible butterfly transect durations (2026-10-26)

The original Henry et al. (2025) *Scientific Data* dataset note explicitly says original national trend authors **excluded survey efforts ≤0 or >10 h continuous observation**. Source: https://www.nature.com/articles/s41597-025-05513-8 (Usage Notes). The original Illinois exploratory pilot retained all finite positive durations, without an upper cap, which could potentially bias `count / survey_hour`.

**Before any new ecological effect model**, independently count the number of unique Illinois survey events with duration >600 minutes (or invalid duration), whether event effort values are inconsistent across source species rows, and how many originally eligible site×years they might influence. Only aggregate the source event counts, years and programme names; no raw site ID or count values in repo. Do not choose thresholds or subset based on the sign of original host-sharing association; 600 minutes is an **external published source-protocol requirement**. If no >600 min events, the current effort-rate model is unaffected by this specific data-quality risk. If present, document source applicability and implement a like-for-like fixed-model sensitivity, transparently labelled source QA not independent confirmation.
