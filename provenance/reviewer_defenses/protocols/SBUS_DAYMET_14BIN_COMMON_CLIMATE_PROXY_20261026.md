# E1b: Regional weather as a coarse common forcing, NOT site-level climate or plant phenology

**Fixed on 2026-10-26 after the E0 spatial source audit but before obtaining any climate values at survey-location classes or estimating an environment-adjusted butterfly synchrony.** A second distinct exploratory falsification test; the prior 640-pair adult temporal association had already been examined. A null/source effect should NOT be rescued by tuning windows/coordinates.

## Original data and why the spatial scale changed
The exact 121 Illinois butterfly monitoring sites contributing 851 standardized site×years and 640 original qualifying temporal butterfly-pair correlations have **only 14 rounded public coordinate classes**, with the source label `Nearest 1` for all 80,286 relevant survey data rows. E0 therefore formally **rejected any one-to-one precise 1 km site/Daymet climate assignment**. No per-site microclimate coefficient will be estimated.

A scientifically more modest question remains: *could regionally shared meteorological seasons account for observed butterfly adult-count-rate cofluctuation?* One regional weather series may legitimately be shared by multiple monitoring sites within a rounded source position, but the weather pixel represents **one proxy location, not a regional mean**. Statistical uncertainty must recognize only 14 independent weather series, and biological microhabitat/host resource quality remain unidentified.

## Frozen weather acquisition
- Independent weather dataset: NASA Daymet V4 1km historical daily meteorology, DOI `10.3334/ORNLDAAC/2129`, public single pixel service `https://daymet.ornl.gov/single-pixel/api/data`, access verified on public unspecific Illinois coordinate 40N,89W for 2015. This is interpolated weather, not local station thermometer or plant observation.
- Exactly **14** original rounded source coordinate classes, reconstructed from the source Figshare v1 zipped `4_res/complete-share.csv` already MD5-pinned `3161b1c8802a0d67771b2044e18da928`. Each site must remain assigned one stable rounded location. Other years’ survey rows cannot change it. No coordinates, per-site names or individual weather responses are exported to GitHub.
- One Daymet request per coordinate class, with variables `tmax,tmin,prcp`, `years=2000,2001,...,2020` and no other locations/periods. Response cap 3MB/query, 60-second timeout, one request (no response-selected retry), verify correct `year,yday` columns and at least 360 days per calendar year. If Daymet refuses multi-year requests, return source limitation, **do not switch model/API to obtain desired coefficient**. Overall coverage all original 851 site×years requires 90% valid daily seasonal coverage per bin-year.
- Climate covariates chosen before inspection: **spring GDD5** = sum max(0,((tmax+tmin)/2)−5°C) for day-of-year 60–181, and **summer precipitation** = sum prcp mm for day-of-year 182–273. These are seasonally targeted abiotic phenology/resource-production **proxies**; NOT observed host-leaf flush, butterfly larval food quality, or direct host-plant phenophases. Temperature and precipitation reflect broad weather shocks only. Source calendars have leap-day handling; DOY windows rather than dates are frozen to avoid year-to-year calendar parsing changes.

## Fixed 640-pair adult synchrony conditional contrast
1. Reconstruct the same original (uncorrected) within-site mean-demeaned annual log(1+adult-count/source survey hour) arrays; assert all 640 original pair correlations matched archived source values to <1e−9. Do not replace the existing 600-minute cap result with base values: weather-adjusted test will use the independently source-published **600-minute survey maximum** (five invalid-duration-outlier events removed), while retaining original 121 sites, 851 site×years, 39 prevalence-eligible butterflies and fixed 640 pair identities. Assert original corrected source contrast `0.14332588463806942` exactly (allow float ±1e−9).
2. For each original pair, retain only sites where both were ever positively detected and all site-years previously admitted. For each contributing site, center **spring GDD5** and **summer precipitation** within that site over its eligible years, using its publicly rounded coordinate class; center both adult rates within site. Within the original pair’s pooled sites×years, regress **each** adult series separately on the same two site-centered climate proxy anomalies (no intercept) and compute Pearson correlation of the two regression residual vectors. This estimates a partial cofluctuation conditional on coarse meteorological common forcing. If rank of climate matrix <2 for any originally eligible pair, or ≥1 original pair cannot retain >30 finite site×years / 5 sites, return NOT_IDENTIFIABLE rather than selecting a surviving positive subset.
3. Main posthoc contrast: `mean(weather-adjusted correlation of 62 originally host-sharing pairs) − mean(weather-adjusted correlation of 578 originally non-sharing pairs)`. Do not recode host classifications, change per-pair weights, species selection or species sites.
4. Recompute exactly 199 original butterfly-family × plant-family bipartite accepted-HOSTS degree-preserving null graphs, seed `20261026+7919×replicate`, same fixed 640 pair identities and weather-adjusted correlation scalars, 5×E proposed swaps. Require ≥190 valid draws, ≥100 accepted swap steps, ≥10% changed viable edges, and at least 20 pairs per host-sharing class. Report null 2.5%/median/97.5%, descriptive right-tail, and observed weather-explained attenuation relative to **the source-600min corrected unadjusted correlation**. Note source-location pseudo-replication across 14 rounded classes; source graph null is not a field experimental intervention.
5. Do not use any within-site climatic cell label as replicated independent environmental weather. WCVP nonnative host ranges have no introduction year and **cannot attribute butterfly population increases to host arrival**, even if year anomalies remain.
6. If Daymet data access fails, location mapping/coverage too coarse for more than a regional proxy, or pair variance vanishes, stop after source-only provenance; do not create an effect estimate or paper claim. If observed temporal effect attenuates, share-specific year weather is plausible. If persists, avoid attributing to host quality: correlated photoperiod, plant productivity, phenology, enemies and spatial auto-correlation remain.

## Decision
The biological claim is limited to `AN_ADULT_RATE_CORRELATION_CONDITIONED_ON_ROUNDED_REGIONAL_WEATHER_PROXIES`. A positive nominal network-null departure is not an independently significant result given exploratory choice after three endpoints, shared climate bin positions, no direct plant data and adult imperfect detectability. Retain under source-exploration; GEB manuscript remains unchanged.
