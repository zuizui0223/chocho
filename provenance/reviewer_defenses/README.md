# Reviewer-defense analyses

This directory contains post-hoc analyses added in response to manuscript review. They are kept outside the active protocol and primary-result surfaces so the repository distinguishes the original ecological analyses from later robustness work.

- `protocols/` — specifications for matched-host and host-bias null models.
- `results/` — structural, ceiling, geographic, occurrence, taxonomic/phylogenetic, climate-distance and precision sensitivity receipts.

The submission manuscript labels these analyses as post-hoc robustness analyses. They remain part of the reproducibility package but are not presented as prospectively defined primary analyses.
