# Post-hoc robustness analyses

This directory contains post-hoc analyses conducted after the primary ecological analyses. They are kept outside the active protocol and primary-result surfaces so the repository distinguishes prospectively defined analyses from later robustness and diagnostic work.

- `protocols/` — specifications for matched-host and host-bias null models.
- `results/` — structural, ceiling, geographic, occurrence, taxonomic/phylogenetic, climate-distance and precision sensitivity receipts.

The submission manuscript labels these analyses as post-hoc where relevant. They remain part of the reproducibility package but are not presented as prospectively defined primary analyses.
