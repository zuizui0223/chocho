# 港と外来食草の出現：途中集計

対象1,469港中、取得完了した17港の2001–2024年の植物記録を集計した。日本8港・英国8港・カナダ1港に限られ、全球の傾向とはまだ判断しない。

重複除去後43,695記録、食草16,855記録・352種。外来候補は1,654記録。

|最寄り港からの距離|外来候補記録|由来判定済み食草記録|割合|由来不明の食草記録|
|---|---:|---:|---:|---:|
|0-1km|154|887|17.4%|742|
|1-3km|647|5,336|12.1%|1,331|
|3-5km|853|7,629|11.2%|930|

この取得済み範囲では港に近い距離帯ほど外来候補の記録割合が高い。港ごとの観測量・地域構成を補正していない記録単位の割合であり、港の効果や持ち込み経路を示す結果ではない。港から5 km圏外との比較はしていない。

外来候補は地域カタログの現分布と在来域の差で判定した。由来不明は在来扱いせず分母から除外し、上表に残した。距離の精度には座標誤差の影響も残る。
