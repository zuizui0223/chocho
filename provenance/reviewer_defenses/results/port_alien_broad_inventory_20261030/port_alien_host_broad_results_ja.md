# 港周辺の外来食草候補：広域の途中集計

登録3,630港のうち、完全な植物種別リストが得られた1,596港（142の国／地域コード）を集計した。座標付き全記録の取得が完了した17港の距離別解析とは取得方式と対象が異なる。こちらは各港の5 km検索範囲における種の記録リストで、2001–2024年をまとめている。

1,150港で計687種の外来食草候補が記録され、港×食草の組は25,742組だった。1,596港全体で食草記録があるのは1,329港、食草は1,513種。外来候補が未記録の港を外来食草の不在と扱わない。

外来候補は地域カタログの現分布から在来域を除いた区分であり、独立した導入確認ではない。同じ植物種でも在来地域の記録はこの表に含めない。港の検索範囲が複数地域にまたがり判定が一致しない場合は不明として残した。

これは港周辺でどの食草が広く記録されるかの結果である。港以外より多いこと、港から持ち込まれたこと、島の中継機能を証明しない。港間の検索範囲の重なりは残るため、港数を独立した導入回数と扱わない。対照地点・観測量の補正は追加していない。

全91,111港×食草の組について、取得元の種別件数・受理種キー・応答ハッシュとの一致を検証した。国／地域別の港数と外来候補の種別港数も再集計して照合した。
