# 全球の港湾と、下水・人由来窒素・農地窒素：空間解像度を変えた識別検証

2026-11-05 · [chocho Draft PR #122](https://github.com/zuizui0223/chocho/pull/122) · **探索的マクロ解析、GEB原稿は未変更**

## 結論（解析単位を混同しない）

**既存の肯定結果を保持する。** 2015年のモデル下水発生量（WWp）とGBIFに索引された港周辺の外来／在来候補寄主比は、WWTP数・都市／農地・国・地理・植物記録量の調整後も正の関連を示した（n=1,055港／42か国、β=+0.05870、国クラスタ95%区間［+0.01310,+0.10429］）。これは下水の窒素による寄主増殖を意味しない。

今回**実際のkg N/年に近い独立データを二段階**で追加した。

1. **NIES GNINPO-DSM 2025（国×年：2005–2022）**。2015年の国別未管理生活排水窒素割合が高いほど同国内の港周辺WWpと外来／在来候補寄主記録比の正の関連が強まるという予測を検証した。都市等を調整した993港・38か国の2015年交互作用はβ=**−0.0324**、95%区間［−0.0681,+0.0033］、未管理窒素の増幅仮説は**支持されない**。都市を入れない1,280港・47か国でもβ=−0.0132［−0.0562,+0.0299］。2005–2010年と2011–2022年の国別窒素分率でも同方向。国固定効果が国別窒素分率の主効果を吸収するので、これは国内WWpの関連の国間修飾に限定される。
2. **CIRAD/Wassenaar 2026、2022年の全球3km等積地図**。人由来の窒素排泄**ポテンシャル**と農地への窒素供給**ポテンシャル**（どちらも単位は10 kg N ha⁻¹ year⁻¹）を同じWPI1,596港の10/25km円内から、NoDataを0にせず抽出した。農地側だけがGBIFの外来／在来候補寄主比に再現的な**正の空間関連**を示す。これは**農業栄養供給・土地利用の共地理性**の証拠であって、下水Nが港の陸上植物へ到達した証拠ではない。

## 2. CIRADモデルの主結果：25km・同じ1,041港／42か国

| 同時投入した変数 | β（log変換後） | 国クラスタ95%区間 |
|---|---:|---:|
| **農地N供給ポテンシャル** | **+0.03993** | **+0.01335〜+0.06651** |
| 人由来N排泄ポテンシャル | +0.02901 | −0.05163〜+0.10966 |
| 下水発生量 WWp | +0.01663 | −0.06512〜+0.09838 |
| WWTP数 | +0.03865 | −0.08159〜+0.15889 |

ソース原本・MD5とGDAL画素を照合した[再現実行 #41923811745](https://github.com/zuizui0223/chocho/actions/runs/41923811745)。25km＋都市化なしは1,336港・52か国で農地N β=+0.04580［+0.02212,+0.06948］。10km＋都市化ありは1,020港・40か国でβ=+0.05065［+0.02370,+0.07759］。**同じ1,011港だけ**で25kmと10kmを比較しても農地Nはそれぞれ+0.03506［+0.00900,+0.06112］と+0.05049［+0.02353,+0.07746］、人由来Nは両半径で不明瞭。

**交絡の根拠**：25km＋都市1,041港において、モデル人由来NとWWpの順位相関ρ=+0.748、WorldCover市街地ρ=+0.429。農地NとWorldCover農地の順位相関ρ=+0.341、WWpとρ=+0.370。したがって双方のN指標が都市／農地の別側面を反映する可能性を考えるべきである。

## 3. 感度分析・負の対照（源泉固定、独立に再計算）

[国・植生記録・格子品質・半径の独立監査](https://github.com/zuizui0223/chocho/actions/runs/41924855106)。最初の検証ワークフローは**解析本体を完走しJSONを出したが、最後のCI検証式が存在しないフィールドを要求して失敗**。後続の修正ワークフローで再検証する。解析数値は再計算出力で確認済み。

| 農地Nとの関係 | n港 | β | 95%区間 |
|---|---:|---:|---:|
| 主解析 | 1,041 | +0.03993 | +0.01335〜+0.06651 |
| 外来・在来双方を1種以上索引した港 | 732 | +0.03065 | +0.00627〜+0.05504 |
| 外来＋在来候補が計5種以上 | 716 | +0.03843 | +0.01036〜+0.06650 |
| N格子の有効画素率が両方50%以上 | 732 | +0.02511 | **−0.01281〜+0.06303** |
| 農地N上位1%の極端な港を除外 | 1,030 | +0.04233 | +0.01608〜+0.06857 |
| 「索引総数」共変量を除く、同じ1,041港 | 1,041 | +0.04044 | +0.01209〜+0.06880 |

国を1つずつ除いた42再解析で、農地Nの係数は**全て正**（範囲+0.03197〜+0.04421）。しかし有効N画素率≥50%の高品質サブセットでは区間がゼロを含むので**質依存性**が残る。

別々の植物群を応答とすると、同じ1,041港で農地Nは外来候補`log(1+richness)` β=−0.0071［−0.0650,+0.0508］、在来候補β=−0.0468［−0.1085,+0.0149］、**それぞれ有意な正ではない**。一方、人由来Nは外来+0.1208［+0.0372,+0.2044］、在来+0.0999［+0.0347,+0.1650］で**双方正**。したがって「農地Nにより外来寄主が増加した」と言い換えてはいけない。観測されているのは*外来／在来の比*の条件付き関連である。

## 4. 生態学的に残ること・残らないこと

**保持できる発見**
- もともとの全球候補寄主の再分配（GEB +54.9%）、155蝶種の時間外予測MSE低下、51島の寄主類似性–蝶相の正の相関は独立結果として保持。
- 植物の高栄養立地選好と港での索引頻度の正の関連（記録国数・全球GBIF記録量調整後ρ=+0.210）。
- WWTP近接・下水発生量・都市化の地理的な正の対応は、環境の人為化という主題として保持。
- 新たに、約3kmの全球地図に基づく農地N**供給ポテンシャル**が高い地域ほど、港に索引された外来／在来寄主候補比が高い**横断的な条件付き関連**がある。

**未支持**
- 国別の未管理生活排水N割合が港周辺のWWp–寄主比の関連を強める予測は支持されず。
- 港周辺のモデル人由来N排泄ポテンシャルは、農地N・WWp・都市化を同時調整すると外来／在来**比**との独立関連が不明瞭。
- 下水由来Nが陸上植物に実際供給され、寄主が増殖し、チョウ定着へ波及する**因果連鎖は未実証**。実際の排水Nを河川・海へ輸送するモデルは陸上の寄主資源の直接栄養と同義ではない。

この結果は**栄養を供給する人為活動のうち、農業側の供給と人由来の下水排泄をマクロな指標で区別できる**ことを示すが、機構の決定的な実証ではない。植物の好栄養性や農業への依存が何を介して港の資源地理に結びつくかは別の検定として残す。
