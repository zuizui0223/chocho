# 農地Nと港の外来寄主候補：0記録・擬似カウント・外来割合の独立監査

2026-11-05 · [Draft PR #122](https://github.com/zuizui0223/chocho/pull/122) · **探索的な応答定義の頑健性検証。凍結済みGEB原稿は変更しない**

## 一文の結論

**農地N供給ポテンシャルとGBIF外来／在来寄主候補の記録比の正の関連は元のサンプル・元の応答定義では再現する。一方、観測された外来候補の割合を港ごとに等重みのロジットで評価すると、広い標本での正の関連は明確ではなく、記録の比較的豊富な港に絞ったときだけ正の方向となった。**

したがって、**農地への窒素施用が外来寄主植物を増やした、あるいは下水Nによって蝶が定着したという機構的主張に昇格させない**。既存の肯定的な港×寄主資源地理の結果は独立して維持する。

## 元データ・再計算の単位

[HydroWASTE施設数](https://github.com/zuizui0223/chocho/actions/runs/41414513676)、[Jones2015下水発生量](https://github.com/zuizui0223/chocho/actions/runs/41563940689)、[ESA WorldCover 2021の市街地と農地](https://github.com/zuizui0223/chocho/actions/runs/41562997326)、[CIRAD 2022年3km人由来N／農地N](https://github.com/zuizui0223/chocho/actions/runs/41923811745) を**同じ港ID**で結合。WPI2019のうち植物照会完了1,596港、元の調整可能な窒素ラスター・都市化の母集団1,041港／42か国。

元応答は2001–2024年GBIFの外来候補数 `alien` と在来候補数 `native` の `log[(alien+0.5)/(native+0.5)]`。両方とも0の港は強制的に対数比0になる。一方、外来割合 `alien/(alien+native)` は両群0の港で**未定義**である。検証では、この違いをそのまま保持し、ゼロ除算や未検出植物を生物学的な不存在に変換しない。

比較する各モデルにおいて、2015年モデル下水量、WWTP数、緯度・経度、大まかな2021土地被覆、国固定効果を統一する。元の寄主分類群索引総数は応答の構成要素を含むため、これを入れたモデル・抜いたモデルの両方を保存。標準誤差は国クラスタ頑健推定であり、港が独立に無作為標本化されたという意味ではない。

## 正の記録比：結果を維持しつつ、再現条件を明確化

| 同じ回帰の定義／品質条件 | 港数・国数 | 農地Nの係数 β | 国クラスタ95%区間 |
|---|---:|---:|---:|
| 既報の元モデル | 1,041港・42か国 | **+0.03993** | **+0.01335〜+0.06651** |
| 同じ指数・追加の「国別の有効変動」確認後 | 1,011港・38か国 | **+0.04064** | **+0.01391〜+0.06736** |
| 上記で擬似カウントを0.1に変更 | 1,011港・38か国 | +0.04172 | −0.00090〜+0.08434 |
| 上記で擬似カウントを2に変更 | 1,011港・38か国 | **+0.03671** | **+0.01764〜+0.05577** |
| 外来・在来候補のどちらかを1種以上記録 | 856港・37か国 | +0.02506 | −0.01126〜+0.06139 |
| 外来・在来候補の両方を1種以上記録 | 732港・33か国 | +0.03065 | +0.00627〜+0.05504 |
| 合計で少なくとも5候補種を記録 | 716港・34か国 | +0.03843 | +0.01036〜+0.06650 |
| 両種のNラスター有効格子率が50%以上 | 722港・31か国 | +0.02420 | −0.01394〜+0.06233 |

**0.5の平滑化という1つの選択だけで正の関連が生じたとは断定できない**（擬似カウント2でも正）。しかし、0/0の港を含めることや、宿主をどれほど検出したかで応答の意味と採用標本が変わる。特に「候補種が5種以上」という条件は**応答を用いた選別**であり検出選択やコライダーバイアスがありうる。事後の絞り込みで得た名目CIは確認的な有意差とみなさない。

## 擬似カウントを使わない、港等重みの外来割合

`alien/(alien+native)` という観測された候補の外来割合を、各港**1観測単位・無重み**の fractional-logit（binomial mean link、国クラスタ頑健分散）と、割合を連続量とするOLSで検証した。各植物種を独立した生存成功／失敗試行と仮定したbinomial count試行**ではない**。

| 部分集団 | Fractional-logit β | 95%区間 |
|---|---:|---:|
| 元1,011港のうち外来／在来合計が正で割合を定義できる860港 | +0.01421 | **−0.03923〜+0.06765** |
| 少なくとも5候補種を記録した716港 | **+0.03360** | **+0.00916〜+0.05803** |
| 外来・在来の両群が記録された732港 | **+0.02807** | **+0.00209〜+0.05404** |
| 2022窒素格子の有効画素率50%以上に制限し割合が定義できる650港 | −0.00402 | **−0.06921〜+0.06117** |

広い標本で割合の係数はゼロを含み、高品質窒素格子に制限しても明瞭ではない。検出された寄主候補の構成比との関連は、観測数の多い港に条件づけた場合の方向性として維持するが、**その選択自体がモデル結果を変える**。よって「農地Nは独立して外来植物を有利にする」という一般法則とは主張しない。

## 重要な分析単位の限定

- 生物学的な存在量・幼虫の利用・新規侵入種の定着は測定していない。応答は港5kmのGBIF索引種名リストと現代地域カタログの外来／在来候補。
- CIRADの農地窒素と人由来窒素は2022年のモデル値で、直接の下水放流N・土壌栄養・植物葉Nではない。
- 2015年の下水体積、2021年都市化、2019年港座標と2001–2024年プールGBIFを時間的に揃えた介入検定ではない。
- 国固定効果と国クラスタ区間だけでは、国の中の調査努力、土地利用、港交通、島嶼の歴史、産業の交絡を識別しきれない。
- 擬似カウント変更、記録数による制限、窒素源の欠測制限、半径違いなど一連のモデルは**複数の事後感度解析**。複数比較の補正済みの確認的主張は行わない。

## 統合した投稿上の判断

主線のGEB論文は寄主資源の人為的再分配とチョウの利用可能な資源地理の変化（既存+54.9%など）で維持。港・下水・富栄養化は独立の探索的補足結果として保存。**今の最も再現性の高い新規発見は、農地窒素の条件付き地理的関連が存在する一方、記録比と外来割合で証拠の強さが変わり、下水由来窒素による機構はまだ識別できないということ**である。
