# 全球の下水処理施設・港湾・外来寄主資源：初回実測と独立監査

2026-11-02 | [chocho Draft PR #122](https://github.com/zuizui0223/chocho/pull/122) | **探索的空間比較。GEB投稿本文は変更しない。**

## 問いと新しい肯定的結果

**世界の港における外来寄主植物の記録割合は、下水処理場という人為インフラの近接性と対応するか。**

答え：**国と大まかな地理的位置を調整しても、正の空間的関連がある**。ただしこれは「下水の窒素が植物を増やした」という機構の証明ではない。施設の位置、推定放流先、処理水量、寄主記録の十分性と在来寄主を比較すると、**施設の集積／都市環境と、生物学的な排水の栄養量を明確に分ける必要がある**。

[実測・ソース固定・CI SUCCESS](https://github.com/zuizui0223/chocho/actions/runs/41414513676) では、**HydroWASTE 58,502施設 × 2019 World Port Index 3,630港のうち全植物照会が完了した1,596港**を結合。港間比較の固定効果に必要な、WWTPの報告状況・港数・WWTP暴露の国内変動が揃う**1,368港・52か国**を主解析に使った。

既存chocho論文の +54.9% 全球的潜在寄主資源拡大、155蝶種の時間外予測改善、51島の寄主–蝶相の正の相関、および種別のEllenberg Nと港記録頻度の正の偏順位ρ+0.210は**独立した肯定結果として保持**。今回の結果を証明済みの因果鎖として接続しない。

## ソースと単位

- [HydroWASTE v1.0](https://www.hydrosheds.org/products/hydrowaste): Ehalt Macedo et al. (2022), *Earth System Science Data*, 14:559–577、CC BY 4.0。TidyTuesdayで固定した2022年CSV [SHA Git blob `0506f873...`](https://github.com/rfordatascience/tidytuesday/blob/774fb8cc81e563d6d30efdcb7b48a38565e923cc/data/2022/2022-09-20/HydroWASTE_v10.csv) を使用。**58,502施設**の処理場座標、推定放流先、処理水量m³/日、処理段階、品質指標を読み込む。原CSVをchochoには複製しない。
- 対象下水処理場：Operationalまたは稼働状態Not Reportedの**56,800施設**。明確に廃止／非稼働／計画中の施設を含めない。ただし**53,033施設は稼働状態未報告**のため、認定稼働施設数ではない。位置品質1・2は52,512施設、排水量の推定区分4は22,930施設。
- [chochoソース固定WPI2019港・植物インベントリ](../../port_alien_broad_inventory_20261030/port_alien_host_broad_all_ports.csv)のクエリ完了**1,596港**。国別内訳は142か国、WPIサーバー照合で**1,596座標取得**、地名から国を解決できる1,593件に不一致なし。
- 1,596港のうち、処理場が**10km以内851港、25km以内1,020港、50km以内1,157港**。近い処理場までの距離の中央値は8.43km、推定放流地点までの中央値は9.53km。
- 応答は2001–2024年プールのGBIF**記録された寄主候補植物種数**。`alien`＝参照カタログ上「当該地域に在来でない候補寄主」、`native`＝在来候補寄主。**その土地で実際に定着・利用された植物量でも、チョウの分布変化でもない**。
- 観測応答は `ln[(alien+0.5)/(native+0.5)]`。0.5平滑化のため両方0の港は「1対1」と扱われる**測定上の人工物**を含む。両方の種数が観測された港や5分類群以上記録のある港を独立感度として必ず示す。

## 主結果：国固定効果と対照

説明変数：半径内のWWTP施設数 `ln(1+n)`。国固定効果、絶対緯度・経度のsin/cosを調整。SEは国単位のクラスタ頑健推定。国内ラベル置換は探索的で空間自己相関を完全には保たない。

| 主応答：外来／在来候補寄主の対数比 | β | 国クラスタ頑健95%区間 |
|---|---:|---:|
| WWTPの近接数・10km | **+0.204** | +0.036〜+0.372 |
| WWTPの近接数・**25km（主解析）** | **+0.1285** | **+0.0077〜+0.2494** |
| WWTPの近接数・50km | **+0.134** | +0.038〜+0.230 |
| 位置品質1・2のWWTP数・25km | **+0.138** | +0.013〜+0.263 |
| 推定放流先の地点数・25km | **+0.140** | +0.029〜+0.250 |
| **推定・報告処理水量m³/日の合計・25km** | +0.020 | **−0.004〜+0.045** |
| 主解析 + **港の索引済み植物分類群総数（観測努力代理）** | +0.097 | **−0.026〜+0.220** |

主解析で0施設→1施設に増えた場合の**外来／在来記録比のモデル上の差は約+9.3%**。これは架空の介入効果や実際の植物増殖率ではない。

施設数と関連するのは外来寄主だけではない。25km WWTP数に対する対数記録種数の係数は**外来候補 +0.530、在来候補 +0.413**で双方正。**WWTP処理水量の寄主比との係数はゼロを含む**。従って、下水の窒素濃度・量的投与反応というより、施設を伴う都市的なインフラ／観測環境に関連する可能性が残る。

## 追加の独立再計算：観測記録と国の偏り

元実測artifactから1,596港×47変数の位置・施設曝露・寄主種数の表を取得し、Statsmodelsで式を独立に再計算した結果、主β = **+0.128502929**でソースと一致。すべて国固定効果と大まかな緯度・経度を調整した上で、**索引済み寄主分類群の総数**も共変量に加えた場合：

| 母集団・感度条件 | 港数 / 国数 | WWTP数25kmのβ | 95%区間 |
|---|---:|---:|---|
| 52か国の全港 | 1,368 / 52 | +0.097 | −0.023〜+0.217 |
| 在来/外来どちらか1種以上索引 | 1,087 / 52 | **+0.139** | +0.019〜+0.258 |
| 合わせて5種以上索引 | 903 / 46 | **+0.150** | +0.041〜+0.260 |
| 在来・外来候補ともに1種以上索引 | 934 / 49 | **+0.152** | +0.052〜+0.253 |
| WWTP数上位1%の港を除外 | 1,354 / 52 | +0.088 | −0.040〜+0.217 |
| 米国を除外 | 1,181 / 51 | +0.116 | −0.021〜+0.254 |

**十分に索引された港に限れば正方向が残る**が、その条件は応答変数の一部で選別しており、検出選択・コライダーバイアスの可能性がある。採択してよい因果感度ではない。逆に全港を使い観測量を加えたり、極端な施設密集港を除くとCIはゼロを跨ぐ。特定の一国を1つ除いたβは全52比較で正（約+0.053〜+0.124）だが、国別の単純順位相関の符号は**47か国中、正24か国・負23か国**。国間の不均一性が大きく、同方向の世界共通法則とは言わない。

## 都市化の独立チェック

[ESA WorldCover 2021 10m地図で同じ港IDが照合できる78港／35島](https://github.com/zuizui0223/chocho/actions/runs/41413762626)のうち、港・非港の土地被覆が共に有効なのは**77港・34島**。陸域500mの平均市街地割合は港**49.0%**、非港**10.9%**。WWTP数25kmと港市街地割合の順位相関は**ρ=+0.306**、非港の市街地割合とは+0.138。ここは国・観測努力を同時に制御したサブセットの効果ではなく、**施設近接が都市化の代理にもなっている**ことを示す交絡監査。WorldCover2021はWWTPデータと同時期の静的ラスタで、GBIFの2001–2010年の環境曝露そのものではない。港側500mの土地被覆と植物の5km種記録の範囲も一致しない。

## 結論・投稿判断

1. **新しく支持される関連**：WWTP施設密度が高い港は外来寄主候補が相対的に多く索引される（1,368港・52か国の国内比較、β+0.129）。観測量で調整後はβ+0.097、区間がゼロを跨ぐ。これは生態学的な機構というより**人為インフラ・寄主資源地理の併存**の証拠。
2. **栄養媒介は未確定**：水量m³/日と外来／在来寄主比の係数は不確実。HydroWASTEは流量であり窒素mass flux、土壌N、下水未処理水、植物のN取り込みではない。下水由来窒素が港の寄主を増やしチョウが定着したとはまだ主張しない。
3. **GEBの主要肯定結果を維持**：全球寄主再分配+54.9%資源機会、155種の時間外予測改善、51島の正の群集類似、およびN植物の港記録正の偏順位ρ+0.210とは別の階層の検証。勝手に否定・統合した因果実証として扱わない。
4. **独立した次の識別条件**：全球1,596港へ同スケールの市街化・人口・植物努力の情報を付けた解析、環境中の独立N負荷推計と植物種の国別導入履歴を検討。処理場の所在が本質的な効果なのか、それとも都市規模の代理なのかを識別する。
