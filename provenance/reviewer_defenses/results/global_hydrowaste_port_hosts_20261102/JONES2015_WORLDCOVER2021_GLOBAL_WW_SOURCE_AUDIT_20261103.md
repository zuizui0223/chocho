# 全球下水発生量・処理場・都市化 × チョウ寄主資源：三つの独立公開データによる追加解析

2026-11-03 | **[chocho Draft PR #122](https://github.com/zuizui0223/chocho/pull/122)** | 探索的マクロ生態学解析。GEB本体の投稿原稿は変更していない。

## 今回の新しい肯定結果

**モデル化された2015年の下水発生量が多い港ほど、外来／在来候補寄主の記録種数比が高い**。これは、同じ港でWWTP（下水処理場）数、2021年の市街地割合、農地割合、国固定効果、大まかな地理的位置、索引植物分類群数を条件づけても正方向だった。

- 標本は**1,055港、42か国**（厳密一致した1596港のうちWorldCover有効・国内比較可能な標本）。
- 同じモデルで、2015年の下水発生量 `log(1+WWp_25km)` のβ **+0.05870**、国クラスタ95%区間 **[+0.01310,+0.10429]**、探索的名目p=0.0116。
- その条件ではWWTP数 `log(1+WWTP_25km)` のβ **+0.05177**、95%区間 **[−0.07565,+0.17919]**。
- 2021年市街地割合β **+0.3713**、95%区間 **[+0.2192,+0.5233]**。
- WWTP数と下水発生量の全球順位相関はρ **+0.517**。2指標とも都市活動と共変動している。

「下水発生量」は都市・人口・産業の空間分布を反映した**モデル値**で、現地土壌に流入した窒素（kg N / ha / 年）ではない。**この正の関連は下水による植物の肥沃化や実際のチョウ個体群増加を証明しない。**

2015年のWWp、WWc、WWt、WWrを厳密な元ZIP SHA256 `c413f7493fb5c2b5a07d3d974abf3b9af25a32fcadd8eb839cc3fe302838e5eb` で固定して取得した。500m都市被覆と25km下水・処理場の比較範囲、5km寄主の生物記録範囲は一致しない。解析に使うものは**ソースを検証した世界各地の港の記録地理**である。

## 同じ標本・同じモデルでどこが変わったか

応答：
`ln((GBIFに記録された外来候補寄主種数+0.5)/(在来候補寄主種数+0.5))`。

国固定効果、絶対緯度、経度sin/cos、`log(1+全索引済み寄主分類群数)`を共変量に保持する（この総数には応答の種群も含むため、観測努力の完全な独立測度ではない）。

| モデル・同じ対象 | WWTP25km β［国クラスタ95%］ | モデル化下水発生量 WWp25km β［95%］ |
|---|---|---|
| 全球の国・地理・索引数調整（**1,368港・52か国**） | +0.097［−0.023,+0.217］ | — |
| 上記に2015年下水発生量を追加 | +0.040［−0.088,+0.168］ | **+0.063［+0.015,+0.111］** |
| 2021年市街地・農地が揃う**1,055港・42か国** | +0.100［−0.024,+0.223］ | — |
| 同じ1,055港にWWpを追加 | +0.052［−0.076,+0.179］ | **+0.059［+0.013,+0.104］** |

同じ1,055港でWWpの追加による標本内R²は**0.64604→0.64775**（+0.00171）と小さい。これは**時間外・空間外予測精度の改善を確認した結果ではない**。

## 「未処理下水」まで分けて確認

Jonesの5 arcminモデルではWWp−WWtという**モデル内の「発生したが処理された量として計上されない下水」**を計算できた。これは放流先に実際に到達した未処理排水、窒素濃度、陸上植物への暴露ではない。

1,055港・42か国でWWTP数・WWp・都市化・農地・国・観測量を同時調整すると、

- `log(1+WWp−WWt)` のβ **−0.0673**、95% **[−0.1384,+0.0039]**：ゼロを含む。未処理下水が寄主候補を増やすという一貫した支持なし。
- モデル化された処理率（WWt/WWp）のβ **+0.109**、95% **[−0.245,+0.463]**（生産量が正の**1,026港**に限定）：方向は不明。

明確なのは「下水の総発生量の多い港と、外来候補寄主の記録比の正の対応」であって、**未処理下水による富栄養化**や処理レベルによる特異的な生態応答ではない。

## 調査努力・在来寄主・群集地理との整合性

外来候補だけでなく、**在来候補寄主の記録数**もWWTP数やWWp発生量と同方向だった（同じ1,055港・42か国で、WWp β：外来+0.229、在来+0.175）。これは都市部の植物記録、園芸・栽培、港の観測機会と混ざっている可能性と整合する。

だから、**WWTP数→窒素→外来植物→チョウ定着**という媒介連鎖を実証したとは書かない。WWpも社会経済・水需要モデルから算出した空間指標であり、人口・工業活動と同じ情報を含む。

一方、chochoにある元々の肯定結果はそのまま保持する。GEBの寄主再分配による全球**+54.9%**の潜在資源機会、155蝶種の時間外予測MSE改善**4.12%**、51島の寄主類似性–蝶相類似性の正の対応 **ρ+0.300**、植物の好栄養性と記録港数の国数・GBIF記録数調整後偏順位 **ρ+0.210**は、**それぞれ異なる分析単位・問いへの実測**である。
