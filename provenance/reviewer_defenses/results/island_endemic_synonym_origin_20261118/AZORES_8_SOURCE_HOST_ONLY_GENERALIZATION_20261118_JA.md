# アゾレスの独立蝶類8種：元HOSTS・WCVPを共通にした寄主資源地理の再構成（2026-11-18）

## 科学的な現在地と新しい結論

元GEBで既知寄主植物に基づく全球+54.9%・島嶼サンプル+118.9%という**肯定結果は元の239種に条件づけて保持する**。その一方で、独立に種・亜種と原産性を分類できるアゾレス蝶8種（在来非固有6種、固有2種）をすべて元のHOSTS植物種とWCVP v13に同じ方法で照合したところ、**生態学的な潜在資源の地理的な増分は2種群で異なった**。

| ソース選別とは独立した群 | 在来非固有6種 | 固有2種 |
|---|---:|---:|
| NHM HOSTS原表で名前がある寄主植物種（蝶ごとの延べ合計） | 268 | 2 |
| WCVP v13で受理植物種に一意解決できた寄主（延べ） | 219 | 2 |
| 在来分布の潜在資源地域数（蝶×WGSRPD3） | **1,102** | **4** |
| 現代（在来＋導入域）の潜在資源地域数 | **1,726** | **4** |
| 導入域によって追加された蝶×地域 | **+624** | **0** |
| 加重の相対増分 | **+56.62%** | **0%** |
| 導入域の追加がある蝶 | **6/6** | **0/2** |

この結果は**元のNHM HOSTSの寄主「種」記録を固定し、その植物種の在来分布と現代の導入域を固定WCVP v13で比較**した source-only **host opportunity** である。蝶の在島数や個体数・産卵・成虫羽化・個別島での同所性を観測したものではない。6在来非固有種の219/268寄主のみが一意にWCVP受理種に解決できており、**未解決の植物名は寄主不在や実際の食草未利用とみなさない**。異名解決と必要形質の境界は元GEB239とは異なるため、元の係数・標本をこの8種で置き換えない。

## 固有種の追加がなかった理由と独立性

独立アゾレス目録の *Hipparchia azorina*（原アゾレス資料は *H. azorinus*）と *H. miguelensis* は、元のHOSTS原表で**同じ植物 *Festuca jubata* だけ**が寄主種として記載される。元WCVP v13で受理植物 *F. jubata*（ID 415473）に一意解決され、在来地域 **AZO（アゾレス）／MDR（マデイラ）** の2地域のみ、導入地域は0。したがって、2蝶種×2植物地域=4蝶×地域のうち追加地域は0。現在のKew POWOでも *F. jubata* の在来分布はアゾレスとマデイラとされる（https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A402924-1）。

**両蝶種は同じ食草1種に由来するため、これは2つの独立した寄主資源応答ではなく、1植物の地理特性が2蝶種に反映された**と記述する。これが「島固有性そのものが植民地的な資源拡大を抑制した」と断定できない重要な点。

## 分類説に対する感度分析も通過

過去の *Hipparchia* 自然史・分類学のレビューでは、同じ幼虫寄主候補に *Festuca petraea* を挙げる文献もある（Fuchs 1993をまとめた1997年のレビュー：https://www.zobodat.at/pdf/Nota-lepidopterologica_20_0150-0292.pdf）。元のWCVP v13を用いて候補を比較した。

| 事前に区別した寄主の解釈 | WCVP受理在来分布 | 導入分布追加 |
|---|---|---:|
| 元HOSTS原記録 *F. jubata* のみ | AZO、MDR | 0 |
| 文献上の別候補 *F. petraea* のみ | AZO | 0 |
| 両候補を採用した**仮想的上乗せ** | AZO、MDR | 0 |

これは分類・寄主名の感度分析で、**野外で両蝶種が2植物種を確実に食べると検証したことではない**。未記録の別のイネ科寄主が導入地に分布するかもしれず、資源拡大の「生物学的ゼロ」を証明しない。

## 339種／239種の既存母集団選択こそ重要な科学的制約

元の GEB239 は、原プロジェクトで**事前凍結された339種のLepTraits主要形質パネル**から絞られたもの。アゾレス2種・マデイラ3種・カナリア13種という、独立した資料で種階級の固有性を分類できた**18固有蝶は339の入口で0/18**。既知食草があるアゾレス2種も統計分析の後半で「効果が小さいため除外された」わけではない。

独立42蝶種を原LepTraitsに照合すると32種に行があり、うち固有18種では10種に行があるが、全ての環境形質が揃うのは0種。LepTraits原表に現れる固有10種は、寄主科数・化性・翅サイズの**寄主資源関連3条件は全て満たす**。しかし撹乱親和性7、湿度親和性7、林縁親和性6、樹冠親和性1の欠測があり、全形質一括条件には入らない。寄主資源**だけ**を解析する新規設計では、環境親和性を要求しないことでこれら10種を候補へ戻せる。残り8固有種はその学名の独立受理名照合の範囲で原LepTraitsに未収録。

これは「寄主さえ特定できれば10種の同じGEB効果を推定できる」とはまだ言わない。**源資料側の種レベルの幼虫寄主、在来植物分布、元339事前選定設計の違い**を保持する必要がある。
