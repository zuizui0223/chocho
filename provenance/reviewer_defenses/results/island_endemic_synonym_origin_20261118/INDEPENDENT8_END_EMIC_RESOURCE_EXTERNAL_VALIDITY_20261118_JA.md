# 島固有蝶の既知寄主植物は、どこまでGEBの潜在資源地理を再現するか（2026-11-18）

## 今回完了した検証と現在地

独立INBO島嶼蝶類42種のうち、カナリアBIOTA／マデイラBorges 2008／アゾレス大学2023で**独立に種レベル固有種と分類された18種**を対象母集団にした。元のLepTraits→S1候補339種→最終GEB239種へ源資料SHA一致で照合すると、**18固有種すべてが候補339種に入る前に脱落**。LepTraitsに学名がある固有種10種でも、調査された主要形質をすべて満たす種は0。研究史・生息環境形質データの欠測を無視して、元239種の+54.9%（全球）／島の相対+118.9%を島固有種平均へ外挿しない。

ここでは**形質による選抜を意図的にバイパス**し、出典から**寄主植物を受理名の種階級まで特定できる固有蝶8種／寄主植物11種／種×植物関係13件**に限定して、元GEBと同じWCVP v13（commit `65bed76bae9d644ccb6ad200c05f9f5071d89e05`）で在来植物分布と全現生分布を同一式で再計算した。**8種は寄主種名が確認できるという条件で選んだ偏りのあるサンプルで、18種の代表標本ではない。**

## 元GEBと同じ計算式で、8種の可能な資源分布は一様ではない

単位は **WGSRPD3植物地域**。蝶が移動・定着した地域でも、実際に幼虫が食べた地域でもない。

## 感度分析で確認したこと

1. `Pieris cheiranthi`は、カナリアで幼虫が利用する外来`Tropaeolum majus`を一つ除外すると、全球の追加潜在地域は **78 → 0**。この観測済み寄主植物1種が追加分を左右する。ただし**カナリア地域の既知在来寄主の有無は変わらない**。導入寄主による「資源選択肢の追加」と「新規の寄主を持つ地域」の区別が必要。
2. `Euchloe grancanariensis`では、野外幼虫が利用した**カナリア在来**`Hirschfeldia incana`を除外すると、追加潜在地域 **47 → 0**。増加するのは、この植物種がカナリア以外で導入された地域を含む全球潜在植物地理であり、`E. grancanariensis`が遠方で繁殖する証拠ではない。産卵だけの`Descurainia preauxiana`と、野外幼虫利用を区別した。
3. `Euchloe hesperidum`の51追加地域には、**1幼虫の飼育下受け入れ**という強い標本依存がある。飼育で受け入れた`Sisymbrium irio`を除くと51→12地域。これは種全体の野外寄主品質の推定ではない。
4. `Pararge xiphioides`の追加9地域は、野外幼虫の島・日付に結び付かない**単一文献の植物種**に依存する。除外して寄主が0種になる場合は「追加0」としない。**効果は非同定**とする。
5. 寄主の確認レベル別では、幼虫寄主の野外・文献報告がある5種中3種に追加潜在地域があり、産卵・飼育だけの情報も入れた6種中4種にある。非局所HOSTSも含めた8種では4種に追加。**直接野外幼虫が植物種名付きで観察されたのは3種**であり、そのうち2種で全球潜在地域の追加を確認（`Pieris cheiranthi`の外来`Tropaeolum`、`E. grancanariensis`の在来`Hirschfeldia`）。これらの分母は同じでなく、証拠の強さを混ぜて推定しない。

## 出発地の寄主はあったのか：全球の資源地理とは別の問い

8種中**8種すべてに出発地の諸島地域に在来と分類された寄主植物種**が記録され、**1種だけに出発地の諸島地域で導入と分類された寄主植物種**（`P. cheiranthi`―`T. majus`）があった。今回確認した植物種名だけを用いれば、**「在来寄主がなかった出発諸島が、外来寄主で初めて寄主を持つ」単位は0**。これは寄主が確認できた8種だけでの記述であり、全固有蝶に在来寄主が十分あるという根拠にはならない。

## 個別島への識別可能性：8種×22島記録でも直接観察は4組

独立チェックリスト上、8固有蝶の「蝶×名前付き島」組は**22組**。出典の植物種に幼虫が実際に確認された組は**4組**だけ（野外3組・庭園1組、蝶は3種）。野外植物の由来は**外来2組**（`P. cheiranthi`のテネリフェ・ラパルマ）と**在来2組**（`E. grancanariensis`のグランカナリア、`G. cleobule`のラゴメラ）。ラパルマの1組は**庭園**であり、野外個体群の持続・寄主品質とは区別する。

残る18組は**確認した資料に「植物種名と同じ島の幼虫が同時に明記されていない」**ことを意味し、幼虫寄主の生物学的不在ではない。`CNY`（カナリア）、`AZO`（アゾレス）、`MDR`（マデイラ）のWCVP植物地域は個別島の植物在来性・日時ではない。

## 一つのGEB論文への最終的な採用境界

**支持：** 元239種の資源増大は保持。独立島固有蝶にも、植物種の導入による全球的な**潜在寄主資源地理の拡大**を示す例と、拡大を示さない例が存在する。さらに**固有蝶が外来植物を実際に幼虫寄主として利用した個別島の観測**を少数例ながら検証できた。

**非支持：** 8/18の選抜パネルから島固有蝶全体の平均効果を推定する、追加78地域を`Pieris`の分布拡大と呼ぶ、源寄主リストが同じでない種の倍率を無条件に比較する、港・船・海流による実際のチョウ定着や幼虫成功を因果的に帰属すること。

現時点では源資料の外的妥当性と生物学的フィルターを示す**補足資料（SI）の反証的検証**として保存し、既存の全球GEB肯定結果・投稿原稿は変更しない。
