# 島間の共通チョウ記録に、対応する共通食草があるか

2026-10-30。前段の51島・1,275組を維持し、225種を候補母集団とする探索的マクロ解析。食草・チョウ相の全体類似性から、個々のチョウと食草カタログの対応へ進めた。

## 結果

両島で2011–2022年に初めて記録された共通チョウは82種、延べ1,163件の種×島ペアだった。そのうち両島の港で記録された共通の外来食草候補に対応したのは33種・208件、17.9%。チョウ種ごとの割合を等重みで平均すると14.2%だった。種×島ペアは同じ島・種を繰り返し含むため独立な侵入事例数ではない。

| 共通する外来食草候補 | 対応して共通新規記録されたチョウ種数 | 対応のある島ペア数 |
|---|---:|---:|
| Medicago sativa（アルファルファ） | 7 | 12 |
| Mimosa pudica（オジギソウ） | 3 | 50 |
| Cocos nucifera（ココヤシ） | 3 | 10 |
| Tropaeolum majus（キンレンカ） | 3 | 10 |
| Lunaria annua | 3 | 1 |

植物の順位は対応チョウ種数、次に島ペア数で決めた。植物ごとの件数は重複しており、足し合わせない。外来候補とは現在分布・在来域カタログに基づく分類で、船舶による導入が確認された植物という意味ではない。

具体例として、キンレンカは Pieris napi、P. rapae、P. brassicae、オジギソウは Zizula hylax、Junonia almana、Zizina otis の共通新規記録とカタログ上で対応した。現地での食草利用の確認ではない。

## 種ごとの関連

少なくとも片方の島で新規記録された組を対象に、「両島で新規記録」と「両島に共通する対応食草記録」の二値相関を種ごとに計算した。5組以上かつ双方の変数に変動がある51種で、phi係数の平均は0.071、中央値は0.028だった。記述的な関連は平均して小さい。種×島ペアの非独立性があるため通常のp値は示さない。距離・気候・生物地理・観測量を調整した効果でもない。

## 何が言えるか

前回の「外来食草が似る島では新規チョウ相も似る」という相関の一部に、名前の分かる食草とチョウの対応が確認された。ただし大半の共通チョウ記録には今回の港データで対応を確認できず、種ごとの関連も小さい。これは食草の不在や食草効果の否定ではなく、現行の観測・カタログで確認できた範囲である。

2001–2024年集約の植物記録がチョウの2011–2022年の新規記録より先に存在したとは限らない。チョウの初記録も到来年ではない。輸送、人為的な食草導入、島間中継、繁殖・定着、予測改善の証拠としては扱わない。全体相関の正方向だけで食草を介した拡大を説明せず、次の比較でも候補225種を保持する。

## 検証

20,337件の「片方または両方で新規記録」の種×島ペアを、島履歴の別の表結合で再構築した。報告された2,180本の食草対応（片側新規記録の組も含む）について、食草ネットワークの辺と両島の外来候補分類をすべて照合した。上位植物の種数と225種の採否も一致。元データの完全性・導入経路を検証したものではない。

資料：`island_shared_host_match_top_plants.csv`、`island_shared_host_match_all225.csv`、`island_shared_host_match_audit.json`、`island_shared_host_match_validation.json`。行単位の詳細はローカルに保存し、ネットワークの大規模な再配布を避けてPRには集計を同期する。
