# 港の食草と島でのチョウ初記録を事例から読む

外来食草候補が2001–2010年に港周辺で記録された20島390種×島のうち、2024年に対象島で初記録となったのは6島8組だった。年は2001年以降の今回の記録資料に基づく。下表の件数は2024年の出現記録数。フェリーは往復航路の接続、LNGは既往記録島から到着島への輸送方向を用いた。

|到着島・チョウ|食草を記録した港と食草の例|同種の最寄り既往記録島|同種既往島との航路・2024年記録数|
|---|---|---|---|
|ボーンホルム・*Nymphalis polychloros*|レネ、ハスレで *Malus domestica* と *Pyrus communis*。*Salix alba* はレネ|エーランド、172 km|シェラン島とのフェリー。3件|
|北海道・*Nymphalis antiopa*|石狩湾新港で *Rumex acetosella*|本州、904 km|本州とのフェリー。2件。照合航路は苫小牧―大洗で、食草調査港は石狩湾新港|
|サハリン・*Celastrina argiolus*、*Polygonia c-album*|ともにウグレゴルスクで *Humulus lupulus*|北海道、いずれも682 km|ともにLNG接続、各1件|
|サハリン・*Vanessa cardui*|ホルムスクで *Tussilago farfara*|北海道、682 km|LNG接続、1件。上の2種と同じ島・年|
|シェラン・*Thymelicus sylvestris*|島内5港で *Bromus erectus* または *Eragrostis minor*|フュン、87 km|航路未確認、1件|
|ウィッビー・*Colias eurytheme*|クープビルで *Medicago sativa*、*Trifolium repens* 等|バンクーバー島、202 km|航路未確認、1件|
|サンタカタリナ・*Strymon melinus*|アバロンで *Trifolium repens*|サンクレメンテ、46 km|航路未確認、1件|

**近距離の対照。** ボーンホルムでは食草先行・航路確認が5組あり、初記録は *N. polychloros* 1組だった。同じ島で *Cupido minimus*（155 km）、*Callophrys rubi* と *Erynnis tages*（ともに172 km）にも先行食草と航路がそろうが、2024年の初記録は0件。ウィッビーでは航路未確認でも *C. eurytheme* に初記録がある。距離比1.25以内、双方250 km以内で種や島をまたいで照合すると5ペア。確認側1/5、未確認側0～1/5で、同じ距離で選べる対照種によって差が変わる。両群を同じ到着島に限定すると近距離での対照は得られない。

**読み方。** ここで追えるのは、港周辺での食草の記録、島間の運航実績、島での成虫等の出現記録の時間順序までである。港を最寄り島と結ぶ航路に限った検証ではなく、チョウの新規記録も到着港に限定していない。現地での摂食や繁殖、船への乗載、当該港からの拡大を個別に調べるには別の観測が必要になる。

全390組を島別に並べた[事例台帳](case_records.csv)には、食草ごとの港名、最寄り既往記録島と距離、資料で航路確認できた既往島、船種、2024年の記録件数を収録した。[照合率の図と方法](README.md)・[個別の対照ペア](pairs.csv)
