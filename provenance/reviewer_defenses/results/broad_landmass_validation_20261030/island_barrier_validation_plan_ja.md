# 島・自然障壁・輸送・到来の時間差：検証計画

設定日：2026-10-29。目標は進行中。既存の結果を受けた追加解析であり、2019–2022年を未閲覧の独立検証データとは呼ばない。

## 研究目標
食草・気候・土地利用が適していても記録が増えない場所、反対に過去の分布から離れて新たに記録される場所を、自然地理と人為輸送の違いで予測できるか検証する。225種の候補母集団と全種の採否表を維持し、既存155種の解析を主比較とする。島だけに母集団を縮小しない。

## 固定する仮説と比較
1. 自然障壁：同程度の距離・資源・気候でも、過去の記録と別の陸塊にある地点、海上区間が長い地点では記録増加が小さい。
2. 島の接続性：過去に記録された陸塊から近く、途中に島がある場合は、単独の孤立島より記録増加を予測しやすい。面積、緯度、観測努力を考慮する。
3. 地形：標高・起伏と経路上の地形が、直線距離だけでは表せない差を追加的に説明する。標高を飛翔抵抗と同一視せず、効果の符号を強制しない。
4. 人為輸送：自然的な接続性が低い場所でも港に近い地点では、食草資源がある場合の新記録を追加予測できる。ただし港への距離だけから輸送や共導入は断定しない。
5. 時間差：独立に年代が判明する食草導入とチョウの最初の確実な記録の間隔が、自然障壁・輸送接続性で異なる。GBIF初記録の差は別の記録指標として扱う。

## 手順と成果物
- [ ] 海岸線・島・港・DEMの取得証跡、年代、ライセンス、解像度、全5282候補セルへの結合率を監査する。
- [ ] 高解像度海岸線とセル中心の陸塊所属を結合。海上中心のセルは除外せず未分類として件数を示し、セル面積の陸塊重なりと比較する。
- [ ] 2001年から各予測起点までの記録のみを用い、同一陸塊の既往記録、最寄り既往陸塊、海上区間を作る。海峡幅と直線経路の海上距離は別の指標とする。
- [ ] DEMのセル内標高中央値・起伏を取得し、経路指標は別段階で追加する。DSMなら樹冠・建物を含むことを明記。
- [ ] 港の近接性を算出。確認済み2019年版は後知恵の地理的関連解析に限定し、2011/2015起点の予測変数には使用しない。航路・輸送量は年代整合する資料がある場合のみ使用する。
- [ ] 既存M5に自然地理を追加したモデルを最初に比較。その後、観測努力＋気候＋土地利用、＋食草、＋過去分布、＋自然地理の分解比較を行う。旧M3にも過去分布の指標があるため環境のみとは呼ばない。
- [ ] RF設定は既存固定値を再利用し、同一評価行で種平均MSE・MAE、未記録地点、島別成績を比較。空間外評価と種外評価を分ける。島単位の保持検証も、十分な独立島数がある場合に追加する。
- [ ] 観測努力・提供者・座標精度への感度、500km候補範囲による遠距離到来の切り落としを監査。広域全候補での解析は既存主解析と別に報告する。
- [ ] 既存の年代付き食草PRも確認し、植物導入年代・チョウ記録年代・地域範囲・典拠を組ごとに照合。年代不明をゼロ年差にしない。左打切り・区間不確実性を残す。
- [ ] 全種採否、取得状況、図、結果、支持されなかった仮説を保存し、検証済みの単位でGitHub PRへ同期する。

## 判定基準
単なるRF重要度ではなく、変数群追加による保持データの誤差差で判断する。固定予測の種×空間ブロック再標本化を用い、その区間はモデル学習・資料誤差を含まないと明記する。既知種での改善と未知種への一般化は別の結論。静的な地理代理変数で気候変化・輸送の因果寄与は識別しない。

取得完了や計画作成だけでは目標完了としない。自然地理について実際の比較予測を終え、港・時間差について実施できた検証と資料上できない部分を明示する。
