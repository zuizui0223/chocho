# 共通上位食草の初記録順序（地域不整合除外後）

上位6食草に対応する現行19組のうち16組で植物が先に記録された。チョウ先行1組、区間重複1組、年代未確定1組。Canada/Greveの2組を隔離済み。残存する原典の全件確認や導入年代の確定ではない。

|食草|組数|植物先行|チョウ先行|区間重複|年代未確定|
|---|---:|---:|---:|---:|---:|
|Medicago sativa|7|5|1|0|1|
|Robinia pseudoacacia|1|1|0|0|0|
|Plantago lanceolata|2|2|0|0|0|
|Capsella bursa-pastoris|4|4|0|0|0|
|Hesperis matronalis|5|4|0|1|0|
|Malus domestica|0|0|0|0|0|

初記録の順序であり、船舶による持ち込み・同時輸送・食草への追随を識別しない。対応なしは年代資料の被覆不足で、食草利用の否定ではない。現在の港周辺記録とは時空間単位が異なる。
出典：Alien Species First Records v3.1、DOI 10.5281/zenodo.10039630。乱数を含むFirstRecordではなくFirstRecord_origの年代区間を使用。
