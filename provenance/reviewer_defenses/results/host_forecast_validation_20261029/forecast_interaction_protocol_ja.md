# 食草による環境応答差の補助解析

主解析の時間外RF結果を見た後の探索的補助解析として、以下を係数の計算前に固定する。予測モデルの設定変更には利用しない。

応答は同じメッシュ集合における標準化記録確率の期間間差。種×WGSRPD地域に集約し、両期間で観測支持があるメッシュが10個以上の組を扱う。2011–2014年から2015–2018年の変化で係数を推定し、2015–2018年から2019–2022年の変化で条件付き再現誤差を評価する。後期の実測環境を使うため、事前情報だけによる将来予測とは別解析である。

気温、農地率、建造地率の期間間差と、(1)全体の食草利用幅のlog1p、(2)地域的に利用可能な食草の割合、(3)利用可能な食草に占めるイネ科の割合の9交互作用を検討する。イネ科は開放景観との関係を問う組成の一例であり、18科全体の組成効果を代表する検定とはしない。結果を見て科を選び直さない。

降水・樹木被覆の変化、初期の記録確率、両期間の記録日数のlog比、提供者集中度の変化を調整変数とする。種のランダム切片、地域の固定切片を持つ混合モデルで、主効果のみと9交互作用追加を比較する。スケーリングは初期の学習集約表のみで決める。9交互作用のp値はHolm法で調整するが、探索的性格は変わらない。

集約行は等重みとし、メッシュ数の多い種・地域の過度な支配を避ける。ただし種そのものの均等重みではないため、RFの主指標とは区別する。記録過程、地域内の空間依存、集約による変化の隠蔽、静的な食草資料の誤差は残る。モデルの収束、ランダム効果の分散、実際の対象種・地域数、集約前後の脱落を記録する。因果相互作用や真の分布移動は識別しない。
