# 将来予測性を重視した評価の固定

2026-10-29。モデル学習前の設計。全体目標は進行中。

## 対象と時間分割

候補母集団225種。2011–2014・2015–2018のそれぞれに2年以上・20記録以上ある10km等積メッシュを選定し、2019年以降の記録は選定に使わない。候補5,282メッシュ。種は2011–2014の初期期間にこの集合で10メッシュ以上・30記録以上ある155種を候補とする。全225種の段階的な除外理由はforecast_candidate_disposition.csvに残す。食草地域境界、環境品質、日付、観測努力に関する適格性は別途明示する。

2019–2024の全行を捨てて適格性を独立再計算し、5,282メッシュ・155種が一致した（forecast_selection_validation.json）。以前の全期間共通4,435メッシュは回顧的比較用で、純粋な時間外評価の主集合にはしない。

学習：2011–2014の状態から2015–2018を予測。最終時間外評価：2015–2018の状態から2019–2022を予測。最終期間の予測誤差を見て特徴量や設定を選び直さない。モデル選択は学習区画のみ。短い系列のため時間外検証は一つの将来期間に依存するという限界を明示する。

## 二種類の予測を混同しない

1. **予測開始時点までの環境情報による評価**：気候・土地被覆の基準期間の平均と期間内傾向、既往出現、食草を入力する。実際の後年の気候・土地被覆は入力しない。持続予測（前期と同じ分布指標）を必ず比較対象に含める。
2. **環境条件を与えた再現検証**：実際の後年の環境変化を入力する別解析。将来シナリオを与えた場合の予測能力に近い問いだが、予測時点に未知だった環境情報を使うため、1の精度として報告しない。

将来シナリオへの展開は、時間外・地域外・種外の検証後。環境変数を観測範囲の外に動かした際のRFの限界を点検し、現代の食草地理を固定する場合は条件付きシナリオとする。現代の静的食草資料や2026年取得の観測アーカイブを使うため、過去に実際に発行可能だった予報の再現とは呼ばない。

## 応答と観測過程

GBIFの存在記録から、観測努力を揃えた記録分布の変化と新規の継続記録を調べる。不記録を確実な不在、初記録を確実な定着としない。種×メッシュ×提供者×日の重複をまとめた記録日が復元できている。これも完全な調査訪問リストではなく、同一提供者・同日内の複数観察者をまとめるため、調査回数とは呼ばない。

標準化した記録分布の予測と、真の分布拡大・定着の予測を区別する。観測過程の不足によって真の拡大が識別できない場合は、その限界を結果の中心に残す。食草×景観の関連が得られても、食草増加・食草転換という機構が観測されたとはしない。

## 共通性の評価

M0背景/既往出現、M1気候、M2土地被覆、M3気候＋土地被覆、M4食草追加を同じ外部評価で比較する。RFで非線形予測を探索し、主要な関連を階層モデルで確認する。食草利用幅・総数だけのモデルと、地域食草組成を使うモデルを区別する。

時間外、空間ブロック外、未学習種の評価を分け、種ごとの予測誤差と種均等重みの集計を示す。種外モデルで種IDを入力しない。同一気候格子を共有する10kmメッシュの依存を考慮する。地域/種による予測の崩れも結果として扱い、平均精度だけから普遍的と呼ばない。

相関する気候・土地被覆・食草の重要度を因果寄与率にしない。外部評価での変数群追加/除外による増分を優先する。後年の記録日数は評価可能性の確認には用いるが、未来予測に利用可能な生態的入力としては使わない。
