# 予測検証の感度分析

2026-10-29。主解析の時間外結果を確認した後に実施する頑健性検証。主解析の事前固定とは区別する。RFの設定、環境変数・食草変数、学習・評価期間は主解析と共通とし、感度結果から主解析モデルを選び直さない。

| 変種 | 変更する内容 | 確認する問題 |
|---|---|---|
| effort20 | 20記録日への希釈化確率を用い、各期20日以上の観測支持を要求 | 記録努力の基準による結果の変化 |
| radius250 | 2014年以前の既知記録から250 km以内に候補を制限 | 到達可能範囲の定義への依存 |
| exclude_top_provider | 最大のデータ提供者を除いて記録日、種別成功日数、季節構成、提供者集中度を再計算 | 特定の提供者への依存 |
| precision100 | 元の出現記録を位置誤差100 m以内に限定して、記録日と観測指標を再構築 | 位置精度の条件への依存 |

最大提供者は主解析の記録日監査で確定した `1e266c3d-92ef-4d5a-8e4a-c04742c772c3`。その除外は予測結果の良し悪しで選んだものではない。

主解析で固定した155種と候補メッシュ領域を起点とする。提供者・精度で絞った後に観測支持を失う組は評価から脱落するため、種数・組数を各結果に記録する。未来の支持を理由に学習行を落とさず、各遷移ごとに学習・評価可能な行を定める。希釈化20日の指標は10日の指標とは異なるため、異なる変種間の絶対誤差を直接ランキングしない。各変種内部で、食草を加える前後の差を比較する。

種外検証は種単位の5分割、空間外検証は5度ブロック単位の5分割。同一気候グリッドは同じ空間ブロックに属する。各場合に2011–2014年→2015–2018年を学習し、2015–2018年→2019–2022年を評価する。空間外検証は隣接ブロック境界に緩衝帯を設けていないため、空間的な独立を完全には保証しない。

この4変種だけで因果帰属・真の占有・食草の移動を検証したことにはならない。提供者の構成変化に関する条件別評価、食草による環境応答差の直接検証、空間依存の残存は別途確認する。

実行状態は `forecast_validation_queue.json`、データ準備の監査は `forecast_sensitivity_preparation.json` を参照。準備完了は解析完了を意味しない。
