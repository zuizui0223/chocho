# 港の外来食草候補とチョウの記録対応

取得済み17港（日本8、英国8、カナダ1）の同じ5 km検索ポリゴンで、2001–2024年の食草とチョウの記録を照合した。既存候補225種をすべて残した途中集計であり、全球の関連の推定ではない。

- 外来食草候補との利用関係を持つチョウ：111種。
- 港の範囲内にチョウ自身の記録がある：31種、重複除去後8,525記録。
- 利用関係のある外来食草候補とチョウの両方が同じ港の範囲内に記録される：16種、59種×港。

これは同じ港周辺での記録の対応である。食草を実際に利用した観察、同時期の生息、港経由の導入、島を中継した分布拡大を示すものではない。未記録は不在と扱わない。地域的な外来候補の判定と、チョウ自身の外来判定は別であり、ここでは後者を判定していない。

全14,637,152件・59ファイルのチョウ原座標を検索した。照合後の全8,525座標が対象ポリゴン内にあることと、225種×17港＝3,825行の食草種数・チョウ記録数・両者の対応フラグを再計算して検証した。観測量の補正や対照地点比較は加えていない。
