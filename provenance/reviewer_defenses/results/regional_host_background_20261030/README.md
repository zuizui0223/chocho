# Regional host associations and matched background comparison

Read `regional_host_background_results_ja.md` with the original correlation report. Raw negative host-distance correlations are not host-specific evidence: matched catalogue-background plants show similarly or more negative associations. This is a retrospective, unadjusted exploratory analysis, not a movement mechanism, introduced-status verification or new forecast evaluation.

The global first-island-record universe retains 225 candidates, with 205 species having events; regional host context covers 3,702 events / 196 species / 870 islands. Eligible correlation support varies by feature and region-count threshold. Host and background comparisons use the same species and regions within each feature. Background means plants in the 225-species host catalogue not listed for the focal butterfly, not confirmed biological non-hosts.

The snapshot includes both the raw association and the counterevidence, per-species correlation aggregates, comparison rules and validation receipts. It excludes raw occurrence coordinates and restricted full host-network edges. The background comparison was specified after observing the original correlations and before computing background results; this is not a claim of whole-study preregistration.

Run `python verify_snapshot.py` to verify hashes and recompute paired descriptive summaries/intervals from species-level correlations. This does not reconstruct restricted regional plant inputs or independently validate the botanical source. Shared regions, phylogeny, climate, land use and recording intensity remain unresolved.
