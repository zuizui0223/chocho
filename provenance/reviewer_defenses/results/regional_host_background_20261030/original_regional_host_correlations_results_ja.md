# 食草の地域的な分布と島の新規記録の近接性

**追加比較による解釈の更新：** 同じ種・地域で比較すると、背景植物にも同程度以上の負の相関があった。このページの生の相関を食草固有の役割の証拠としない。`regional_host_background_results_ja.md` と併読する。

元座標による12,028件の島の新規記録のうち、地域別食草情報を対応できた3,702件・196種・870島を探索した。候補225種は維持し、食草情報のないイベントを食草なしに変換していない。食草の再構成値と既存値の不一致は0組だった。

同じチョウ種の中で、地域ごとの食草割合と、島の新規記録から以前の最寄りチョウ記録までの距離中央値を比較した。地域内の多数の島を独立な食草分布データと数えないよう、まず種×地域に集約した。食草割合の分母は、そのチョウのカタログ上の全食草数。

|食草指標|全対象：平均相関 / 種数|過去の観測被覆あり：平均相関 / 種数|
|---|---|---|
|食草全体|−0.236 / 106種|−0.220 / 81種|
|在来食草|−0.229 / 107種|−0.159 / 83種|
|外来候補食草|−0.144 / 98種|−0.121 / 78種|

各種5地域以上、食草と距離の双方に変動がある場合のSpearman相関を計算し、種を等重みで平均した。10地域以上に限定しても各指標の平均相関は負だった。ただし指標ごとに評価可能な種が異なり、平均値の大小から在来・外来の効果の強弱を判定しない。種単位の再標本化区間は記述的なもので、系統関係や共有する地域の依存性を考慮していない。

**食草割合の高い地域ほど、以前のチョウ記録に近い場所で島の新規記録が見られる傾向**がある。一方、これは外来食草が遠距離の移入を促したという結果ではない。現在の粗い地域別分布を使っており、気候適性、地域の形状・隔離度、土地利用、記録の密度によって同じ傾向が生じる可能性がある。

港周辺の植物オカレンスとは別の解析である。外来候補は現存分布にあり在来分布にはないカタログ上の集合差で、独立に導入が確証された分類ではない。食草がチョウより先にその島に存在したか、港の食草が中継地を作ったかは、座標・年別の植物記録による次の検証課題として残る。現時点で機構や将来予測性能は立証していない。
