# 島・港の観測的な正の相関を出発点にする：51島の追加感度検証

2026-10-31｜**既存の観測結果を再計算し、観測的な主張だけを先行させる**。新しい植物・蝶の調査データを取得した成果ではない。GEBの完成済み原稿・+54.9%の主結果は変更しない。

## 第一の問い（実際に答えられる範囲）

**港周辺に索引された外来候補幼虫寄主植物の種類が似ている島同士では、2011–2022年に新たに索引されたチョウ相も似ているか。それは両方ゼロの島ペアや長距離・従前のチョウ相だけの結果か。**

- 元の完成済み港照会103島から、前期蝶記録と港外来寄主候補の双方がある**51島**を固定した。**1,275組は独立サンプルでなく51ノードの全ペア**。候補蝶は225種、51島の新規索引は116種・430蝶×島、前期99種。
- 港植物は**2001–2024年のプール**。新規チョウとは初索引年が2011–2022年の観測記録を指し、初移入・繁殖確認ではない。植生が先行したとみなさない。
- 種組成の類似性は島間Jaccard。港距離は代表港間の直線距離で、船便・散布経路ではない。

## 正の観測結果を固定データから独立再計算

| 比較 | 観測値 | 解釈 |
|---|---:|---|
| 港で索引された外来寄主候補Jaccard × 新規索引チョウJaccard | **Spearman ρ=+0.300** | 元の51島1,275ペア結果を再現 |
| 同じ寄主候補Jaccard × 従前チョウJaccard | **ρ=+0.418** | **既存の蝶相との一致のほうが強い** |
| 島間距離・従前蝶相を順位残差化 | **偏順位相関 +0.215** | 距離・既存相に加えて記述的な対応が残る |
| さらに両島の寄主・新旧蝶の索引種数の最小/最大、港数を調整 | **偏順位相関 +0.221** | 検出努力そのものは調整していない |
| 寄主候補Jaccard >0 のペア | **711ペア、ρ=+0.285** | 全ゼロペアだけの結果ではない |
| 寄主・新規蝶の両方Jaccard >0 | **394ペア、ρ=+0.326** | **事後条件付け解析**なので独立の検証や予測ではない |

元の1,275ペアでは寄主候補共有が711ペア、新規蝶共有が600ペア、両方Jaccard=0は358ペア。**両方ゼロを排除しても相関が消えない**というのが今回の直接的な追加所見。ただし、共有のある島だけの選別は新しい選択バイアスも生み得る。

距離の四分位（約4,289 / 8,904 / 11,388kmで区切る）内でも、寄主×新規蝶相のρは**+0.298 / +0.195 / +0.183 / +0.191**。これは国・海域内の独立再現を意味しない（四分位でも大陸横断ペアが入る）。

## ノード依存を無視しない探索的参照：残差行列の島ラベル置換

元の順位残差（距離・旧蝶相調整）を**島×島の対称行列**に戻し、チョウの行・列の**同一島ラベルを一緒に置換**。固定寄主残差との相関を各回再計算した。**5,000回に見えるが、実行は4999回のランダム置換＋観測1回のモンテカルロ補正**。島ペア1275個をランダムに並び替えてはいない。

| 島ラベルの置換範囲 | 観測偏順位相関 | 置換帰無平均 | 置換参照の両側tail率 |
|---|---:|---:|---:|
| 51島を全球で自由に | +0.215 | +0.000 | 0.0002 |
| 地理距離だけでcomplete-link ≤1,000km群を作り、群内のみ | +0.215 | +0.164 | 0.0440 |
| 同じく≤2,000km群 | +0.215 | +0.157 | 0.0282 |
| 同じく≤3,000km群 | +0.215 | +0.144 | 0.0154 |
| 両島の索引種数等を加えた順位残差、≤2,000km群 | +0.221 | +0.140 | 0.0010 |

**重要**：地理群内置換の帰無平均がすでに強く正（+0.14〜+0.16）。**共有地理に起因する対応をゼロへ消したわけではない**。地域内の残差ラベルが交換可能という仮定は実際に保証されず、地理距離閾値・植物の出現頻度や種の真の検出率を事前登録した検定でもない。上記のtail率は**感度診断に限る**。通常の独立ペアの検定p、母集団への信頼区間、因果推定のpとして引用しない。

## 既に存在する反証・限界は必ず併記

1. **新規索引に固有ではない**：従前蝶相ρ=0.418は新規ρ=0.300より大きい。
2. **植物の先行性は広域では未識別**：2001–2024年植物情報を使うため、後年植物記録も含まれる。歴史的な2001–2010年の17島に限定した寄主×初索引の超過は、植物の島での出現頻度・6海域を固定した帰無で消えた。
3. **港を独立な機構として測っていない**：外来候補植物は港周辺の索引であって、同島非港植物相との差ではない。港に近いこと・植物の種類・船舶で運ばれたことは同義ではない。
4. **検出努力・生息地の交絡**：GBIF植物と蝶の標本数/観察者/データ提供者、海域、気候、島面積、非寄主植物の組成を全面的に同条件にしていない。
5. **並行の1km歴史港／非港植物解析**（PR #116）は港固有の適合外来寄主の増加を独立に支持しておらず、直接的な港機構に昇格しない。5km港索引と1km沿岸植生を混同しない。

## 次の一つの主検証

**外来候補寄主の類似性が、同じ港で記録された一般植物・非寄主植物の類似性より、2011–2022年のチョウ相を追加的に説明するか。**

- 51島を固定し、**港×植物種×記録年×データセット**を再取得して、同じ港・半径・年・最低植物記録機会に限った比較にする。植物の「GBIF未索引」は「不在」ではない。
- M0：地理距離＋以前の蝶相＋一般植物のJaccard＋植物/蝶の観測努力＋気候/島属性。M1：M0＋**同じ港の適合外来候補寄主Jaccard**。帰無は島ノード依存・海域、植物の地理的出現頻度・調査努力を保持。先に比較単位を固定し、採用島数を報告。
- このM1の付加価値が消える場合でも「港周辺の記録植物と蝶相の正の空間共変動」は観測事実として維持。**寄主としての生物学的特異性**は主張しない。残った場合でも港輸送・実際の寄主利用・定着・島間リレーを証明しない。
- **港固有の効果**を主張するには同一島・同一時期・同一半径の非港対照が別途必要。今の相関結果はその試験の代用にならない。
