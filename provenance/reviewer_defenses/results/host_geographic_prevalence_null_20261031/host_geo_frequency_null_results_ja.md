# 島での適合寄主の先行記録は、植物の記録地理を揃えると特異的でなくなる

2026-10-31｜chocho original230 ソース固定追加検証｜**肯定的結果を厳しく反証し、主張を適切に格下げした結果**。

元の採否を変えず、原寄主ネットワーク**2,396辺**、2011–2017年の蝶初索引**113件（60種・17島）**、2001–2010年の植物索引種キー×38港を固定。先行する適合寄主の索引記録があった蝶イベントは**34/113 = 30.09%**。この記述的な肯定結果は、追加の3つの帰無参照で評価した。

| 帰無参照 | 植物の条件 | 期待する先行寄主重なり割合 | 観測30.09%以上の置換 |
|---|---|---:|---:|
| 旧・植物科＋原HOSTS寄主次数のみ | 全ネットワークの植物種の空間被覆を一致させない | **25.25%** | **10/299** |
| 新・地理的出現頻度を保存 | 上記＋植物が17島中**0島・1島・2–3島・4島以上**に記録された区分を固定 | **30.00%**（帰無95%範囲 27.4–32.7%） | **293/499** |
| 新・地域プロフィールも固定 | 上記＋6つの島群の**どの群に植物が索引されたか**を固定 | **30.26%**（帰無95%範囲 28.3–31.9%） | **356/499** |

**中心結論：「適合寄主とチョウ記録の先行共記録は観測された」が、「植物科・寄主数を保つ素朴な帰無より多い」という超過は、植物の地理的な索引されやすさを保つと消失した。** これは植物の実際の同島資源量が定着を改善した証拠ではない。植物の共通な空間的利用機会／GBIF調査被覆／広く利用される寄主植物という競合説明が残る。

## 機構の識別と5年間の後続記録
- 従前の初索引後5年以内の蝶の再索引は、先行適合寄主の索引あり **26/34 = 76.5%**、索引未確認 **70/79 = 88.6%**。生の差 **−12.1ポイント**。未確認は**生態的寄主不在ではない**。
- 地理頻度マッチの帰無における再索引差の平均は **-7.9ポイント**で、観測差以上は **485/499回**。地域プロフィールまで揃えた帰無では平均 **-11.6ポイント**、観測差以上は **381/499回**。どちらも**寄主に独立した再索引促進効果は確認できない**。
- 全蝶種で「寄主がないから蝶が定着しない」とする説明も支持しない。真の生存、繁殖、到来年、港経由の輸送、地域別の植物外来性は測っていない。

## 統計と再現性に関する診断
- 6地域島群の構造は元14近隣島ペアから固定。地理的出現頻度は**前期2001–2010の植物種キー×島集合**から計算、後期蝶記録を参照しない。植物科・蝶寄主次数・植物寄主次数・蝶×植物科次数を各置換で保存。地理頻度区分ごとに入れ替えた植物の分類を超えない。
- 地理頻度マッチの受理置換は **1,990,037回**、地域プロフィールマッチでは **1,941,445回**。置換可能な元リンクはそれぞれ2232/2396、2157/2396で、全リンクが自由に置換されるわけではない。帰無スコア系列のlag1自己相関は約0.015、0.018。**499 MCMC drawを499の完全独立な生物学的反復とはみなさない**。
- 今回も植物を**実際に昆虫が利用したことは確認していない**。植物の原記録地は2019 WPI港周辺の5kmであり、島内の全植物・港外生息地や標本提供者・気候・船便輸送量・歴史的移入年を含まない。歴史的植物の索引は植物の当地における生物学的起源・豊度を示さない。
- 著者専用の原HOSTS 2,524辺・元発生座標は公開せず、4つの固定Action artifactから元解析を実行し、原の既存ネットワーク帰無 **10/299** を同じ実行で再現した。保存済み名称照合表は受理植物種キーのみで蝶との寄主辺を含まない。
