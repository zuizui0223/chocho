# 港から運ばれた外来寄主は、島をチョウの生態的中継地に変えるか

## 最新の実測・接続監査（2026-10-30 後続作業）

- **先行植物の記録機会**：51島・194港の2001–2010植物記録を固定1,275島ペアへ接続。両島で一般植物記録が各1件以上ある共通新規チョウ組は800/1,163、先行する適合寄主の両島での一致は5/800。各島の最大港記録が100件以上でも4/189。**初期植物記録ゼロだけで寄主一致の少なさは説明しきれない**が、植物種ごとの記録不足と種組成・努力偏りが残る。[記録適格性結果](../early_botanical_observation_support_20261030/early_botanical_opportunity_results_ja.md)。
- **記録偏り**：194港の早期植物検索件数合計155,002のうち117,356（75.7%）が島ID15の39港に集中。港の検索圏は重複し得るので独立植物観察数とはしない。全島・全種の寄主効果には未昇格。
- **船で運ばれた種子と寄主**：2020年の冷蔵コンテナ散布体の主要4分類群と、現在の港外来寄主候補を照合。*Phragmites*（属）の接点と *Saccharum* の異種の接点はあったが、焦点4群に同じ種として輸送を裏付けられる一致は0。先行寄主4植物種の移入経路は未確認。[輸送経路・分類照合](container_seed_host_crosswalk_results_ja.md)。
- **近隣島中継の候補**：先行寄主一致の5チョウ×島ペア中3組は港代表地点間101–111 kmだが、2011–2017追跡表では各組の片方の初記録年が不明。両島の初年と前島の再記録が時間順に確認できる唯一の組（*Vanessa cardui*）は港代表地点間18,478 kmで、近隣島中継の証拠ではない。[時空間の接続監査](directed_island_chain_screen_results_ja.md)。
- **次の実データ障壁を最小化**：近隣候補の欠けた初記録年だけを、ローカル原年表 `work/barriers/global_original_species_island_year.parquet` から解決する[厳格な年表復元スクリプト](resolve_original_island_chain_years.py)と合成データテストを作成。PR公開データに当該原Parquetがないため、**原年表からの実測再判定は未実行**。この未実行を「他方の記録が2018年以降」と補完しない。

**現在の結論**：港由来の植物が近隣島への中継を促進する可能性は反証可能な問いとして具体化したが、輸送種子の同一性、先行寄主による存続、次島への供給源を直接つなぐ共同データは未取得。旧GEB本論文の結果を変更せず、PR #104探索支線として保持。

## 1. 元座標で確認済みの長距離記録と島の役割候補

以前の島記録からの長距離記録は、前期・後期の調査機会が揃ったコホートでも残っている。

| 観察コホート | 全島上初回記録 | 最近接過去記録地から500 km以上 | そのうち最近接過去記録が島上 | 100 km未満で最近接過去記録が島上 |
| --- | ---: | ---: | ---: | ---: |
| 全て | 12,028 | 350 | 206 / 350 (58.9%) | 6,035 / 10,551 (57.2%) |
| 過去の記録機会あり | 3,813 | 174 | 108 / 174 (62.1%) | 1,674 / 3,153 (53.1%) |
| 過去・後続の記録機会あり | **3,136** | **164** | **104 / 164 (63.4%)** | **1,309 / 2,529 (51.8%)** |

過去・後続の観察機会がある群では、500 km以上の記録ギャップの最近接過去地点が島である割合は、100 km未満群より**11.7ポイント高い**。ただし全記録では差が**1.7ポイント**と小さく、観測機会で対象を制限すると大きさが変わる。別種・別海域・別年代・記録密度の構成をそろえた推論ではなく、通常の独立事例としてのp値は付けない。

**「島が中継地」の証拠ではない。** 近い過去のGBIF記録地が実際の供給源だった保証はなく、同じ記録過程の空間的偏りがある。500 kmは最寄り過去記録地との距離で、蝶個体の飛翔距離ではない。今回の有益な発見は、長距離・両期間記録機会あり・最近接過去記録が島という具体的な検証候補が**104件**ある点。

## 2. 先行寄主植物が確認できた箇所

別の51島、82種、2011–2022新規記録の共通蝶×島ペア**1,163件**について、現代の港寄主リストと前期の港寄主リストを区別。

| 植物の参照期間 | 対応する種×島ペア |
| --- | ---: |
| 2001–2024（蝶記録より後の植物を含む） | **208 / 1,163 = 17.9%** |
| 2001–2010（蝶記録前の候補） | **5 / 1,163 = 0.43%** |

先行する寄主の記録がある5組は、**5蝶種・7島、延べ10種×島端点**。独立した2011–2017初回記録の5年間追跡データには端点6件があり、その6件は後年にも記録され、5年目の記録は2件だった。これは後期に記録され両島で共通する蝶・寄主のセットから事後選択された、極小かつ非独立な集合。**「先行寄主により定着成功率が高い」という比較は一切できない**。残り4端点が追跡CSVに無いのは、このCSVが2011–2017初回記録に限定されるためであり、後続記録がなかったことを意味しない。

なおここでの前期一致も港の検索圏で植物が記録されたという事実のみで、その島で同種が2001–2010年に外来だった、コンテナで運搬された、自然条件下で繁殖資源となった、という証拠ではない。

## 3. 単純な港主効果と別の構造として検証する

港植物との統合ができた別の2011–2017年島上蝶初回記録追跡は5,665件。そのうち**332件（5.9%）**だけが2001–2024年集約の港寄主区分に対応し、残り5,333件は未評価。これは2011–2017年時点の寄主存在証拠ではない。歴史的2006–2010年定期船接続性と完成した港植物記録が重なるのは39港・27島で、従来の51島内では21島。港名一致の地理的同一性は別途検証が要る。

独立に必要なキーは、蝶種・島・年・最初の観測機会・次の観測機会、寄主植物種・島・年・当時の外来区分、港・当時の船便または貨物/検疫、次の島の観測努力。同じイベント単位で**「先行する寄主」×「500 km以上の過去記録ギャップ」×「複数年再記録」×「後続島記録」**が交差するデータは、現在公開済みの派生スナップショットでは得られない。別の集計コホートを合算した係数・p値は禁止。

## 4. 最初の識別可能な機構テストの設計

**最も重要な差の差：** ある島・年代で外来寄主植物が独立に検出された後、その植物を**実際の寄主リストに持つチョウ**の後続の新規記録・複数年再記録が、その植物を寄主にしない比較可能なチョウより増えるか。さらに隔離の大きい島で差が強まるか。これなら「港が発達したら全蝶の記録が増えた」という観測努力・市街化だけの説明に対して、寄主特異的な反証がある。

ただし植物初回記録は導入年ではなく、同時期の調査努力増加により植物とチョウの両方の検出が増える可能性がある。事前の植物記録年、年別観測日数、提供者、同じ島の非寄主植物の初回記録という負の対照を要する。寄主の位置が港内か別の港から離れた場所か、非港の市街化沿岸かも分ける。

続いて同じ種の島iでの複数年記録とi→jの次の島での新規記録を、実際の海峡距離・大陸由来の代替経路・観測履歴で比較。**前の島が見つかったことと、本当にその島が次の移入源だったことは別**。船による蝶自身の直接輸送も競合機構とする。

## 残る入力と停止線

**最優先で不足するもの**：原座標と年月を保持した植物の島×年・港/非港の対応リスト（特に104件の長距離・近接過去島候補の周辺）、当時の当地における外来区分、実際の航路/積荷/植物検疫の独立証拠。現代の港2019位置・土地被覆2021・2001–2024一括植物リストを過去の説明変数に流用しない。

コンテナ吸気グリルに付着した植物散布体が直接確認された実証例は存在する（Scientific Reports 2020, https://www.nature.com/articles/s41598-020-71954-3）。ただしその実証例の**30分類群**が本研究の島・蝶の寄主に対応するかは未検証。船体汚損、貨物への混入、園芸目的の持込みも異なる経路。今回のGBIFデータから個別の種子輸送経路を推定しない。
