# 近接島ペアでの蝶記録の時間順：寄主特異性を主張する前のベースライン
2026-10-30｜PR #104｜後続の実測（非公開原Parquet、公開1,275島ペアCSV）

**問い**：2001–2010年の適合港寄主が両島で確認された3つの近隣蝶×島ペアで見えた「前の島に再記録→後の島で初記録」は、近い島々の共通新規チョウにとって一般的なのか？

## 公開済みペア地理×原年表の独立集計
公開 `island_host_network_pairs.csv` の1,275島ペア（Git blob `5663d2ffe42419f5c4496b92c9f3bbf76175907b`）から、港代表地点間の大円距離が **200 km未満** の14島ペアを固定。ユーザー提供の原 `speciesKey×landmass_id×year` Parquet（SHA-256 `8362ec4538d28916b2f9aaf98d1512b343b15f8f2eefe060ee61798c9a67406f`）を224種で再構成し、両島の初索引年がともに2011–2022年となる蝶×島ペアを数えた。結果は**14島ペア中12島ペア・計41件**。各島ペアの共有新規種数は公開CSVの14行と完全一致。

| 観測される年順 | 公開前期寄主リンク付き焦点 | それ以外の同じ近接島ペア群 |
| --- | ---: | ---: |
| 両島で新規記録がある | 3 | 38 |
| 両島の初記録年が異なる | 3 | 33 |
| 先の島で初年以降・5年以内に再記録され、**後の島の初記録より早い** | **3/3** | **18/38（47.4%）** |
| 後の島でも初年から5年以内に再記録 | 2/3 | 24/38 |

距離60–150 kmの「その他」16件でも8件（50.0%）が先の島の再記録→後の島の初記録の順序を持つ。これは**記録順序そのものが珍しい固有の寄主メカニズムの証拠ではない**ことを示す実測ベースライン。

## これを寄主効果の検定にしない理由
- 焦点3件は、先行寄主が両島で確認された**事後選定の5件から、近隣だけを選択**したもの。島276を共有し、*Colias*2種は同じ169–276ペア・同じ*Medicago sativa*。独立3サンプルではない。
- 「その他38件」は**寄主なし群ではない**。過去の植物記録が足りない、宿主ネットワーク対応が異なる、由来未確定などが混在。両群の島・種・年・観測量は未マッチ。3/3 vs 18/38の有意性検定や因果的差・リスク比は禁止。
- 完全に同じ2島ペア（169–276、276–715）では、焦点3種以外に両島で2011–2022年に新規記録された蝶はない。厳密な同島ペア寄主陰性対照が作れない。
- 両島の初記録時差は観測活動の差でも生じる。初記録＝生物学的初到来でも、再記録＝定着でもない。港間距離は航路ではない。

**実質的な新規結果**：欠けていた島の年が解決できた後に、同距離帯の固定全島ペアについて時間順序の普遍性を測定した。これでH3の単純な存在主張は反証可能になったが、**寄主を介した中継促進というH3の機構は未立証**。

[集計とソース検証用JSON](near_island_record_order_baseline_20261030.json)。全41の種×島×年行、元座標、非公開原Parquet、restricted host catalogue edgesは公開していない。CIは公開ペアの母集団・各ペアの種数・集計整合性をチェックし、非公開原年表の直接再読込ではない。

**次の主線**：前期寄主の上流・下流の同じ島・年での存在証拠、実船便または検疫記録、同種についての直接大陸到来 vs 先行島の時系列予測の比較。欠測を植物不在／移動不在に変換しない。
