# 蝶の既知寄主植物は港中心にあるか：年代付き5km・1km・非港の照合

2026-10-31 | chocho PR #116 | **蝶の後続記録を主語に保つ、港という媒介仮説の実測監査**

## 結論

**植物が蝶の初記録より14〜19年早く「港から5km以内」に索引されていたという従来の肯定的結果は保持する。しかし、同じ植物が「港中心1km以内」に索引されたという結果ではなかった。** 同じGBIF索引・2001–2010年・空間中心・品質条件で半径を1kmと5kmに切り替えて再照会すると、対象**11植物×港**の全組で**5km以内に記録あり、1km以内には記録なし**。従って観測植物は検索半径1〜5kmの範囲に索引されている。**11組は互いに独立する移入事例ではない**。各港半径が重複し、実記録数も少ない。

加えて、同島の港から5km以上離れた非港沿岸1km地点では、*Alnus incana* を島276の**2地点**で索引できた。これは「港だけに存在する寄主」という説明の対照となる。ただし未索引は植物不在ではなく、**島への移入、船舶随伴、繁殖・定着、実際の幼虫摂食や島間中継は未実証**。

## 既存蝶×寄主を新しい空間データへ直接接続

元の著者寄主ネットワークから過去に公開・検証された3蝶リンクと2植物の分類名・受理種キーを維持。元の**5km圏植物種キー×年**を原年表蝶初索引年と照合した4植物×島の独立した文脈について、今回新たに同じ2001–2010年の**1km港・1km非港**を比較した。

| 既知寄主・島 | 対応蝶 | 植物最初の索引 / 蝶最初の索引 | 同じGBIF再照会：港1km | 港5km | 非港1km |
|---|---|---|---:|---:|---:|
| *Medicago sativa*・169 | *Colias croceus*, *C. hyale* | 2002 / 2019 | 0/2港 | **2/2港** | 0/4地点 |
| *Medicago sativa*・276 | *C. croceus*, *C. hyale* | 2001 / 2015 | 0/4港 | **4/4港** | 0/8地点 |
| *Alnus incana*・276 | *Nymphalis antiopa* | 2001 / 2015 | 0/4港 | **4/4港** | **2/8地点** |
| *Alnus incana*・715 | *N. antiopa* | 2002 / 2021 | 0/1港 | **1/1港** | 0/2地点 |

- GBIF受理植物キー：*M. sativa* **9151957**、*A. incana* **9148577**。2種の *Colias* は寄主・島・先行記録年が同一なので6蝶種×島端点は4植物×島の独立事例ではない。
- 植物の1km内未索引は、港側も**当時ほかの植物種が索引されていた**地点で起こっている。一方、元の5km検索の範囲は大きく、自然/都市/農地等を混在させる。
- 新鮮なGBIF検索では*Alnus*島276の港5km圏は**3、2、1、1件**（同一の記録が複数円に入る可能性あり）、島715は2件、*Medicago*島169は1、1件、島276は2、1、3、1件。植物が広く多数生育したと推定しない。
- 各港の1kmと5kmを同一APIで再照会し、1km植物不索引が以前の索引年代・データベース変化だけによる見かけの違いではないことを確認した。これは原5km索引の再取得を意味し、原記録の初到達・導入年を証明しない。
- 非港沿岸2地点は元GSHHG 2.3.7の同一島でWPI港から5km以上の地理的対照として固定されているが、未カタログの小港や人為植栽がないとは保証しない。

## 生態学的含意と次の検証

この結果から言えるのは、**港の外来寄主植物が最初に港の直近へ定着したという前提は、対象とした正の3蝶リンクの実測によっては支持されない**ということ。一方、海上輸送で運ばれた植物が港周辺1〜5kmへ分散・植栽された可能性は排除できない。港から離れた沿岸記録だけでは輸送由来の立証はできない。

本来の蝶の分布拡大仮説を検証する次の主要条件は、(1) 植物の**当時の島別在来/外来判定**、(2) 元の蝶×島×年**未索引リスク集合**と努力情報、(3) 寄主の港/非港の空間分布を本土直行・海上隔離・移動性と競合させた**後年の蝶記録予測**。5km圏での初植物索引と後年の蝶初索引だけから「植物の中継→蝶定着→別島への中継」を結論しない。
