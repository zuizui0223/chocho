# The five larval-label / added-host country cases map to eight source-recognized introduced plants

**21 October 2026; source-bounded first step of a genuine spatially matched
butterfly–host analysis.** A separate GitHub Actions run restored the original
author-only HOSTS/WCVP/BCE/CHELSA archive using the **fixed exact ZIP
SHA256** and reconstructed the 239-butterfly resource model, without altering
its host links. It then independently matched **all 48 positive
butterfly×country cells** to the existing country-WGSRPD3 material/guard
geographical design: **26 positive added-host flags reproduced and 22
non-added**. No individual plant or butterfly location was used to select
the five cases.

| *Papilio demoleus* | Haiti | Same six accepted species | 6 |

**8 unique source-defined candidate plant species; 20 source-listed
butterfly×country×plant links.** Each source name was a single
accepted WCVP botanical binomial; none has yet been independently resolved
against the current GBIF species taxonomy or confirmed to be recorded
within these countries. The six `Papilio demoleus` plants repeat in three
Caribbean countries *by botanical range coding*, not by actual
observed local presence. The `Colobura dirce`–`Cassia fistula`
source link requires **independent host-use validation** before any
ecological conclusion; HOSTS record membership alone does not confirm
successful feeding. Similar source caution applies to every edge.

## What this establishes—and does not

The country-level resource-opportunity classification has been reproduced
directly from WCVP accepted host identities and fixed country→WGSRPD3
links rather than reverse-engineered from butterfly results. This is
the necessary source-taxon bridge for the next *matched subcountry*
GBIF plant-occurrence validation.

An introduced host recognized somewhere in the matching WGSRPD3 region
need not occur in the GADM1 province where butterfly larvae were
recorded. A plant present in GBIF may be cultivated, outside the
actual encounter season, host-inaccessible or unsuitable for larval
development. HOSTS/WCVP acceptance does not provide verified
same-site egg/larval host identity or fitness.
