# 17島の先行寄主記録超過は、地域を保存しても残るか

2026-10-31。元の230蝶種・2,524件の著者用寄主辺、GBIF受理植物名、2001〜2010年の38港植物種記録、2011〜2017年の蝶初索引を固定し、**113蝶種×島イベント**に対して地理的な帰無を実測した。植物原座標・非公開寄主辺は再配布しない。

## 今回の新しい結果

| 帰無モデル | 先行する適合寄主の平均 | 観測34件以上の抽出 |
| --- | ---: | ---: |
| **観測** | **34/113（30.1%）** | — |
| 蝶種と島の記録数を保持し、地域に関係なく入替 | 28.19/113（24.9%） | 49/1497（3.27%） |
| **6つの近隣島群の内部で入替**（蝶種×島群の記録数も保持） | **28.69/113（25.4%）** | **83/1497（5.54%）** |

地域内帰無の記述的95%抽出範囲は23〜35件で、**観測34件はその内部**にある。「実測が構造帰無よりやや多い」という方向は残るが、**地域ごとの蝶記録構造を保持すると明確な超過とは言いづらい**。299回の原寄主ネットワーク植物科/次数保持帰無では10/299回が観測以上だったが、今回は元の植物-蝶寄主ネットワークは固定し、**蝶種×島の記録割り当て**を移動した。異なる条件付き比較であり、2つの値を独立に掛け合わせない。

## 品質・限界

- 蝶種ごとの総記録島数・島ごとの新規記録蝶種数を固定。地理内帰無はさらに蝶種×島群の件数を固定。島群は6成分、島数2・4・5・2・2・2。
- 各条件で乱数シード3本×499回＝1,497回の置換を取得。地域内で観測34件以上はチェーン別27・30・26回。平均28.72、28.69、28.65件。標本のlag-1相関は−0.066、+0.015、−0.006。いずれもMCMCの正確な混合・独立抽出の証明ではない。
- いずれも実際の蝶移動、港での寄主導入、幼虫寄主利用、繁殖・定着の測定ではない。植物の非索引を生物学的な不在に変換しない。気候・微環境・提供者努力・大陸からの直接到着も未調整。
- 初索引後5年間の再記録を促進するというH2仮説も前段で支持されず（寄主先行索引あり26/34、索引未確認70/79）。今回の地理固定帰無は**重なり**を検定し、再記録促進を検定するものではない。

結論：**先行寄主の記録と蝶の島記録には、構造的な一致が存在する。ただし地域や記録条件を固定したうえでの独立した寄主資源効果はまだ確認できない。**
