# 共通上位食草：食草資料による感度比較

上位6種の49利用関係は42組が既存HOSTS表、7組がBCE追加候補だった。地域数等の条件を満たして相関を計算できた24組のうち、追加候補は4組。これらを外して相関の種間平均を再集計した。新しいモデルを学習した結果ではない。

|食草|全資料：種数／平均ρ|既存HOSTSのみ：種数／平均ρ|
|---|---:|---:|
|Capsella bursa-pastoris|2 / +0.639|2 / +0.639|
|Hesperis matronalis|5 / +0.052|4 / -0.003|
|Malus domestica|4 / +0.013|4 / +0.013|
|Medicago sativa|9 / +0.017|6 / +0.056|
|Plantago lanceolata|2 / +0.550|2 / +0.550|
|Robinia pseudoacacia|2 / -0.276|2 / -0.276|

アルファルファは既存HOSTSのみでも平均がゼロ付近で、強い共通の正方向は現れなかった。Hesperis matronalisも同様。ナズナ・ヘラオオバコの正の相関と、ハリエンジュの負の相関は、今回のBCE追加候補の有無では変わらない。ただしこれらは各2種しか解析できていない。

既存HOSTS由来であることは、その地域での幼虫の利用や発育成功を確認したことを意味しない。植物は2001–2024年の集約記録であり、2015–2018年から2019–2022年のチョウ記録変化に先行した資源とは限らない。結果は記録された地域内の未補正の探索的関連である。
