# 上位6食草の利用関係：資料の由来

上位6種について、現在の食草―チョウ対応を元のHOSTS受理名表とBCE追加候補に照合した。全対応の由来は追跡できた。ただし由来が確認できることと、現地で幼虫が利用していることの確認は別である。

|食草|対応数|既存HOSTS表|BCE追加候補|
|---|---:|---:|---:|
|Capsella bursa-pastoris|6|5|1|
|Hesperis matronalis|5|4|1|
|Malus domestica|5|5|0|
|Medicago sativa|20|17|3|
|Plantago lanceolata|6|4|2|
|Robinia pseudoacacia|7|7|0|

資料全体は潜在的な幼虫資源の再構成として提供されている。手元の受理名表には個別の発育段階・摂食観察・発育成功・原著の判定欄がないため、各対応を独立した野外摂食確認としては扱えない。BCE資料自身も、受理植物名への対応は幼虫の摂食・発育・産卵を独立に保証しないと明記している。成虫訪花の混入が確認されたわけではない。

例：Argynnis paphia–Hesperis matronalisは手元のHOSTS表に存在する。Pieris brassicae–Medicago sativaは同表に見つからず、追加候補の由来を持つ。直感で削除せず、個別種の機構の主張前に原典の確認対象とする。

したがって前の図は、資料上の潜在的利用関係を介した記録分布の探索的照合である。特定の食草がチョウの拡大を駆動したという証拠ではない。
