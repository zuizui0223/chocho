# 上位の共通食草とチョウの記録変化：探索的照合

港で外来食草候補として記録された上位6種について、利用関係のあるチョウの地域別記録変化と照合した。2015–2018年から2019–2022年への標準化記録確率の平均変化を使用。地理的な分布面積の増加や定着を直接測ったものではない。

食草が外来候補として1港以上で記録された地域に限り、その食草が記録された港の割合と、チョウの記録確率の変化を種内で順位相関にした。各地域5メッシュ以上・各チョウ5地域以上。植物は2001–2024年の記録をまとめており、拡大前の資源供給や将来予測の検証ではない。

|食草|解析可能なチョウ種数|種別相関の平均|正の相関の種数|
|---|---:|---:|---:|
|Capsella bursa-pastoris|2|+0.639|2|
|Hesperis matronalis|5|+0.052|3|
|Malus domestica|4|+0.013|2|
|Medicago sativa|9|+0.017|5|
|Plantago lanceolata|2|+0.550|2|
|Robinia pseudoacacia|2|-0.276|0|

アルファルファは9種で方向が分かれ、共通した正の関係は見えない。ハリエンジュは解析可能な2種とも負だった。ナズナとヘラオオバコは正だが各2種に限られ、共通機構の証拠には足りない。上位種の広がりや利用するチョウの数だけから、拡大を促す食草と結論できない。

全体の食草モデルで予測が改善したことは、これら個別の食草の効果が確認されたことを意味しない。今回は未補正の探索的相関であり、共有する地域や他の食草、港の観測被覆、気候・土地利用との共変動が残る。無記録地域を不在として追加していないため、記録された地域内での条件付き比較である。

相関全72件を順位のPearson相関として再計算し、要約値を照合した。
