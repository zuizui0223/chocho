# 港湾植物相の栄養選好とチョウの寄主候補：一般植物対照・独立島監査

2026-11-02 · [chocho Draft PR #122](https://github.com/zuizui0223/chocho/pull/122) · **探索解析、GEB/JBI原稿への昇格なし**

## 新しい答え

全球の「栄養豊富な立地を好む外来寄主候補ほど、多くの港で索引される」という正の結果は保持する。既存の182種の全球GBIF記録国数・記録件数を条件づけても、偏順位相関 **+0.210（属単位再標本化95% +0.065〜+0.348）**。

局所的な港効果は別。今回、**同じ島の港・非港の一般植物相を独立に取得して、寄主候補のN値とその他の植物のN値を同時に比較した。**

その結果、前期の比較可能な6島では港の**その他の植物相**が非港より好栄養性に偏る正の対応がある一方、**外来寄主候補だけに港優位は見られない**。しかし同一27ペアを保った前期→後期の植物索引組成では、寄主候補のN値がその他の植物に対して相対的に上昇する。観測記録構成の変化であり、栄養供給による移入や繁殖成功の証明ではない。

## 評価量と支持範囲

その他の植物は対象182種に含まれないN値付き植物で、蝶の**真の非寄主ではない**。対象182種とその他のN値付き植物を分け、個々のGBIF記録件数ではなく**異なる植物種を等重み**として平均N値を計算した。

`D = [N_寄主(港) − N_その他(港)] − [N_寄主(非港) − N_その他(非港)]`

最低条件：港・非港双方の一般植物記録≥30、各地点の対象寄主候補N値付き≥2種、その他の植物N値付き≥5種。ポートを島内で平均し、**島を独立の等重み単位**とする。

| 同一期間の港−非港 | 2001–2010（27ペア/6島） | 2011–2024（43ペア/18島） |
|---|---:|---:|
| その他の植物の平均N差 | **+0.1885**（95%再標本化 +0.063〜+0.316） | +0.1317（−0.096〜+0.380） |
| 外来寄主候補の平均N差 | +0.0110（−0.111〜+0.103） | −0.0728（−0.416〜+0.240） |
| 寄主候補−その他の植物：港と非港の差の差 D | **−0.1775**（−0.314〜−0.030） | −0.2045（−0.569〜+0.095） |

**前期の相対的な負の差（D）は、港のその他の植物が高Nに偏る一方、候補寄主はそれに追随しないため生じる。** 後期単独のDは不確かで、N値照合率≥10%の条件では +0.0034（−0.229〜+0.238）とほぼゼロになる。後期単独の「候補寄主が港で抑えられた」は頑健な結論として採用しない。

### 本当の同一地点・同一島を使った時間比較

両期間に十分な植物記録があるのは同じ**27港・非港ペア／独立6島**（GB2、DK2、FR1、SE1）。差の差Dの後期−前期：

- **+0.14936**、島等重み・再標本化95% **[+0.0526,+0.2518]**
- 6島すべて正方向、島符号置換の両側の名目値 **0.03125**。探索した複数の比較後の値であり、確証的p値ではない。
- 1島除外感度：+0.1099〜+0.1784。1島だけで生じた符号ではない。
- 観測努力の港/非港比≤5倍（26ペア/6島）で+0.1463（再標本化95% +0.0464〜+0.2518）。
- 両地点の植物種におけるN値照合率≥20%（24ペア/5島）で+0.1166（+0.0361〜+0.2382）。
- D変化の内訳はその他の植物N差が**−0.09825**、候補寄主N差が**+0.05111**。これらを差し引くと相対差 +0.14936。

地域的には6島すべてヨーロッパ。元27ペアのうち18ペアは英国の1島（地理ID 15）だが、集計では島ごとの寄与を等重みにした。**全球規模の時間変化への外挿はしない。**

## 実際の土壌窒素との接続：現時点で保留

[ISRIC SoilGrids 2.0の250m・0–5cm推定全窒素](https://maps.isric.org/generated/soilgrids/nitrogen.html)をWCS経由で港4・非港4地点に試した（[ソース検証](https://github.com/zuizui0223/chocho/actions/runs/41408816351)）。**8地点中7地点がゼロ値・欠測疑い**、1地点のみ正の値。陸上の別の3地点でも1地点がゼロ値、2地点に正の値があり、海岸の土地マスク・ソースタイルの影響と実測の土壌窒素ゼロを区別できない。生物学的なゼロに変換しない。したがって**土壌窒素の港−非港差・植物Nへの説明変数には採用しない**。ISRIC公式もREST APIの停止状態を告知しており、WCSの値でも直接の土壌測定ではない。

## 最終判定と主論文との接続

1. **保持する全球の肯定結果**：外来寄主候補のN値と記録港数との正の関連は、全球のGBIF記録国数・記録数で部分調整しても残る（182種、偏順位ρ+0.210）。
2. **追加の肯定的な地域パターン**：6島の前期の港で、対象寄主以外のN値付き植物相が非港より相対的に高N。さらに同一27ペアで寄主候補とその他の植物の相対的N構成が後期に向かって正方向へ変化。
3. **未解決の機構**：港湾の土壌N富栄養化、下水・大気沈着・肥料由来窒素、植物の真の移動、船による昆虫到着、幼虫の寄主利用、種の定着、他島への二次分散は実証されていない。GBIFで先行して索引されたことと生物学的先行性・不在は異なる。Ellenberg指標はドイツ中心の植物立地選好であり、各地点の直接的な栄養量ではない。
4. **追加解析の優先条件**：利用可能な植物N背景の面積/検出補正、港と同じ島の非港市街地・自然沿岸の区分、実測可能な窒素曝露、当時の外来性を独立に入れる。土壌グリッドのゼロ値が解けるまで地図の補間で代替しない。

元GEBの**+54.9%の潜在資源機会拡大**、155種の時間外予測改善（MSE−4.12%）、51島の外来寄主・蝶相の正の類似度相関（ρ+0.300）は維持する。解析単位が違うため、相互に否定・重複計上しない。PR #122は探索Draftを維持、元のGEB投稿原稿は変更しない。
