# 港湾の好栄養性寄主：記録努力と植物種数を揃えると結論はどう変わるか

2026-11-02 | [chocho Draft PR #122](https://github.com/zuizui0223/chocho/pull/122) | **探索・測定感度の追試。元GEB原稿は変更しない。**

## まず保持すべき発見

**全球の肯定結果は維持。** ドイツ由来エレンベルグN指標を厳密照合した外来寄主候補182種では、全球のGBIF記録国数・記録件数を順位残差で調整しても、植物の高栄養立地への選好と、記録された港の数に正の関連（偏順位ρ **+0.210**、属単位再標本化95% **[+0.065,+0.348]**）があった。これは*港記録の地理的関連*であり、港湾の栄養富化が原因であるという証拠ではない。既存GEB +54.9%潜在的資源増加、155蝶種の時間外予測精度改善、51島の寄主候補と新規蝶相の正の相関は引き続き独立した結果として保存する。

**新たな局所の観測パターン。** [種別GBIF植物記録の元データで監査した厳密な27港・非港ペア／欧州6島](ALL_FLORA_BACKGROUND_N_SOURCE_AUDIT_20261102.md)では、港対非港の「寄主候補の平均N−その他のN値付き植物の平均N」の後期−前期の差は、植物種を等重みにした場合 **+0.14936**（島再標本化95% **+0.0526〜+0.2518**）。独立6島の推定値は全部正だが、国を独立単位（英国・デンマーク・フランス・スウェーデン）とみなすと厳密両側符号の最小p=**0.125**。同じ27ペアのうち18ペアは英国の1島、港ペア等重みで+0.0746、島等重みで+0.1494という違いもある。

## 今回の新しい結果：GBIFの何を揃えるかで符号が変わる

[記録件数の均一抽出・植物種の入れ替わりの元解析](https://github.com/zuizui0223/chocho/actions/runs/41410195136)と、[10通りの記録件数・植物種数の標準化](https://github.com/zuizui0223/chocho/actions/runs/41410501626)を、凍結済み312地点×期間の植物種キーと記録数だけからオフラインで再実行した。新たなGBIF APIの取得はない。

各港ペアについて港・非港×前後期の4セル間で観測数を等しくし、植物種ごとのN値平均から27ペアの差の差を再計算する。植物種は1種につき1回の等重み平均、抽出段階だけを変える。「record」はGBIF記録数比例の非復元抽出、「species」は記録された種キーを等確率で抽出する。

| 条件 | 同じ6島を比較できた抽出の比率 | 島等重みでの平均N時間差 |
|---|---:|---:|
| 標準化なし／全植物種に等重み | 既存27ペア全て | **+0.149** |
| GBIF記録30件で標準化 | 0% | 判定不可 |
| GBIF記録60件 | 34.1% | −0.014 |
| GBIF記録120件 | 100% | **−0.094** |
| GBIF記録250件 | 100% | −0.038 |
| GBIF記録500件 | 100% | −0.007 |
| GBIF記録1000件 | 100% | +0.044 |
| 植物20種で標準化 | 0% | 判定不可 |
| 植物40種 | 26.1% | +0.215 |
| 植物80種 | 100% | **+0.136** |
| 植物160種 | 100% | **+0.128** |

299回／条件、全ての島で評価できた場合の抽出平均を記載。各シミュレーションの抽出誤差は大きく、例えば記録120件条件の2.5–97.5%は**[−0.882,+0.744]**、植物160種条件は**[−0.406,+0.704]**でゼロを跨ぐ。これは生物学的な信頼区間ではない。

前回の**399回×120記録**による独立検証でも、全島利用できた397回の平均N差は−0.081で、新たな299回の−0.094と同じ方向だった。

**読み方**：植物の種類を均等に見ると、寄主候補の相対的N選好が後期に高くなったパターンは概ね残る。しかしGBIFの**記録されやすい植物種に重みが強くかかる**抽出では、特に小さな標本で同じ符号にならない。したがって「実際の植物の量」「個体数増加」「実際の寄主の拡大」の測定へ格上げしない。説明されているのは、GBIFで索引された種名の構成である。

## 追加：記録植物の前後期の入れ替わり

同じ27地点ペア×欧州6島について、後期に記録されたN値付き植物種のうち**前期に未索引だった割合**（島等重み、非存在や移入を意味しない）：

| 種群 | 港 | 非港沿岸 |
|---|---:|---:|
| 全球の候補寄主182種に入る植物 | 25.7% | 29.7% |
| その他のN値付き植物 | 33.1% | 34.5% |

後期のみ索引された割合は対象寄主・その他双方で相当あり、港のみで明瞭に増えたわけではない。GBIFの調査やデータ供給の変化を含むので、新規記録を移入／実際の定着として扱わない。前期10年、後期14年と年数が異なることも残る。

## 生態学的結論と次の独立データの条件

- **保持する肯定結果**：全球の好栄養性外来寄主と記録港の広域的な正の対応（ρ+0.210、記録国・件数の部分調整後）。
- **保持する限定的な局所パターン**：欧州6島で、等重みの植物種組成上、寄主候補の相対的N値が時間とともに正方向へ移動（+0.149）。これは種名で測った現象そのものの記述。
- **強化された限界**：記録件数に比例したサンプリングでは符号が不安定。土壌の実際のN、下水放流、肥料、植物の現物増加、卵・幼虫、港経由分散・新規蝶の繁殖は未測定。ドイツ中心のN値を世界の土壌栄養量へ読み替えない。
- **識別条件**：GBIFの各時期の独立した調査努力・植物観測リストを含む同一地点反復、現地での確認や独立した植生記録、地域内の種群別データ、利用可能な直接的な土壌／窒素負荷データ。現行SoilGrids 0–5cm沿岸試行は8地点中7地点がゼロまたはマスク疑いのため、そのまま測定値にしない。

GEB/JBI本文へ機構的な主張として昇格させない。**現在の強いストーリーは「広域の好栄養性寄主の港湾記録」「欧州での記録植物群の相対変化」「GBIF観測方法での見かけの効果の変動」を区別すること。**
