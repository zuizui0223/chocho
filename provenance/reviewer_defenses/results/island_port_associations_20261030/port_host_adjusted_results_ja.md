# 港と導入食草：調整後の探索的関連

既存225候補・155解析対象種の島側から、種×島内に2セル以上ある対象を用いた。全島比較は93種・22島・975セル・49,509種×セル。137種・40島の記述集計全体と同じ対象ではない。単独セルの種×島は島内関連に寄与しないため除外。

2019–2022年の記録確率を応答とし、2015–2018年の初期値、前後期の観測日数・提供者優占度、起点の気温・降水量と傾向、農地・市街地・森林割合と傾向を調整した。種×島の固定効果と、種ごとの合計をそろえる重みを用いた。港位置は2019年版で、過去起点の予測ではない。

導入食草割合の主効果は種×島内で一定のため固定効果に吸収された。港との交互作用は、異なる食草割合を持つ種・地域で港距離の関連が違うかを表す。局所的な食草密度や資源供給の媒介効果ではない。

## 結果
- all_islands: 交互作用係数 +0.00387、二方向クラスタt近似95%区間 [-0.03733, +0.04507]。
- excluding_GB_Ireland: 交互作用係数 -0.01490、二方向クラスタt近似95%区間 [-0.10395, +0.07414]。
- stable_provider: 交互作用係数 +0.01894、二方向クラスタt近似95%区間 [-0.01461, +0.05249]。

すべての区間が0を含む。明確な共通の関連を確認したとは言えないが、関連がない証明でもない。空間ブロック数は全体18、2島除外15、提供者優占度差≤0.1の比較9。特に最後は区間推定が不安定。

二方向クラスタ共分散には小さい負固有値があり、各表示係数の分散は正だが、共分散全体を用いる同時検定は行わない。元の正規近似区間を残し、少数クラスタを考慮したt近似を追加感度分析として表示。空間依存が全て除去されたわけではない。

重み付き最小二乗係数は独立なnumpy解と最大1e-9未満で一致し、種×島内の中心化も確認した。これは数値計算の検証であり、生態学的な識別の保証ではない。

今後は非線形性、先行島の記録との関連、港近傍での地点付き食草記録、輸送情報を調べる。現結果だけでは自然分散と人為的持ち込みを区別できない。

補足：stable_provider は提供者優占度の前後差≤0.1という条件。提供者の同一性・構成の安定を保証せず、同じ優占度でも提供者自体が入れ替わる可能性がある。
