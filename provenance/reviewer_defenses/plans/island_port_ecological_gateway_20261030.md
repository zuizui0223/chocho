# 島と港を主役にした次の検証設計（2026-10-30）

**目的：** 現行PR #104の探索支線を増やし続けず、*島＝自然の到達障壁と潜在的中継地、港＝人為的な到達機会と局所的な環境フィルター*という二つの役割を、一つの反証可能な問いに統合する。

> **港は、自然に隔離された島において、寄主資源を集中・共通化する「選択的な入口」になっているのか？**
>
> 対立仮説：港周辺の食草記録とチョウ記録の対応は、同じ島の非港沿岸、島の既往チョウ相、近隣島、気候、土地被覆、記録努力を考慮すると消える。

これは既存の「港が近いほど新規記録が増える」という単調な主効果モデルとは異なる。輸送機会の増加と、樹林・草地の減少という逆方向の経路を区別する。港を無条件に有益とも有害とも扱わない。

## 現在使える実測証拠

- **島の履歴：** 元座標に基づく2011–2022年の島上初記録12,028件（205種、2,656島）。6,852件（57.0%）では最寄りの前年以前の記録も島上。ただし実際の島間移動を確定しない。
- **港の局所環境：** ESA WorldCover 2021の同一島・遠方沿岸対照に対し、港1 kmでは市街地+21.9ポイント、樹木−7.3、草地−6.1。208島・625港。対照の海岸線までの距離・地形は厳密には揃っていない。これは2021年の土地被覆の比較であり、過去の港開設効果でも食草量でもない。
- **港の植物：** 1,596港の2001–2024年完成済み種リスト中、外来食草候補を記録したのは1,150港、687植物種。港外の植物分布を同じ手順で採った比較ではない。
- **島ネットワーク：** 外来食草候補のある港をもつ島と原座標由来のチョウ履歴を結べる51島・1,275島ペア。食草類似性×2011–2022年新規チョウ組成はSpearman 0.300だが、既存チョウ組成との相関0.418の方が強い。食草植物は2001–2024年集約で後年の情報を含む。
- **年代制約：** 同じ51島・82蝶種・1,163件の共通新規記録について、食草を2001–2010年に限定した場合に記録確認できた対応は5件（0.43%）だけ。未記録を植物不在と解釈しない。
- **輸送制約：** 2006–2010年の港接続性と2001–2024年植物データを両方もつのは39港・27島、従来の51島に重なるのは21島。港名一致は座標で独立確認した港同一性ではない。2019年港一覧や2021年土地被覆を過去年の輸送説明変数として投入しない。

## 最初に確認したデータの重なり（既存公開派生CSVの同一landmass_idで計数）

既存の51の島ネットワーク対象島について、同一島の港-非港沿岸WorldCover比較が**1 kmで40島、5 kmで14島**ある。2001–2010年の港植物取得完了51島に対して、1 km植生比較と共通するのも**40島**。40島は新しい解析で自動的に適格と決めた集団ではなく、植物の「港対照」と歴史的記録努力の再確認が必要な**サポート候補**である。5 kmの14島に広げて見かけの支持を増やす操作はしない。

検算（公開派生データだけを利用）：

```python
from pathlib import Path
import csv
R = Path("provenance/reviewer_defenses/results")
def rows(rel):
    with (R / rel).open(newline="", encoding="utf8") as f:
        return list(csv.DictReader(f))
island = rows("island_host_network_20261030/island_host_network_islands.csv")
vegetation = rows("coastal_port_vegetation_20261030/coastal_control_vegetation_pairs.csv")
early = rows("island_dated_host_match_20261030/island_port_early_inventory_islands.csv")
eligible = {r["landmass_id"] for r in island if r["eligible"] == "True"}
v1 = {r["landmass_id"] for r in vegetation if r["near_radius_km"] == "1"}
v5 = {r["landmass_id"] for r in vegetation if r["near_radius_km"] == "5"}
e = {r["landmass_id"] for r in early if r["all_ports_complete"] == "True"}
assert (len(eligible), len(eligible & v1), len(eligible & v5),
        len(eligible & v1 & e)) == (51, 40, 14, 40)
```

## 一本の主線として進める段階

### 1. **第一優先：港は同じ島の非港沿岸より、対応食草を集中させるか？**

対象は前記の40島を出発点とする。港近傍と、同一島の離れた非港沿岸における**蝶225種の実際の対応食草種リスト**を、同じ探索半径・季節・期間・土地面積で取得・照合する。島内でも海岸線距離、標高、土地被覆、植物の観測努力とデータ提供者を明示してマッチング・調整。外来候補／在来候補／由来不明を区別し、観測未確認を不在としない。

**中心指標**は「同じ蝶が利用できる食草の種類・集合が港に特異的に集中するか」で、島を独立クラスタとして評価する。港近傍の非食草植物・在来一般植物を陰性対照に、植物の記録密度だけで増える説明を検討する。2021土地被覆と2001–2024集約植物を使った最初の比較は*現在の空間構造*に限定し、後期の蝶記録を予測する解析に流用しない。

**停止条件：** 植物と観測努力が港・非港で比較可能な島の実数と地理的分散を報告し、疎であれば島全体の一般効果を推定しない。観測数だけを増やして独立島数の不足を補わない。植物相を採った後で半径や島の採否を有利な方向に最適化しない。

### 2. 島は「中継地」か、それとも単に記録密度が高いのか？

別の固定された確認として、元座標の島上初回記録履歴を使い、**前年以前に同種が記録された島の有無・距離**と、過去の大陸記録からの距離を競合させる。近隣島の過去記録を使う場合は、その島でのチョウ一般の記録努力、地理的な候補島数、同種の過去記録件数を照合。種・年代・海域・検出努力を保つ参照を作り、後年の記録だけで事前の分布可能性を定義しない。

初回記録は「このデータで初めて見た年」なので、通過・繁殖・真の移入は測らない。既存の57.0%は記述比率であり、島が実際に中継したという帰無超過ではない。

### 3. 両者を接続：孤立した島ほど港での資源集中が重要か？

第一段階で港特異的食草が実証でき、第二段階で検出・距離の比較支持ができ、**チョウの初回記録より前に同じ島で食草が記録されている**場合に限る。種×島×年のリスク集合を作り、過去の距離障壁（大陸・島間）、過去の記録努力、独立した植物記録の先行性、港/非港の対応食草の差、交互作用を比較する。時間外および島をまとめて外す評価を優先し、異なる地域の島を独立に検証する。

帰無：港の植物と蝶の対応は、単純な島・地域の植物相、記録努力、観察された過去の分布で説明可能。
対立：**自然に孤立した島でだけ**、港特有の適合する寄主資源が後期の記録出現または5年再記録と追加的に対応する。

予測性能の増分と統計的関連は分けて報告する。港接続性は当該年代で有効なデータがある島に限り利用し、交通の影響を帰属できない場合は「港周辺の景観／資源構造」に主張を限定する。

## 成功条件・失敗時の結論

- 港と非港の食草集団に比較可能な差がない：港が島を横断した資源供給源という仮説は未支持。**都市化の特徴は残るが、資源・蝶への経路とは区別**。
- 港で食草が集中しても先行記録が乏しい：港周辺の**現代の機能的環境**として記述。過去の蝶拡大の原因とは主張しない。
- 過去食草→その後の蝶記録と、島の隔離との交互作用まで頑健：限定した島と年代での「selective ecological gateway」仮説を支持する観測証拠。ただし直接の移入・繁殖を識別するには現地・航路・実験データが必要。

**原則：** 元の225候補種を保持し、支援データ不足・分類未解決・植物記録なし・観測未実施を分けて保存。#104の既存否定結果と元の独立GEB論文は上書きしない。新しい探索は、この主線以外へ分岐しない。
