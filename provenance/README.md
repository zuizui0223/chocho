# Provenance

This directory holds execution, migration and superseded-analysis history needed for auditability but not for the paper's ecological narrative.

## Current provenance surfaces

- `SCIENTIFIC_ORIGIN_AND_HYPOTHESIS_LINEAGE.md` — discovery chronology, Q1–Q5 and inference-status lineage.
- `FIGURE_SOURCE_ARTIFACTS.md` — exact source artifacts and hashes for the five manuscript figures.
- `RELEASE_MANIFEST.md` — archival boundary for the v1 release.
- `migration/` — repository-split provenance and source commit snapshot.
- `workflows/` — historical workflow definitions required to audit frozen executions.

## Archive

- `archive/climate/protocols/` — superseded response-blind climate-test protocols.
- `archive/climate/bindings/` — superseded execution bindings.
- `archive/climate/audits/` — supporting diagnostic receipts not used as primary manuscript results.
- `archive/resource-development/` — early resource-reconstruction receipts retained only for development history.

Archived material is not an alternative model/specification library. It is retained only to document the path to the frozen current analyses.

Submission-facing files should not require readers to understand this history.
