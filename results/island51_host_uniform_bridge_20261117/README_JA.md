# 寄主植物が海の回路とチョウ相の関係をどこまで説明するか — 原51島の同一標本での検証（2026-11-17）

## 判定：寄主組成による完全な説明は支持されない

元の**51島／1,275無向島ペア**、同じ元の2011–2022年のチョウ初回索引群集Jaccard、同じ2001–2010年の先行索引群集Jaccard、2001–2024年の外来寄主候補Jaccard、元のGSHHG均質海域Circuitscape型の無向抵抗を、**一行も再索引せず**比較した。元の数値ソースは[CI #42193019385](https://github.com/zuizui0223/chocho/actions/runs/42193019385)の保存artifact **#13490383689**、元の結果が分かる前に固定した島の経度ブロックは[CI #42325176725](https://github.com/zuizui0223/chocho/actions/runs/42325176725) artifact **#13554313981**。両者の原CSVはSHA-256を固定し、ソースを取り違えると実行時に停止する。

**新しい4モデルの同じベース**：
- B：大円距離のlog1pとその二乗、元194 WPI港の各島のlog1p港数の和・絶対差、**後期2011–2022チョウ相**の応答についてのみ**前期2001–2010チョウ相Jaccard**。
- BU：B＋**均質GSHHG海域の無向電気抵抗**（原本で正規化済み）。
- BH：B＋**同じ島で候補として記録された外来幼虫食草の種組成Jaccard**（2001–2024年をプール）。
- BUH：B＋両者。

推定は既存の**OLS・学習ペアだけで標準化・[0,1]への予測値クリップ**。モデルを入れ替えても植物・チョウの元データ、51島、1,275ペア、港の母集団194、海域端点182は固定。追加の気候・記録努力・現代の寄主種数制御を後付けで「完了済み」と呼ばない。

## 1. 51島を1つずつ未知にする既存評価（LOIO）

| 後期チョウ相のモデル | 島等重みのMSE | Bからの改善 |
|---|---:|---:|
| B | 0.006797761 | — |
| BU（海の回路） | 0.006452306 | **+5.082%** |
| BH（外来寄主候補） | 0.006515128 | **+4.158%** |
| BUH（回路＋寄主） | **0.006305452** | **+7.242%** |

- B→BUの+5.082%とBU→BUHの+2.276%は、**2016年ではなく既存の2026-11-06の原本結果と数値誤差1e−12以内で一致**。
- 先に寄主組成を入れたBH→BUHでも、海の回路の追加は**+3.218%**、**35/51島**でMSE低下。49...ではなく元の51島全てを残した。
- 後者の**51島を再標本化する記述的95%区間は +0.513〜+5.763%**、4999回。BU→BUHの外来寄主の残余増分+2.276%の記述区間は**−1.371〜+5.490%**でゼロをまたぐ。
- 絶対MSEで、回路単独の減少分は **0.000345455**、寄主を含むと残る回路増分は **0.000209676**（約60.7%）。差の約39.3%を**「植物による媒介率」や生態学的な因果寄与と呼ばない**。特徴量の重複・学習・クリッピングなどに依存する予測誤差の差である。

## 2. より厳しい「両島とも未知」の15地域ブロック評価

元の51島を結果に触れずに経度順で**11/10/10/10/10島**の5群に固定し、15組のブロックペアで全1,275無向ペアを**1回だけ**テスト。学習にはテスト両島の属するブロックが含まれない。これは同一個体群で評価を厳しくしたもので、独立した新しい島集団ではない。比較は全ペアの平方誤差平均に基づく。

| 後期チョウ相 | Bからの相対MSE改善 |
|---|---:|
| B＋海の回路 BU | **+12.345%** |
| B＋外来寄主 BH | +1.088% |
| B＋両方 BUH | +11.175% |

寄主を先に入れたBH→BUHでは回路追加 **+10.198%**。逆に回路を先に入れたBU→BUHでは寄主追加が**−1.335%**、すなわち悪化する。**群内235ペアではBU→BUH +2.268%だが、異なる経度群の間の1,040ペアでは−4.062%**。寄主による予測の地域外転移は一様でない。

**前期2001–2010年のチョウ相**を応答にすると、同じ厳しい評価でB→BUが**−10.680%**と不利、BU→BUHは**+5.791%**。異なる年代の索引群集は検出史・構成・地理的被覆も異なるので、これを海流輸送の歴史的な変化と解釈しない。

## 3. 生態学的含意と主張の境界

1. **同じ蝶々×51島の母集団で「海の回路と外来寄主の補完性」を実測予測で示せた**。LOIOでは両方の説明変数を入れた方が単独より有利である。
2. **回路の情報は寄主候補の類似だけでは消えない**。寄主による完全媒介説は支持されない。ただしこれは*媒介の反証実験*ではなく、説明変数を入れ替える予測比較である。
3. **寄主の追加情報は地理的な転移で不安定**。未知の両端の異なる経度群ではむしろ悪化。海の回路は地理的・生物地理的・観測的な情報を代理する可能性を保つ。
4. **比較がまだできていないもの**：同じ51島でのWCVP**外来植物相全体**と、外来のうち**真に当地の幼虫が食べた寄主**の分離。今のHは元の港付近の**候補**であり、報告された局所食害や繁殖を測らない。
5. 最重要の時間整合制約：候補寄主は**2001–2024**の植物記録の集合で、**2011–2022**のチョウ応答より後の植物を含み得る。したがって寄主を「必ず先に到着した媒介変数」として扱えない。追加の記録努力・寄主リッチネス調整はこの今回の4モデルに入っていない。別の過去の厳しい3モデル解析（AIS・風・寄主数・一般植物索引努力付き）とは**変数・基準モデルが異なり、数値を足し合わせない**。

## 4. 長期原稿への接続
