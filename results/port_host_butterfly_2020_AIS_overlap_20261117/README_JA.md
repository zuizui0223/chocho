# 同じ港・島で「植物→チョウ→船便」を結合できるか：原本固定の識別性監査（2026-11-17）

**結論：植物・チョウ・港の地点IDは結べたが、努力量と船便ODを含む一つの統計モデルは、現在の独立標本では成立しない。** 既存の全球潜在寄主資源+54.9%、島の相対利得+118.9%、155種の後期GBIF予測誤差−4.12%などの肯定結果は上書きしない。これは母集団・観測条件・時間順序の監査であり、蝶の移入・繁殖を直接観察した研究ではない。

## 元ソースを変えずに照合した

- 元の[同一島港／非港沿岸の17島・24港地点対（48地点）](../../../provenance/reviewer_defenses/results/paired_island_port_nonport_coast_20261109/RESULTS_JA.md)：2001–2010年の植物と蝶のGBIF索引、2011–2017/2018–2022年の蝶の新しい索引を保存。
- [Duvallet et al. 2024 Zenodo AIS2020原航路](https://doi.org/10.5281/zenodo.10783698)：2020年1月1日〜10月7日の記録のみ。元2020出発港の名前を正規化して**同じ名前＋元WPI港から25km以内**にあるものだけを「確認済み」とした、独立の[51島194港ソース監査](../../../results/island51_zenodo2020_portvoyage_audit_20261107/README.md)。未照合は実際の航路ゼロとはしない。
- すべての入力に元のGit blob SHAロックをかけた。港・非港のサイトID `(landmass_id, port_id, side)` が一対一、船便も`WPI_port_id`を一致するものだけ採用。元の各年の蝶記録件数は混同しない。

## 結果：情報を一つの観測単位にそろえると急激に減る

| 出典と品質条件 | 港／非港のペア | 島（独立空間単位） |
|---|---:|---:|
| 元の調査対象 | 24 | 17 |
| 港・非港とも2001–2010の植物記録が10件以上 | **23** | **16** |
| 港・非港とも先行期2001–2010の蝶GBIF件数5件以上、記録数の比が1/4〜4倍 | **5** | **3** |
| 港・非港とも2011–2017の蝶GBIF件数10件以上、比が1/4〜4倍 | **6** | **6** |
| 植物・先行蝶・後年蝶の上記努力条件がすべてそろう | **3** | **3** |
| 元WPI港に2020年AISで名前+座標検証済みの港が対応 | **6** | **5** |
| 元港に元51島の**別の島との2020年直接観測航路**も結合 | **2** | **2** |

**航路の対応が成立したのは、landmass ID 15、26の各1港だけ。** 観測努力条件を厳格にすると、独立した島単位の反復は3島程度に落ちる。港・非港比較には港側の植物記録数≥30という**元の標本選抜条件**もあり、全植物記録強度の違いを「船舶の植物輸送効果」と呼べない。

**重要な時間的制約**：AISの航路は2020年。植物記録は2001–2010、チョウ記録には2011–2017が含まれる。したがってAIS2020をこの植物・チョウ期間より前の原因として扱うと**未来情報漏洩**になる。2018–2022の一部との同時期相関さえ、2020年の10か月弱に偏った資料と歴史的真の寄主導入年の欠落によって大きく制約される。

## 事前に固定したモデルの停止条件と判断

仮に観察的な後段モデルを追加する場合でも、**港／非港15組以上、独立した元島10以上**を最低限の記述的データ充足ゲートとする（十分な統計的検出力の保証ではない）。今回、同一港IDの船舶島間ODは2港・2島、植物と前後の蝶努力が揃うのは3港・3島で、どちらも**停止条件**。

したがって、この監査では「港×適合寄主×AIS航路→チョウの定着」のモデルは**一度も適合していない**。無理に少数ケースを回帰して、元の独立の+0.2445港→外来植物相、寄主情報の+4.12%GBIF記録予測、海域の6.49%の条件付き予測などを因果連鎖へ統合しない。

## 次の本当のボトルネック

1. **植物の供給の時間**：種別に港付近と非港海岸で導入前後を観測できる、同一期間・同じ採集努力の元データを集める。現代のWCVP外来区分を昔の導入年に変換しない。
2. **チョウの実現**：植物と同地点で、蝶の目標群観測日数（単なる出現記録件数ではない）を得て、複数年の再記録・幼虫利用を区別する。先行蝶記録で評価セルを事後選択しない。
3. **船の到達**：2020年以外の歴史的な港起終点の照合率・方向・年を拡大する。2020の「未照合」を真の船便ゼロとして回帰に投入しない。

**論文の選択：** GEB統合本稿は「外来植物が再分配されると潜在的な寄主資源の地理が再編され、その地理が既知チョウのGBIF記録の条件付き予測に情報を持つ」というすでに検証できている二段階を主張する。港・海流・航路は、現状では供給と到達に関する**限定された独立の観測的補助証拠**として残す。従前の肯定的なデータを撤回しない。
