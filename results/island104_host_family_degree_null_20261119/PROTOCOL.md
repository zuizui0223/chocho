# Catalogue-host geography versus family/occupancy matched pseudo-hosts

**Exploratory protocol fixed 2026-11-19 JST AFTER the positive 668-known-host versus 7,219-unlisted-flora test was already seen.** This is a diagnostic of the data construction, NOT preregistered independent confirmation and NOT a biological non-host classification.

## Source and population
Use immutable original PR118 HOSTS×WCVP v13 accepted species aliases and allflora sidecars pinned in the successful [host-mask audit](https://github.com/zuizui0223/chocho/actions/runs/44445904218). Original accepted 1,706 host plants of the frozen 239 butterfly species (2,596 insect×plant edges), 104 coastal botanical islands, all **5,355** exactly source-matched plant dyads, **5,353** potential butterfly-resource Jaccard-defined dyads, and the original **1,088** held-*both*-islands-unseen fivefold source-hash test pairs. Fail closed if any source hash, taxa, geographic identities, original Jaccards or published held-out H/O score changes.

## Null that does NOT use the consumer response
For all 7,887 accepted alien plant IDs in those 104 islands, use **WCVP accepted family** and the **number of the 104 islands on which each plant occurs**. Define fixed occupancy classes: 1, 2–3, 4–7, 8–15, 16–31, 32–63, 64–104 islands. Group plants by (family, occupancy class). Preserve, within every stratum, the observed number of plants labelled known HOSTS hosts (total 668). Draw 199 pseudo-host sets uniformly **without replacement within each stratum** with fixed RNG seed 20261119. For each draw the complement is pseudo-other. Family composition, each taxon's actual island distributions and the distribution of occupancy classes are left intact; individual host identity changes. Note how many host labels are *immovable* because an entire stratum consists of registered hosts; state the number of uninformative strata. Do not treat repeated draws of overlapping networks as independent observations. No user-level specimen or proprietary WCVP rows are published.

For each original island dyad calculate pseudo-H and pseudo-O Jaccard, explicit empty-union flags, and log1p(min/max) island pseudo-H and pseudo-O accepted-species counts. The **primary** E baseline includes the original fixed source E covariates, both flags, and all 4 pseudo-H and pseudo-O marginal richness covariates. Secondary S baseline additionally includes *target-derived* contemporary potential butterfly-resource richness. Compare fixed alpha=20 ridge, five source-hash held-out folds, training-only scaling for: baseline B, B+H_jaccard, B+O_jaccard, B+H_jaccard+O_jaccard. Same island folds and 1,088 pairs for observed host labels and every pseudo draw. Do not change model/hyperparameters based on sign.

**Primary statistic:** (O+H vs O) relative MSE gain, equal-weighted across the frozen five folds, with 199 label-shuffle scores and add-one upper-tail rank (1+sum(null≥observed))/200. Also report B→H/B→O gains, H−O gain contrast and O given H, each source fold and pair-weighted checks. Report observed and null quantiles, null max, positive-fold counts and the two above-mentioned richness/origin label constraints. The null is a descriptive source-conditional label exchangeability diagnostic, **not** an iid test of plant or butterfly ecology; source family × occupancy may leave exchangeability violations. S is retrospective and should never replace E as prospective evidence.

## Decision
If H outperforms this matched label null, this only shows known-host catalogue identities contain more information about a **potential consumer response built from the same catalogue** than comparably common WCVP plants do. Even a strong result can be a tautological name overlap and cannot prove feeding, population increase, human-mediated immigration, historical port cargo or observed community homogenisation. If H does *not* outperform, retain the original +17.609/+20.939% O→H incremental source result but qualify it as explainable by family/distribution/host margins. The independent observed GBIF butterfly-assemblage endpoint is the next biological target, separate from this deliberately same-source diagnostic.
