## 生態学的な解釈と独立検証との整合

この検定は「Hを含む元の植物相の配置が、植物科・島出現頻度とH/Oの種数を調整した後でも、元の*潜在的*蝶資源の地理予測に情報を加えるか」を調べている。しかし**応答（候補寄主で支持され得る蝶種）も説明側のHも共通のHOSTS×WCVPデータから構築**されている。Hを知れば応答の構築に使った植物名を知ることになるため、帰無を超えても同定できるのは**データベース内の構造的対応**であり、実際の幼虫利用率・個体数増加・港を通じた到着・定着の証拠ではない。

独立したGBIF 224蝶種×169地域の*観測蝶相*では、一般外来植物相を入れたモデルに既知寄主の植物相を加えた改善は**+0.091%**に留まる（[元の独立観測結果](../../provenance/reviewer_defenses/results/global_colonial_resource_beta_20261031/GBIF_GLOBAL224_EMPIRICAL_READOUT_20261101_ja.md)）。104島の潜在資源指標とは母集団と応答が異なり、+16.4%と+0.091%を差し引いたり統計学的に直接比較したりしない。生態学的には「資源地図の強い再配置と、実際の群集記録の対応は別物」という区別をさらに明確にする。
