# 港・海流の比較対象を固定：EuDiS形質照合22島×WPI・寄主植物相

**2026-11-16 実行・原本ゲート成功**：[PR #165 GitHub Actions #43894481481](https://github.com/zuizui0223/chocho/actions/runs/43894481481)。

## データ結合の結果

- 原本EuDiS × WCVPで**同一地域の在来と外来両方に形質情報がある22島嶼地理区**を固定して再利用（[固定原本CI #43892007427](https://github.com/zuizui0223/chocho/actions/runs/43892007427) のoriginal artifactを直接復元）。名称と地域コードを含むQ1寄主候補・WPI港数・WCVP植物相の**同一WGSRPD3コードで22/22件完全に結合**。
- **22/22地域にWPI登録港あり**、さらに**22/22地域でWCVP港対象植物相の付加情報あり**。港が全て存在するので**この標本だけでは「港あり vs 港なし」の識別は不能**。
- TDWG level1=1（欧州）9地域、欧州以外13地域。元の同地域在来−外来の海流散布形質保有率比較は22島で+2.9515 pp（95%地域記述区間+2.0395〜+4.5323 pp、17正・4負・1同率）。
- 欧州以外の13地域には**少なくとも1種のEuDiS在来海流散布形質候補があり、WPI登録港もある**。ただし全てが現地の漂着証拠・航路資料を持つとは限らない。

## 設計上の判断

- **次の海流側試験**：旧NOAA OSCARの2005年u/v取得成功を踏まえ、13候補から**実際の出発海岸・到着海岸の地理座標と浮遊期間が裏づけられる、狭い島対**を選ぶ。その前に出発地の植物源と受け手の在来／外来履歴を区別する。地理コードだけでは方向付き輸送には進めない。
- **港・船の試験**：22全て港ありなので、港数を海上運搬頻度の代理とみなす因果推定は行わない。必要な比較は同島・同海岸帯の**港 vs 非港地点**、または公的に確認された歴史的起終点別船便だけ。
- **蝶側への統合**：元225蝶×51島の情報と単位が重ならないので、現時点で「港/海流が蝶定着に寄与した」とは言わない。GEB統合本稿+54.9%、島+118.9%、155種予測誤差改善+4.12%の主張は変更しない。

## 港の実座標とTDWGポリゴンの独立照合（2026-11-16追加）

- NOAA WPI 2019ソースGeoJSONの**3,630港のPoint**と公式TDWG WGSRPD3 Level3 GeoJSON（固定ソースSHA `52da7828aba9d461dd133c27b3bd7a4407161f54`）を、座標を補間・移動しない**厳密なポリゴン内包含**で検証。原本EuDiS適格22地理区のポリゴンのみ候補にした。
- **22地理区中20地理区、308港座標**に信頼できる単一区域対応が得られた。欧州以外の元13地理区では11地理区：`ALU,AZO,CNY,CVI,CYP,EAI,GNL,JAP,NFL,PEI,SAK`。
- **KUR（千島列島）・MDR（マデイラ）には厳密内包点が見つからなかった**。別ソースの現代WPI集計では登録港があるが、海岸の外側に置かれた港点／地理区境界／IDの違いが未解決。**港無し・到達不可とは解釈しない**。座標を恣意的に最近傍の島へ割り当てない。
- 採用済みは同一地理区の形質対象×座標の**可能な対応**であり、個々の植物がその港から運ばれた、または島間に歴史的船便があったという意味ではない。WGSRPD3は広い島群や複合地理区も含むため、島群の代表点を種子出発地と同一視しない。
