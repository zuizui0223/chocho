# 2010年以前の「そのチョウ種が利用できる既知寄主」の実記録と、2011–2022年のチョウ記録（2026-11-17）

## 結論

**種ごとの幼虫寄主植物が島の港周辺に先に記録されている場合、後にそのチョウがGBIFへ初めて記録される頻度は粗く高い。しかし、チョウ種・島・既に記録された同種チョウの供給源までの地理距離を条件にすると、その独立した正の関連は検出されない。** この結果は、島嶼の潜在資源拡大 +118.9%、全球 +54.9%、外来植物相と海域回路 +4.239%、島蝶群集と海域回路 +5.082%、港×全外来植物相の正の関係を否定するものではない。後者は**異なる推定対象**である。

この新しい検証で最も重要なのは、今まで用いた2001–2024年の寄主植物プールを**過去の寄主資源であるかのように扱う時間逆転を解消した**こと。GBIFの記録された植物は真の植物導入日や当該港の幼虫の摂食・繁殖を示さない。

## 1. 先行する種ごとの寄主指標を真正の出典から作成

- **2001–2010年**：オリジナル194 WPI港の5 km GBIF Plantae speciesKey記録を源泉とする。194港すべてが実行済み、27,598「港×植物種」記録組合せ、植物分類群4,876種、**合計173,113件の港検索インデックス記録数**（重なる検索円は独立でない）、45/51島に少なくとも一種の植物が索引。
- **蝶の既知幼虫寄主**：原著者側で照合したオリジナル230種の2,524蝶×寄主植物エッジから、HOSTS由来の1,642植物名をGBIFの受理種名へ源泉照合。**1,581固有植物種**がEXACT_ACCEPTED、うち**413種**が上記2001–2010年に元194港のどこかで索引済み。41/51島に少なくとも一種。蝶に対応する寄主IDのみを、各蝶種×島の植物記録集合と交差して二値/種数の指標を作った。
- **蝶の応答**：原本を公開GBIFで再取得した225蝶種×51島=11,475セル、2001–2010年既記録・2011–2017年・2018–2022年の固定窓。オリジナルHOSTS種名と受理名で直接203種、出典中の一意なシノニム対応15種を照合し、**218蝶種**で検証（217ではない）。2001–2010年にその蝶がまだ索引されていない**10,431種×島セル**をリスク集合とし、後の**306初索引**を応答とした。
- 元分類群・蝶HOSTS個別エッジの生データは新たにGitHubにアップロードしない。新CIは解析時に元Actions artifactを一時取得して**集計JSONと51島・5地理群の誤差CSVだけ**保存する。再現に当該artifactの保存期限・アクセスが必要であり、完全な匿名公開再実行を宣言しない。

出典：原HOSTS [#40979986160](https://github.com/zuizui0223/chocho/actions/runs/40979986160)、分類群 [#41177682289](https://github.com/zuizui0223/chocho/actions/runs/41177682289)、194港の真正2001–2010年植物GBIF [#42361257543](https://github.com/zuizui0223/chocho/actions/runs/42361257543)、独立225×51蝶GBIF [#42556346640](https://github.com/zuizui0223/chocho/actions/runs/42556346640)、海域回路 [#42193019385](https://github.com/zuizui0223/chocho/actions/runs/42193019385)、地理群 [#42325176725](https://github.com/zuizui0223/chocho/actions/runs/42325176725)。個々の原本SHA256を新しい独立スクリプトで強制検証。

## 2. 元の個別蝶種×島の肯定結果と、地理的交絡

| 2010年以前にその蝶の既知幼虫寄主が港5 kmで索引済みか | 種×島 | 2011–2022年の蝶初索引 | 記録率 |
|---|---:|---:|---:|
| あり | 1,075 | 53 | **4.93%** |
| なし | 9,356 | 253 | **2.70%** |

島と蝶種を固定した二方向固定効果の線形確率差は **+2.841ポイント**、島・種の2方向クラスタを使う記述的95%区間 **[+0.084,+5.598]ポイント**。これは歴史的な寄主が後続の記録と正に対応するという**肯定的な観測結果**である。

しかし、同種蝶が2001–2010年に既に索引されていた別島までの**最短大円距離**を追加すると、差は **−1.103ポイント**（記述的95%区間 **[−3.720,+1.515]**）、さらに同じ元GSHHGの**無向・均質海域回路抵抗**を追加しても **−0.890ポイント**（**[−3.452,+1.671]**）。すなわち、独立した先行寄主効果の正符号が残らない主要な調整要因は**既存の蝶の分布からの地理距離**であり、海域回路抵抗を加えて初めて消えたわけではない。先行同種が元51島外にいる可能性を測定できないという制約は残る。

「寄主がない」ではなく**「194港・5 kmの過去GBIF記録に出ない」**対照であり、人口・島の面積・植物観測の不均等、観察されない幼虫寄主の時期・生存率などは不明である。

**感度**：2001–2010年の一般植物が一種以上索引されている45島だけに限定しても、地理距離＋回路追加後の差は **−0.630ポイント**（**[−3.172,+1.911]**）。受理名直接照合の203蝶種だけでは **−1.014ポイント**（**[−3.620,+1.592]**）。2011–2017年の後期第一窓と2018–2022年の第二窓それぞれでも、到達距離等を入れた寄主独立差の区間はゼロをまたぐ。

## 3. 元51島の地理的な予測テスト

同じ2011–2022年の新記録306件を対象に、過去の情報のみを予測変数として、島を1つずつ外す51検証と、先に固定済みの経度5地域群の学習外評価を行った。

**共通基本モデル**：前期に索引された同種蝶の最寄り島までの大円距離・無向海域回路・その出典が存在しない場合のフラグ、元地域の前期蝶の索引状況、2001–2010年の植物記録数と植物種数、194元港の港数、緯度・経度の周期成分、蝶種ごとのHOSTS既知寄主数・蝶種ID。学習データのみ標準化、罰則強度固定のL2ロジスティック回帰。**追加モデルはその蝶種固有の2001–2010年の寄主索引の有無だけ追加**。外した島の未来蝶記録や2011年以降の植物は説明変数に使わない。

| 地理的転移の損失（正なら改善） | 先行寄主二値情報の追加 |
|---|---:|
| 51島の島1つ保留 Brier | **約−0.27%** |
| 51島の島1つ保留 log loss | **約−0.24%** |
| 5地域全体を留保 Brier | **約−0.38%** |
| 5地域全体を留保 log loss | **約−0.37%** |

改善は見られず、候補寄主の存在が地理・植物記録努力・元の蝶の分布に比べて独立の転移可能な予測情報を持つとは判定できない。学習の地理単位が共有されるため無作為の新地域実験ではなく、これ自体は生態学的な寄主効果がゼロだという証明でもない。

## 4. GEB統合論文への扱い

これは元の239蝶種の全球潜在寄主資源増加、126島の外来植物、51島の蝶群集類似性の解析とは**同一母集団ではない**。メイン図は維持し、**Supplementary Results S.C**で「観測された寄主→後期の蝶記録」の時間順の直接検証として報告する。生物学的な供給・到達・実現を同じものとせず、**『外来植物が潜在的な寄主を提供する』と『その植物が後続の蝶定着を原因的に増やした』を明確に分ける**。

新しい種別HOSTSの出典は蝶の**幼虫寄主の既知リスト**であり、過去年のその植物が**外来**だったかどうかの島内種別由来は検証されていない。したがって「先行する**外来**食草の効果」と呼ばず、厳密には「先行する既知寄主植物の索引」である。過去の全194港の検索0を生物の不在とも呼ばない。
