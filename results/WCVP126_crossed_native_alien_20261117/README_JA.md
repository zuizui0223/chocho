# 在来植物相と外来植物相の島間類似：WCVP受理種・海の形・実際の港湾データを交差比較（2026-11-17）

**作業結論：全126島・7,875島ペアの「同じ在来種／同じ外来種がどの島に載るか」という種単位比較が成立した。** EuDiSの欧州寄りの海流散布形質の取得率に頼らず植物相全体を比較できる。外来植物相の共有Jaccard類似度は在来より高い。ただし、海の形の情報は**在来と外来の双方**の地域外予測を改善し、港数の組合せは外来だけを強く改善しなかった。ゆえに**「在来=自然海流／外来=港・船」という二経路の実証にはまだ届かない**。

- 原本：rWCVPdata WCVP v13, source SHA `65bed76bae9d644ccb6ad200c05f9f5071d89e05`。受理種360,064、`extinct=0`、`location_doubtful=0`、地域×種の在来/外来origin重複を拒否。
- 地域：オリジナルQ1に固定された**126 WGSRPD3島**。原本の在来×島**184,997**、外来×島**39,024**、計**224,021種×地域**。元全植物相集計126/126で一致し、原植物IDではなく受理種IDを使い種名の重複に左右されない。
- 在来・外来をそれぞれ別々の126×受理種疎行列にして全上三角**7,875ペア**の共通種数、和集合、Jaccard、Sørensen、Simpson重複率を計算。種名と個別元植物分布の原本は再配布しない。外来Jaccardは7,874ペアで定義可能、在来は7,875ペア。定義不能はゼロに変換しない。
- **Jaccard中央値：在来0.004487、外来0.046030（約10.3倍）**。全域の現代分布の類似が異なることを示す記述的な結果。母集団の種数・地域記載・帰化史・観測努力が異なるため、これ自体から船と海流の寄与の比は推定できない。

## 2. 距離・港と船の接続を同じ種×地域ペアに照合

- 元のTDWG v3地理区 SHA `52da7828aba9d461dd133c27b3bd7a4407161f54`の**各代表点間大円距離**を7,875ペアに固定。複数島を含むWGSRPD3地域を一島の中心点だと扱わない。
- 元WPI2019の3,630座標から126島TDWGポリゴン内に**厳密に入る546港**を確認。元WPI2023の登録港数は異なるスナップショットとして、植生の説明用**港数指標**には使えるが船の直接移動ではない。
- 元Zenodo/Duvallet et al. 2020 AIS航路の厳密なWPI名称＋元座標確認済みIDは51島群からの194港・46外部対応港に限られ、今回の126WGSRPD3へ変換すると**確認済みAIS港のある10植物地理区**、両側に確認港がある**45島ペア**、**実際の直接航路索引が少なくとも1件ある島ペアは7ペア**。残りを船便ゼロにしない。2020年船便から現代WCVP植物種の移入年・積荷・幼虫輸送は推論できない。
- この制約ゆえ、実航路を説明変数とする全球7,875ペアの「在来海流 vs 外来実船便」主モデルは**識別できず未適合**。

## 3. 海の地形基準：旧51島GSHHGグラフを使った126島への接続

元の51島で利用したGSHHG v2.3.7の**0.0625度海陸マスク・0.5度海ブロック**を、元NPZ SHA `79a25cb1491c30bc5542333bd4020535bc88772c98f8aa8fa1fe9c12f7b8e906`のまま使用。港ではなく公式TDWGの島の海岸線上から固定的なソース点を選び、水路が分離されたブロックを正しく分けた同じ巨大海域連結成分へ接続した。既存の生物応答を見て島を選ばない。

## 4. 同じ島群で実行した「交差した予測」の現状

5,356ペアのうち、在来と外来のJaccardが両方定義できる**5,355ペア／104島**を共通分母に固定。交差検証では、毎回1島を完全に学習ペアから除外し、その島が関与する島ペアを予測（104 leave-one-island-out folds）。記録単位は**島**であり、5,355ペアや両端2回分の検証を独立な実験反復としない。

- **B（基本）**：大円距離（logと二乗）、TDWG Level1同一区分、緯度差、当該植物相の種数両端min/max、面積両端min/max。
- **G（海の形）**：B＋GSHHG海上最短距離の大円距離に対する対数超過。
- **P（港数の代理指標）**：B＋現代WPI港数の両地域のlog1p積。**実航路ODではない**。
- **GP**：B＋G＋P。固定したridge penalty 20、訓練ペアでだけ標準化、両植物相とも完全に同じ島ペアに対する、島等重みMSE比較。

| 島holdout・追加MSE削減率（正が改善） | 在来植物相Jaccard | 外来植物相Jaccard |
|---|---:|---:|
| B→G（海の形追加） | **+2.234%** | **+1.775%** |
| B→P（港数代理追加） | −0.077% | +0.043% |
| B→GP（両方追加） | +2.154% | +1.936% |
| P→GP（港後に海の形を追加） | **+2.230%** | **+1.894%** |
| G→GP（海の形後に港代理追加） | **−0.082%** | +0.164% |

島再標本化によるB→G記述的95%区間は在来**+1.12〜+3.38%**、外来**+0.62〜+2.94%**。B→Pの外来は**−0.38〜+0.45%**でゼロをまたぐ。少なくとも現時点の**方向を含まない海の形**は、在来と外来双方で追加情報を持ち、**現代港数だけ**では外来共有を選択的に予測できていない。これが「海流が在来、船が外来」の支持と違う理由。ペアの両端の現代在来/外来植物**種数**は既知として利用しているので、これは完全に未知の島の植物相を前向き予測した研究ではない。

## 5. 旧EuDiS +2.95ポイントの扱い、Fig2の判断

以前の[EuDiSの22島・同一島内の比較](../eudis_thalasso_wcvp_gate_20261116/README_JA.md)では、十分に形質を照合できた島で在来植物相の方が外来植物相より「海流散布形態」に分類される割合が高い**中央値+2.9515ポイント**（記述区間+2.04〜+4.53）。これは記述的な**形質構成**であり、実際の海流散布量でも、全126島の植物の無作為標本でもない（EuDiSは欧州原産植物に偏る）。

現時点のFig2で確実に述べられるのは**港数と外来植物相全体の条件付き関連**と**在来植物相と外来植物相の散布形質構成の記述的な違い**まで。「自然海流／人為船便が独立して各植物相を作った」という二経路は強い**仮説図**なら可能だが、実証済みの主因果経路として描くのは早い。新しい5,355ペアの結果は、**地理的距離・海の形に沿った自然と人為の両植物相の再編**を考える補助結果として使う。本文で海流×船便の対称な独立機構を宣言しない。

次の物理ソースとして、**方向を持つ実測NOAA旧OSCAR流速**を、同一126島の海岸発進点で取得できるかを別途検証する。現在の海の形は**無向**であり、元の大西洋3経路の2005年粒子追跡を1275や7875組の到達確率へコピーしたものではない。浮遊寿命・季節・沿岸解像度・海上風・実船舶OD・歴史的移入年が整合した時だけ、物理輸送の二経路を本文の柱へ昇格する。

**投稿単位は一つのGEB原稿**。全239蝶種の潜在食草資源+54.9%、島の相対増分+118.9%、155蝶種のGBIF記録予測誤差+4.12%、先行の港・海域の肯定結果は変更しない。今回の植物相側の独立追加結果は、探索的な港／自然地理補助図と方法防御として残す。

## 6. さらに厳しい検証：両方の島が学習データにいない組合せ

先の104回のleave-one-island-outでは、テストペアの他方の島が学習に含まれている。そこで、同じ**5,355ペア・104島**を結果と独立の島コードSHA256により5群に固定し、各群で**両端がテスト群の島からなるペアのみ**を評価した。残る島だけでモデルを訓練し、境界をまたぐペアを当該foldの学習にもテストにも使わない。**1,089のユニーク島ペア**がさらに厳しい転移評価に含まれた（元の全5,355ペアとは評価母集団が違う）。距離・同一植物地理大区分・緯度差・島面積・同じ植物相の種数のmin/maxは全モデルで同一。海の形は無向GSHHG最短水路距離、港は現代のWPI港数の組合せ代理指標であり、実海流・実船便ではない。

| 厳密な両端未知5群評価：島群等重みのMSE改善率（正が改善） | 在来Jaccard | 外来Jaccard |
|---|---:|---:|
| B→G、海路幾何のみ | **+1.735%** | **+1.858%** |
| B→P、現代港数代理のみ | **−0.391%** | **−0.147%** |
| B→GP、両方 | +1.471% | +1.807% |
| P→GP、港数後に海の形 | +1.856% | +1.951% |
| G→GP、海の形の後に港数 | −0.268% | −0.052% |

B→Gの5群再標本化（**独立実験ではない**）記述的95%区間は在来 **−2.24〜+4.11%**、外来 **−1.59〜+3.69%**。両方ゼロをまたぎ、前節より厳しい転移では推定精度が不足する。いずれも海路幾何の改善方向は残るが、**在来専用という予測はない**。港数の追加も強い独立改善を示さず、港を「船で植物を運んだ」という輸送の説明変数へ昇格しない。

[両端未知5分割の元データによる実行成功CI #44011411479](https://github.com/zuizui0223/chocho/actions/runs/44011411479)、[出力の固定された機械可読要約](VERIFIED_DOUBLE_UNSEEN_SOURCE_20261117.json)、実装 `scripts/audit_WCVP126_native_alien_double_unseen_islands_20261117.py`。**在来と外来を全く同じテストペアで評価した**が、5群からの再標本化区間は標本内の地理依存を完全に補正した信頼区間ではない。

**結論の扱い：** Fig2は現状でA「港と全外来植物相の条件付き地理的関連」、B「EuDiSで形質照合した22島の在来・外来間の海流散布形態の記述差」を並べること自体は可能。ただし両者に**実際の海流による自然輸送／実船便による人為輸送が実証された**という矢印を付けない。全球植物相7,875ペアの新結果は、この強い因果図を支持するテストではないため、方法・Supplementで効果と限界を提示する。
