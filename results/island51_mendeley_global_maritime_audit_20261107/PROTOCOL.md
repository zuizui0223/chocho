# Frozen public alternative global maritime network source audit

Date 2026-11-07. This is an exploratory third-party source compatibility audit on the existing original 51-island / 194-WPI-port study. Parent PR141 and PR142 findings were inspected before this audit: the published Zenodo original-2020 triplet source had 12 verified island pairs and 133 cross-island source rows, while even an intentionally false-identity-assuming scenario of all 27 near-but-name-discordant nodes produced only 28 hypothetical source island links, below a source-only feasibility threshold of 80 original source island pairs. DO NOT replace those 12 verified pairs or convert the 27 hypotheses into actual voyages.

## Public candidate 1: a GLOBAL network artifact (NOT raw vessel visits)

Jasper Verschuur, Ernst E. Koks and Jim W. Hall, 2022, Ports' criticality in international trade and global supply-chains (Nature Communications, DOI 10.1038/s41467-022-32070-0). Research model outputs at the openly advertised Mendeley Data dataset, DOI 10.17632/vzzy3b9gg4.1, identifier vzzy3b9gg4, version 1, CC BY 4.0. Public folder names advertised by the authors include Network, Port_to_port_network, Maritime_transport, Port_statistics and other model output. The paper studies approximately 1300 globally important ports and predicts trade allocation on a global modeled maritime network. This is a different estimand from raw vessel-identified port-to-port AIS journeys: DO NOT call model edges observed 2020 voyages or date them to the 2001-2010 butterfly/plant records.

Use ONLY the officially documented Mendeley Data public API host https://api.data.mendeley.com, and advertised public dataset ID/version. Attempt read-only public GET dataset metadata, public list of folders and files, with 20-second request limits, at most 4 network retries for transient status codes and explicit short backoff, no user credential/OAuth bypass or scraping login. Record endpoint, URL, HTTP status, response type and a bounded source manifest of folder names, file IDs, byte sizes, filenames, checksums and content-type. Do not infer a file exists based on folder labels or descriptions alone; distinguish source advertised file name from verified downloadable bytes.

If an openly downloadable file can be identified whose PATH and name explicitly indicate a source port table, maritime Network edge list or Port_to_port_network model output, inspect at most 3 selected files, each with advertised uncompressed size <=120MB, downloading through the documented public redirect URL only (no authentication). Verify downloaded SHA256 against its published source metadata when provided, detect actual file format (CSV/ZIP/Parquet/GeoJSON), and inspect only column names and maximum 5 harmless sample rows, without republishing any raw ship identifiers. Handle zip members safely and cap inflated bytes. Save an unambiguous source-only access receipt even if permissions or rate limits block download. Do not fabricate a WPI port match if source lacks IDs/coordinates; do not convert modeled network to observed vessel passages.

If explicit port geography and edge data are successfully retrieved and verified, a SECOND source-frozen protocol must state exactly how ports will be matched to WPI (name+position/validated original IDs) before any full join or island route coverage number is calculated. Exact source matched port pairs must be verified as model-provided graph edges, not observed AIS travel. Model edges used as assumed geometry/conductance are not cargo movement observations.
