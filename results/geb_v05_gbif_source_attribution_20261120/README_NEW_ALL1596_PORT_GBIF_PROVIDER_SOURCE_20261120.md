## この結果をどこまで使えるか

1. **肯定できる**：元の1,596完了港の地理的IDと港中心位置を保って、現時点の公開GBIF索引から植物由来の1,482提供元を同定し、提供元ごとの索引件数を取得できた。記録数のデータソース集中と検索圏による重複を監査できる。
2. **元の研究との非同一性**：元の植物キャッシュは**5kmポリゴンWKTを用いた`speciesKey` facet**であり、今回の植物元記録は**港中心`geoDistance=5km`の`datasetKey` facet**。中心は小数6桁で一致しても、境界に位置するGBIF記録の集合は完全同一とは限らず、さらにGBIF索引の取得日時も違う。
3. **いま言えないこと**：この1,482提供元は元の2026年の1,596港植物サンプルの「オリジナル提供元1,482件」を証明しない。出現レコードIDの重複除去もしていない。したがって、**元のGBIF植物サンプルの派生DOIを過去に遡ってこの件数で登録してはならない**。
4. **生態学的主張は維持**：港と外来植物相の関係、島の寄主機会拡大、隔離の勾配はもとの別解析・別母集団の肯定結果である。本監査はそれらを否定も強化もする独立の因果検定ではなく、出典データの提供元追跡可能性の確認である。植物を船が輸送したこと、チョウが実際に定着したことはこの索引からは立証できない。

**次の出典作業**：元の港ごとのWKT・当時のGBIF元レコード（`gbifID`、`datasetKey`）が別保存されているか探索する。見つからなければ、別日時で取得したデータを元のサンプルと区別し、許諾された新しい原レコード集合を重複除去したうえで、対応するDOIと査読用の実在する公開資料を作成する。
