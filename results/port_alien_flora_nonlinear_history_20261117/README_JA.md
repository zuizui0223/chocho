# 島の港―外来植物相の地域差は何に依存するか：非線形性、記録履歴、未知地域への転移（2026-11-17）

**結果：港と外来植物相全体の正の関連が、小さく／在来植物の乏しい島で強く見えることは、従来モデルの探索的な肯定結果として保持する。しかし、(1) 面積と在来植物種数が強く相関し、(2) 非線形モデルでは推定が変動し、(3) 地域外予測では交互作用を加えると6条件すべてでLevel1地域等重みMSEが悪化したため、全球に普遍的な港湾の増幅機構へ昇格することはできない。** 元の全球239チョウ種+54.9%、島+118.9%、155種のGBIF記録予測+4.12%、港と外来植物全体の既存の正の条件付き関連は変更しない。

## 解析を行った理由と原本

前の[PR #173](https://github.com/zuizui0223/chocho/pull/173)では、元のWCVP v13/WGSRPD3 **126島**、既知の幼虫寄主HOSTSにも対応できる**123島**、植物GBIF記録量と照合できる**98島**で、別々に推定した港×面積（123島β−0.139、探索的Holm p=.024）と港×在来植物種数（β−0.182、同p=.024）がいずれも負であった。この結果は現代の島植物相・港の**地域間相関**であり、輸送した種子・外来植物導入の時刻・チョウの繁殖記録ではない。

本検証では元CSVのGit blob SHAを固定し、前の同時モデル（123島：港×面積−0.04254168、港×在来植物−0.13899715）を数値再現してから、**結果を見た後に実施する頑健性・反証診断**として2種の新しい解析を追加。前の論文本文・図は編集しない。

## 1. 港・面積・在来植物の非線形主効果を許したら

`ln(1+外来植物種数)`のモデルに、`log2(1+港)`の二乗、`ln(area)`の二乗、`ln(1+在来植物種数)`の二乗、`area×native`の主効果、さらに`port×area`と`port×native`を**同時**に追加。TDWG Level1は固定効果で調整。98島では現代の植物GBIF記録件数、1900年以前の植物索引件数を追加・代替した。Level1×面積半分の層でFreedman–Lane残差置換1499回、Level1を保持した島bootstrap699回の**探索的感度**を計算した。

| 標本と条件 | 港×面積 β（置換p） | 港×在来植物 β（置換p） |
|---|---:|---:|
| 126島、非線形 | +0.001（.998） | −0.244（.177） |
| 123島、非線形 | +0.062（.750） | −0.218（.125） |
| 港がある91島に限定、非線形 | −0.027（.895） | −0.248（.255） |
| 98島、非線形＋現代植物GBIF件数 | +0.413（.020） | −0.446（.041） |
| 98島、非線形＋1900年以前GBIF植物記録件数 | +0.473（.011） | −0.428（.034） |
| 98島、非線形＋両時代のGBIF件数 | +0.457（.011） | −0.462（.029） |
| 港のある69島、非線形＋現代GBIF植物件数 | +0.342（.497） | −0.334（.299） |

**強調：** 98島モデルはとくに面積との交互作用が従来の負から**正に反転**しており、在来植物との交互作用も大きく、信頼できる「独立の2機構」を示さない。現代植物索引で調整した98島モデルのLevel1内bootstrap区間は面積 [−0.042,+0.985]、在来植物 [−0.927,+0.0009]でゼロをまたぐ。1900年以前の植物記録を応答とした古い植物索引の地理的診断は港×在来植物のp=.343、港×面積p=.152と不確か。**1900年以前の索引記録は歴史的導入でも、港建設前の真正な対照でもない。**

幼虫寄主候補だけが外来植物全体より港と強く結びつくかは、**外来植物全体を条件にした123島非線形モデルでは港×面積β−0.0125（p=.807）、港×在来植物β+0.0089（p=.839）**で支持されず。98島でも同じ方向の明確な肯定結果はない。従来の全球寄主資源再構成を否定する検定ではなく、港の*寄主特有の選択的集積*が別件の問いであることに注意。

## 2. 9植物地理大区分を順に除外した地域外予測

**出発点：交互作用が同じ地域の標本にだけ合うのではなく、異なる植物地理区に一般化するか**。9つのTDWG Level1大区分を順に全除外し、残り8区分で`外来植物種数（log1p）`を学習、外した区分でMSEを測定した。比較は「港・島面積・在来植物を使う基準モデル」対「そこに港×面積・港×在来植物の2交互作用を追加するモデル」。非線形仕様は1節と同じ二乗／面積×在来主効果を含む。**未知のLevel1地域にはその地域の固定効果を予測できないため、両比較モデルともLevel1固定効果は使用せず**、訓練地理区内だけで共変量を標準化し、未学習地理区の応答は使わない。

| 固定した島標本・基準仕様 | 交互作用を足したときの地域等重みMSE改善率 | 改善したLevel1区分（9中） |
|---|---:|---:|
| 126島・線形 | **−6.47%** | 5 |
| 126島・非線形 | **−7.81%** | 2 |
| 123島・線形 | **−10.92%** | 4 |
| **123島・非線形** | **−5.63%** | **1** |
| 98島・非線形＋現代の植物GBIF記録量 | **−2.45%** | 6 |
| 98島・非線形＋1900年以前の植物GBIF索引量 | **−2.19%** | 7 |

改善率は**正なら誤差減、負なら悪化**。評価対象の大区分を等重みにした結果がすべて負。123島非線形は9つの大区分から再標本化した記述的95%区間[−11.92%,−1.15%]。9区分の平均では交互作用の採用を正当化する転移予測上の利得がない。対して全126島線形モデルの**島等重み（pooled）MSE改善率は+5.51%**であるため、地理区の重み付け次第で結論が変わる。この差はモデルに学習地域の構成が効いているという警告でもある。98島の数モデルは多数の地理区で少し改善する一方、一部の地理区で悪化が大きく、等重み平均が負になる。

本診断も**同じWCVP原本を6仕様で再利用した事後検証**であり、未観測の新時代・新地域植物相で確認した「真の外部検証」ではない。まして真正の寄主植物利用、港の植物輸入歴、船便や蝶分布の時系列ではない。

## 3. 一つのGEB論文にどう反映するか

1. **強く残す肯定結果**：全239蝶種で食草リスト固定・植物の地理的配置を変更した潜在資源地理+54.9%。島と本土の相対増幅（+118.9% vs +40.9%）、島の低い在来寄主初期カバレッジ16% vs本土37.5%、別155種の独立したGBIF記録予測+4.12%。港と外来植物相の現代の正の条件付き相関は既存の独立した供給環境の結果として保持。
2. **探索的補助結果として維持**：既知の島サンプルのシンプルな条件付きモデルでは、小面積・在来植物相の乏しさに沿って港との外来植物相関連が強い。これは**標本内での異質性**で、現状の他地域への一般化・独立機構・輸送因果は認められない。
3. **主図Fig2の新しい中心主張に昇格しない**：非線形・歴史的観測・地域外予測の反証を並べずに、港×小島効果を一つの確定メカニズムと書かない。元のFig2にある港と外来植物相の主関連を維持し、本修飾とその不安定性は**Supplementの感度分析**に限定する。
4. **実際の生物移入を主張するための根拠が未充足**：港と船舶ODの同地点・年代照合、導入植物の島ごとの導入時点、幼虫の局所寄主利用と複数年繁殖、GBIF記録努力の比較が要る。2020年AISを2001年以前の植物輸入の説明変数に使わない。

**判断：** この枝は統合GEBの肯定結果を増幅して宣伝するためでなく、検証可能な範囲を明確にして査読耐性を上げるためのSource QA。元主原稿・図を上書きせず、Draft／未マージ／未投稿のままとする。
