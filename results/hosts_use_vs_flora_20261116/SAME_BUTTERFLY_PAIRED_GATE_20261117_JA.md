# 同一チョウ種の島・本土比較：結果確認前の判定ルール

**2026-11-17、PR #163の続き。** 原HOSTSを調査記録として扱い、「同じ種が島と本土で報告された場合に、地域外来の既知寄主に結びつく割合が上がるか」を評価する。元GEBの全球239種・植物相科調整の数値は変更しない。

## データ・比較

- 固定HOSTS原本（GloBI commit 808e0b8）、受理植物名・地域原産区分（WCVP v13 commit 65bed76b）。FAO抽出済み作物種を除く感度分析。
- Papilionoidea（原HOSTS昆虫科による蝶上科分類）、元239種のみの2母集団。ガはこの対照の母集団に含めない。
- 元のLocationが**WGSRPD3の単一地域に完全対応**する場合のみ。明示的Lab Rearing=Yは除外するが空欄は野外飼育/野外利用を意味しない。
- **種×受理寄主植物×元Locationを1回に重複除去**し、1地域で解決済みHOSTS記録が10以上という元フローの利用可能範囲にそろえる。
- 両方に記録のある**同じチョウ種**の利用比をそれぞれの地理クラスで計算し、同じ種の「島−本土」差を算出する。同じ種が複数の地域にあるときは**地域を均等重み**し、その種の地域差を1個の観測にする。
- 2指標：A. 外来寄主報告の生割合の差、B. 元報告の植物科内で同地域のWCVP外来割合を引いた残差の差。植物科対照は利用できる野外寄主や餌量を表すものではない。
- **さらに強い観測上の例**として、「同じチョウ種×同じ寄主植物」の組合せが島と本土の両方のHOSTS記録に載る例を抽出。島が外来・本土が在来と分類されるものを例示するが、野外で同じ幼虫を追跡した証拠とは呼ばない。

## 事前に固定した採用基準

1. 両方で報告された共有蝶種が**10種未満**なら主分析に昇格せず、事例リストとして扱う。
2. 平均の種単位ブートストラップ9,999回の95%記述区間がゼロをまたいだら、「元の蝶種の構成とは無関係に島で利用超過がある」とは主張しない。
3. Aが正でも、B・FAO除外後Bが正方向を保持しないなら、観測上の原割合の差は消費者の新しい食性変化ではなく植物組成・報告選別で説明可能な範囲とする。
4. 「野外で幼虫が移入食草を摂食」「港が食草を輸送」「移入食草で島に定着した」は、どの係数でも主張しない。
5. 元の島42.4%/本土9.1%、FAO除外後20.9%/8.1%、島資源+118.9%、全球+54.9%、別155種の記録予測+4.12%は、別の推定対象としてすべて保持する。
