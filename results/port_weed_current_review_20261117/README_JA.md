## 海流と回路を同じ島ペアで比較

GitHub Actions成果物を次の4実行から同じフォルダにダウンロードする。44012093616（2005年の方向付き粒子接近行列）、44013658955（104植物地理区の無方向の均質海域回路抵抗）、44010307551（同じ地理区間の距離）、44013825017（元の植物相予測結果）。最初の3入力で次のコマンドを実行できる。

    python compare_currents_and_circuits.py INPUT_DIRECTORY current_circuit_pairs.csv

海流計算の有効な7,313方向を回路に照合。接近12方向で逆方向が評価可能なのは10、逆方向の接近は0。近接はモデル粒子が別地域の岸50 km以内に入ること。同一起点で近接しなかった別の宛先を、地域間距離が観察ペアの1/2〜2倍または1/1.5〜1.5倍となるものから選定。少なくとも3対照がある場合、接近先の回路抵抗が対照中央値未満だったのは広い距離窓で5/6、狭い窓で2/4。事後的な記述で、窓によりケース構成が変わり、出発地や季節の全範囲で海流を観測したわけではない。モデル源は2005年3放流日、最大90日、1度に間引いた旧OSCAR流速である。全12方向の植物種共有に関する既存の距離・種数照合は別の比較で、3対照以上を確保した2方向で実数2、期待2（#175）。

104地域の植物相類似度（5,355組、島を留保した予測）の回路抵抗追加で外来相のMSE 4.239%減、在来相0.110%増。宛先を入れ替えても同じ抵抗値になる。従来の51島のチョウ群集での5.082%改善は異なる応答と標本。いずれも植物種子の向きやチョウの飛翔の証拠とはならない。

## 港からチョウへ

#157の主図は港で記録された外来食草候補と全球の潜在資源を接続。#124では外来一年生草本の絶対割合の正の増加は確認できず、「外来雑草」として一括しない。#158の過去年代の植物記録と後のチョウ記録の元表にはコルシカの Medicago sativa / Colias croceus がある。#163の同一種の地理別寄主報告は別の証拠で、当該港での食害や繁殖を証明しない。#85–86の独立定着記録も到着者を母集団とした成否比較ではない。#157のハワイ島のオオカバマダラは地域的導入食草の港記録に続く島内幼虫と産卵があるが、植物個体・港・次の島へ渡った子孫は照合されていない。航路仮説と自然海流は植物供給に関する競合説明として扱う。
