# 在来寄主・外来寄主と島のチョウ記録：同一種×島の履歴補正

**2026-11-16 | source-locked exploratory audit | successful source workflow.**
This report is **NOT** a test of observed colonisation, breeding success, larval feeding on introduced plants, shipping transport, population recovery, or ecological host absence. It retains the earlier global positive results and does not alter the one-paper GEB manuscript.

## 結論

**最も安定して残った肯定結果は、在来寄主の先行記録がある種×島で、以前から記録されていたチョウが後年もGBIFに再記録される傾向が高いこと。** 外来寄主のみの先行記録について、後年の新規索引の正の増加は検出できない。原データの歴史補正により新規索引イベントは少なく、外来寄主のみのイベントは主解析の各期間1件である。

これらは「外来寄主が役立たない」証拠ではない。植物の記録は資源**機会**、蝶の記録は観測**索引**、因果的な移入・定着・存続とは異なる。

## データ・単位・時系列

- 事前固定の**225チョウ種×51元のGSHHG landmass groups = 11,475セル**。GBIFの1700–2000年歴史調査を全セルに均一適用（894セルで既往索引）、2001–2010の原データに結合。後期は2011–2017および2018–2022を分ける。
- 原本[全11,475セル履歴取得成功](https://github.com/zuizui0223/chocho/actions/runs/43586278558)、[履歴整合後の外来寄主×海洋アクセス検定](../port_host_ocean_long_history_20261114/README.md)。
- 2001–2010に港付近5kmでGBIF植物の記録が存在した島だけを植物側の研究対象とし、島当たり原データ記録数 **≥10** を主解析、**≥30** を感度分析。
- 種の既知幼虫寄主と港周辺の植物種記録を結び、同一種×島を「対応寄主の記録なし」「外来寄主のみ」「在来寄主のみ」「両方」「起源未解決のみ」に分ける。**対応寄主の記録なしは、存在なしの証明ではない。**
- WCVPの外来／在来は**現在の植物地理区レベル**の候補区分で、各島・港への歴史的導入年代は不明。チョウは島のどこかの記録であり、寄主植物の港周囲5kmと同じ局所位置で食草利用したとすることはできない。
- 同じ蝶種および島の固定効果で記録有無との関連を記述。近似的な蝶種×島2-wayクラスタ誤差。固定効果は各蝶種×島特有の調査努力まで調整しない。

## A. 履歴補正後の新しい蝶GBIF索引に対応するか

主解析、先行植物記録≥10、全セル歴史を1700–2010（または2017）まで調査。

| 2001–2010の港周囲の寄主記録 | 2011–2017 初めての後期GBIF索引 / リスクセル | 2018–2022 初めての後期GBIF索引 / リスクセル |
|---|---:|---:|
| 対応寄主の索引なし（真の不在ではない） | 57 / 6,289 | 37 / 6,232 |
| **外来寄主のみ索引** | **1 / 387** | **1 / 386** |
| 在来寄主のみ索引 | 9 / 415 | 8 / 406 |
| 在来と外来の両方 | 2 / 170 | 4 / 168 |
| 起源未解決のみ | 1 / 104 | 1 / 103 |
| **計** | **70 / 7,365** | **51 / 7,295** |

同じ蝶種・島の固定効果で「対応寄主の索引なし」と比べて、外来寄主のみの係数は早期 **−0.644ポイント**（近似95% −1.667〜+0.379）、後期 **−0.320ポイント**（−1.013〜+0.373）。在来寄主のみは早期 **+1.442ポイント**（−0.664〜+3.547）、後期 **+1.281ポイント**（−0.251〜+2.812）。

ここにある「初めて」は**ソースで初めて索引された**ことであり、新規移入・新規繁殖を意味しない。特に外来寄主のみの事例は1+1件しかないため、因果的・生態学的ゼロも負の選択効果も判断不能。植物記録≥30に制限すると後期の外来寄主のみは **0/368** で、少ない正イベントによる推定係数の符号や区間は解釈に不適切。

## B. 以前から記録されていたチョウの再記録

1700–2010のいずれかに記録のあったチョウ種×島を抽出し、2011–2022に少なくとも1件GBIF記録されたか評価（調査努力や実在個体群存続を直接確認するものではない）。

| 対応寄主の先行索引 | 再索引 / 以前の索引あり | 比率 |
|---|---:|---:|
| 対応寄主の索引なし | 263 / 361 | 72.9% |
| 外来寄主のみ | 41 / 48 | 85.4% |
| 在来寄主のみ | 146 / 164 | 89.0% |
| 在来・外来両方 | 125 / 144 | 86.8% |
| 起源未解決のみ | 17 / 18 | 94.4% |
| **総計** | **592 / 735** | **80.5%** |

同じ蝶種・島の固定効果に、過去の蝶記録量2項（log1p[1700–2000件数]、log1p[2001–2010件数]）を追加すると、対応寄主の索引なしに対して：

| 固定効果＋過去の記録量を調整 | 推定再索引率差（百分率ポイント） | 近似95%区間 |
|---|---:|---|
| **在来寄主のみ** | **+11.24** | **+3.00〜+19.48** |
| 外来寄主のみ | +4.68 | −8.50〜+17.85 |
| 在来・外来の両方 | +11.11 | −1.64〜+23.87 |
| 両方 vs 在来寄主のみ | −0.12 | −7.95〜+7.70 |

過去の蝶記録数のうち1700–2000の記録量自体が再索引と正に関連：log1p件数当たり +6.81ポイント（+2.58〜+11.04）。**過去の記録強度の調整は必須**であり、これを加えると「在来+外来」が「在来のみ」より優れるという点推定はほぼ消える。

### 地理・時間の感度分析（事後的探索診断）

- **Great Britain (landmass 15)・Ireland (26)を除く**：645セル、514再索引。在来のみ **+11.99ポイント**（+4.64〜+19.35）、外来のみ+1.19（−9.75〜+12.13）。
- 2001–2010の植物記録≥30：573セル、474再索引。在来のみ **+11.25ポイント**（+1.99〜+20.51）。
- 過去1700–2000に記録のあるセルのみ：647セル、513再索引。在来のみ **+11.98ポイント**（+3.08〜+20.87）。
- **直近2001–2010にチョウ記録があるセルのみ**：515セル中489再索引（**95.0%**）。在来のみ係数は+1.54ポイント（−3.77〜+6.85）と不明確。再記録が天井に近く、追加変数で差を識別しにくい。時間窓で結果が異なるので、普遍的な生態学的存続効果とは解釈しない。

4つの比較は同じ記録群の重複する部分集合であり、独立の実験反復ではない。区間は探索的な近似クラスタ区間で、複数比較・系統的類似・植物・チョウのソース選択を包括した確認的信頼区間ではない。

## 統合GEB論文への結論

**保持する肯定結果:** 239種の潜在寄主地理+54.9%、島+118.9%・本土+40.9%、155種の既知チョウのGBIF記録予測に寄主情報+4.12%、海洋地理の島間群集類似度への探索的追加情報。今回新たに、在来寄主が港周辺に索引される種×島で歴史的に記録された蝶の後期**再索引**が多いという、観測上の接続も確認された。

**昇格しない:** 外来寄主だけが新しい島のチョウの定着を増やす、港・輸送が植物を運んだから蝶の繁殖が成立した、という一連の因果的連鎖はなお確認できない。

**論文上の位置づけ:** 主論文は「導入植物によるチョウの潜在資源地理の再構成」と「寄主・海洋地理の観測記録への条件付き予測」を明確に区切る。本解析は追加の資料・限界の根拠。源データが示す新規索引・再索引を定着率や個体数増加として呼ばない。
