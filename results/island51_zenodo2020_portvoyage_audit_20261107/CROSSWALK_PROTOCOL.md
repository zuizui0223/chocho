# Verified crosswalk of actual 2020 AIS origin/destination ports to original WPI194

Frozen 2026-11-07, after source-format inspection but before mapping/matched-voyage counts. Parent source original Zenodo archive publisher MD5 af27e1bef1f706e2e29ed53aee47ff10 verified; archive contains exactly one semicolon CSV named triplet_2020.csv, with departure/arrival date fields, port IDs/names and from/to longitude/latitude. File is 2020 observational origin/destination data, not 2001–2010 voyages or proof of cargo/biological transport. No butterfly outcomes are examined for this port matching.

## Original and external inputs
1. Original WPI source exact 194 port IDs (source table Git blob a4681c3e3c1406d3a37f51464a298286e9d0ee4f), 51 landmass groups and 182 original marine eligible ports. Retain original port names, country, historical coordinates.
2. Duvallet et al. (2024) Zenodo 10.5281/zenodo.10783698 original 2020 date-ship-port CSV from source ZIP, MD5 af27e1bef1f706e2e29ed53aee47ff10, CC BY 4.0. CSV delimiter is semicolon. Fields include date-out, date-in, Port_ID_waiting_area_id_from, PortName_from, lon_from, lat_from and corresponding to fields. The port ID namespace is NOT assumed to be WPI OBJECTID; no numerical ID join is permitted without independent semantics.
3. Date-only/position source validation: original year 2020 departures, valid arrival >= departure; reject malformed or missing coordinates or identifier as UNRESOLVED, not biological absence. Unknown name "nan" is unresolved. Track all raw and excluded counts.

## Exact source-only linkage (primary)
Normalize a port name by Unicode NFKD/ASCII uppercase, punctuation to spaces, trim whitespace, and remove leading "PORT OF"/"PORT" or trailing "PORT", "HARBOR", "HARBOUR", "TERMINAL" tokens only when at least one meaningful other token remains. Do NOT fuzzy-match spelling, edit distance, transliteration or nearby-only ports in the primary source link.
For each complete external endpoint (source port ID, name, longitude and latitude) and each original WPI port, calculate spherical haversine on radius 6371.0088km. An endpoint matches a WPI port only if its normalized external name is EXACTLY equal to that WPI normalized name and distance <=25km. If zero or >1 original WPI port candidates meet both conditions, mark NO_MATCH or AMBIGUOUS, never force a match. Multiple different external nodes can map to a single WPI port only if each independently meets name + geography rules. Output original source positions and WPI IDs, source country, and actual geodesic match distance for full audit.

Secondary diagnostics only: among otherwise unmatched external endpoints, nearest original WPI within 5km or 10km is a geographic proximity candidate with no verified original WPI port identity, never included in the primary actual voyage network.

## Observed direct 2020 source links
For every original valid 2020 from-to source row, count a matched WPI origin/destination voyage ONLY when BOTH endpoints independently have a unique verified WPI source mapping and are different original WPI ports. Same-WPI-port movements are tracked separately; missing endpoint, malformed time or ambiguous matches are tallied as unavailable, not absence of vessel journeys. Build exact observed origin WPI port -> destination WPI port voyage counts and corresponding island group link aggregates, with distinct source port pair and original island pair count. No original vessel identifiers are published; ship IDs used only indirectly to identify raw event schema. No route invented for unobserved original port pairs.

Output complete summary over original 194 source ports, all original 51 island groups and all 1275 possible unordered original island pairs; mark each WPI port and island with whether at least one verified external port endpoint was matched. A zero observed 2020 journey is a ZERO MATCHED OBSERVATION and NOT absence of actual travel or inter-island dispersal. Retain source page md5/sha256, all exclusion reasons, source node names, conservative matches and geographically close but name-mismatched diagnostic counts.

## No biological fit until source coverage qualifies
Before any butterfly outcome modelling, report primary actual-voyage coverage. A subsequent separately frozen predictive test may be considered ONLY if at least 15 different original island groups have at least one uniquely verified original WPI endpoint and at least 80 different unordered original island-group pairs have one or more directly linked original WPI port voyages. The threshold is a source-only minimum for the feasibility of a paired 51-island prediction, not a declaration that other island routes are absent. Do not loosen the matching criteria or threshold after reading butterfly outcomes. The true original WPI observational port cohort remains unchanged in any event.

## Limits
External AIS monitoring and derivation are geographically and vessel selective. The source CSV date-out/date-in and origin/destination ports represent the publisher's inferred vessel journeys, not independent confirmation of direct non-stop carriage or cargo. The 2020 network postdates earlier 2001–2010 plant and butterfly communities and is not evidence that a plant/insect was moved on the recorded voyages. Most original port names may not match exactly; failure is information about source compatibility, not a negative biological result. Original PR137 local graph placebo and PR140 cross-community positive/adverse findings retain their own verified source populations.
