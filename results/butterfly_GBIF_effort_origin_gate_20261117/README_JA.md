**解釈：** GBIF記録リストの累積的な共通化は残るが、索引記録件数をそろえると増加幅は小さい。生態学的な群集均質化が証明されたわけではない。これは同じ種×島の観測努力を完全補正した解析ではない：観測者、調査法、記録場所、データセット、記録媒体、時間帯、観測した群集の選択が未統制である。また初期と後期累積スナップショットは時間的に独立しない。異なる対象陸塊どうしの数値を補正効果として直接引き算しない。

## チョウ分布を植物やGBIFから推定しない判定ゲート

独立に判定する3軸：
1. **チョウの由来：** native / introduced / vagrant / unknown（実際の島単位）
2. **繁殖・定着：** established / reproducing / casual / unknown（成虫記録だけでは繁殖未確定）
3. **固有性：** single_island_endemic / archipelago_endemic / not_endemic / unassessed

- 島固有性には全域の**在来分布**を独立資料から確認することが必要。「GBIFで他島に出ていない」だけでは判定しない。群島固有と単一島固有も区別。
- 原始的な「島で記録あり」と在来を同一視しない。GBIFのcountry facetやHOSTSの在来寄主地理、WCVPの植物在来性から**チョウの在来分布を代入しない**。
- 根拠CSVを入力する場合、speciesKey×landmass_idを照合し、**島境界に対応する独立資料のURL**を必須化。固有種ラベルは**全在来分布の独立精査済みフラグ**が必要。根拠がなければ全てunknown/unassessed。
- 現状、チョウの独立在来性CSVは未作成。したがって**11,475セルの由来状態は未判定、317初索引も未判定**。正に確証された固有種が0件というのは**証拠結合状況**であり、固有種が自然界にいないという結果ではない。

候補の外部ソースは、島別蝶チェックリスト、受入分布や移入記録を記載した地域動物誌、学名を照合できる分類学的レビュー、繁殖・幼虫の一次観察記録。**事後の317初索引だけでなく同条件の非イベントも**資料精査対象にし、選択バイアスを避ける。
