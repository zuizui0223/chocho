## 科学的判断

1. **採用可能な新しい記述的な肯定結果：** 十分な形質照合が得られた22島では、在来植物相の方が外来植物相よりEuDiSの海流散布形態を持つ種の割合が高い傾向。これは島内の同一地域比較であり、別々の25島と70島の中央値を引いたものではない。
2. **まだ言えないこと：** 海流がこの植物を運んだ、港が外来植物を運んだ、海流と船のどちらが強い、またはその結果チョウが定着した。海流のベクトル、漂流・塩水生存期間、導入年代、元の漂流種子の供給源、歴史船便・実際の到着を直接計測していない。
3. **大きなバイアス：** EuDiSは**欧州在来植物中心**。非欧州島でのEuDiS一致は世界の在来植物全体の無作為標本ではない。島の在来25地域と外来70地域という適格性の差自体が地域・導入史・データ可用性に依存する。主効果や区間がゼロをまたがないことだけで全球海流メカニズムを確証しない。
4. **次段の物理モデル：** 高信頼形質の実データがある同じ島・植物集合に限定し、NASA OSCAR v2.0の方向付き日別表層流＋浮遊可能期間で **source→destination** の到達をモデル化する。距離・環境・供給源・地域/分類の偏りを条件にし、方向反転・地理偽連結と比較。WPI港数は船便の代わりに使わず、歴史的に実証されたOD船便だけ別に扱う。
5. **論文判断：** 全球植物経路の主張に自動昇格しない。この結果は統合GEB原稿の主文とは別の探索的供給側の実証準備段階として保持する。
