## Main result: native and introduced WCVP floras on identical islands

The original one-island-out test had **alien +4.239%, native −0.110%** out-of-sample MSE reduction from adding the source-authentic **undirected GSHHG uniform finite-volume electrical resistance** beyond geographic distance and accepted taxon richness. Crucially, that one-island-out test still trains on data involving every other island, including the partner island in each test dyad.

We reran the same **104 source-verifiable botanical island regions**, same **5,355 Jaccard-defined dyads**, original source-only deterministic **five hashed geographic folds** and ridge **alpha = 20**, but required **both island endpoints absent from training**. Only the **1,089 within-held-fold** dyads are scored; this is a more demanding but smaller evaluation population. Before changing the marine predictor, the original source **shortest-water-path** double-unseen gains were reproduced *exactly* (native +1.735107%, alien +1.857653%); both B and port-only P baseline MSEs, training/test counts and fold memberships were independently held identical. No response-optimized transformations or thresholds were chosen.

| MSE relative gain from adding **electrical resistance** (positive = better) | Native flora | Introduced flora |
|---|---:|---:|
| Previously reported 104× one-island-out | **−0.110%** | **+4.239%** |
| **New strict both-endpoints-unseen: equal five-fold mean** | **−0.044%** | **+2.735%** |
| Strict: 4,999-draw descriptive *same-fold* bootstrap 95% | **−0.984 to +0.431%** | **−1.649 to +5.508%** |
| Strict: pair-weighted MSE sensitivity | **−0.156%** | **+3.260%** |
| Strict: folds with circuit MSE lower than baseline | **3/5** | **3/5** |
| Strict: adding port-count pair proxy **after** electrical resistance | **−0.403%** | **−0.300%** |

**Origin comparison, conditional model and same-fold descriptive scale:** alien minus native *relative MSE gain* **+2.779 percentage points**, common 4,999-draw five-fold bootstrap interval **−1.693 to +5.400 points**. **This is not a confirmed statistically nonzero difference or proof of distinct transport routes.** Both single-flora intervals also cross zero in the five-fold strict test. Positive point estimates are not enough to say that an electrical circuit predictively transfers to *any* unstudied region with confidence.

## Model and interpretation boundaries

- **Flora:** accepted WCVP v13 contemporary native/introduced richness and accepted same-name Jaccard. The held islands' own richness marginals enter the model by construction; this is not an independent prediction of historical propagule arrivals.
- **Predictors:** baseline has log source distance (and quadratic), broad botanical Level1 equality, latitude gap, min/max native or alien accepted-richness, min/max island area. C adds original undirected **electric current analogue** generated by equal water conductivity; P adds a product of contemporary indexed World Port Index port counts. P is not actual shipping origin–destination or cargo.
- **Scientific decision:** a predictor-specific alien-flora positive association survives as a **directional point result** under harder geographical exclusion, while neither this result nor its native–alien difference is confirmed by the five-fold descriptive uncertainty; do not claim "currents assembled native flora, ships assembled alien flora" or that extinct/current contact explains island endemism.
- **Distinguish alternate marine geometry:** the earlier different GSHHG *shortest-water distance* strict transfer improved **both** native +1.735% and introduced +1.858% with broad intervals. Circuit and shortest-path outputs are distinct model inputs, not interchangeable estimated transport rates.
- **Butterflies:** original +54.9% global / +118.9% island potential resource opportunities and independently observed *Pieris cheiranthi* on alien *Tropaeolum majus* are unchanged; this marine-plant test estimates no butterfly colonization/fitness consequence.
