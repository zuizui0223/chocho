# 同一島の港と非港沿岸：2001–2010年の寄主候補と後年のチョウ記録
2026-11-09｜chocho 統合論文 PR #157 の探索的な追加検証／作業 PR #158

## 結論
**同じ島の遠方沿岸対照と比べても、港に既知のチョウ適合外来寄主植物が選択的に集中し、後年の蝶初索引が増すという独立した一般的対応は確認できなかった。** 外来寄主「候補」は全球の鱗翅目寄主カタログを用いたもので、その時代・島における現地外来性、および225蝶種別の食性一致を示すものではない。事前指定の3種類のチョウ×寄主だけは種別照合した。元論文の全球・島間の肯定結果は変更しない。

## 新しく取得・検証した規模
- GSHHG 2.3.7 元の島ID、NGA WPI 2019の原座標3,630港に固定。
- 以前に植物索引と1 km土地被覆が結合できていた79港／36島を起点に、2001–2010年の**港の**植物索引記録30件以上・島最大3港で候補27港／19島。そのうち同じ島で全WPI港から15 km以上離れ、港から15–125 kmにある新たな遠方沿岸対照を作れる24港／17島を使用（計48地点）。以前のESA WorldCover 2021の非港対照点そのものを再使用したわけではない。
- 港・非港とも中心から半径5 km。GBIF 2026-11-09再照会による2001–2010年の植物speciesKey索引、225固定蝶種の2001–2010年／2011–2017年／2018–2022年索引を取得。**蝶「初索引」≠真の新規移入／定着**。

## 島等重みの実測結果（港−非港）
| 結果 | 実測、17島単位の判定 |
|---|---|
| 先行外来寄主候補記録種数のlog1p差 | 平均+0.2488。港優位10島、非港優位6島、同数1。符号検定 p=0.4545。島bootstrap95%区間 −0.1784〜+0.7034 |
| 先行外来寄主候補の全植物索引種数に対する比率差 | 平均 **−0.01314（−1.31ポイント）**、島bootstrap95%区間 −0.04545〜+0.02011。港優位8・非港優位8・同率1 |
| 先行全植物のGBIF記録件数のlog1p差 | 平均+0.5509、港優位13・非港優位4、符号検定p=0.0490。ただし**港の記録数30件以上で事前に絞っているため**、この正方向は純粋な港効果を意味しない |
| 後年2011–2017年に地点で新しく索引された225蝶種数のlog1p差 | 平均+0.2895、港優位9・非港優位4・同率4、符号検定 p=0.2668 |
| 後年2018–2022年のlog1p差 | 平均−0.1648、港優位7・非港優位6・同率4 |

## 後の蝶記録差との対応
Spearman相関は港−非港の差を島内で平均し、**島（n=17）**を独立反復単位とした。pは10,000回の島入替え、区間は3,000回の島bootstrap。複数港を独立反復にはしない。

| 先行植物の港優位指標 | 後年蝶種数差の期間 | Spearman ρ | 島置換p |
|---|---|---:|---:|
| 候補寄主の素の種数差 | 2011–2017 | +0.168 | 0.512 |
| **候補寄主差から全植物種数差を差し引いた値** | **2011–2017** | **−0.085** | **0.749** |
| 寄主候補が全植物に占める割合の差 | 2011–2017 | +0.236 | 0.356 |
| 寄主の全植物比補正差 | 2018–2022 | +0.085 | 0.745 |
| 先行全植物種数差（対照） | 2011–2017 | +0.224 | 0.379 |
| 先行全植物記録件数差（対照） | 2011–2017 | +0.202 | 0.435 |
| 先行チョウ種数差（対照） | 2011–2017 | +0.119 | 0.648 |

両側の先行植物記録が10件以上である港対照が少なくとも1つある島16に限った参考感度では、全植物比補正差 vs 2011–2017年の蝶記録差はρ=+0.090、p=0.730。ただし**この16島内の他の低努力ペアを除外して再計算したものではない**。

## 事前指定3種類の蝶×既知寄主の種別照合
- *Colias croceus*／*Medicago sativa*
- *Colias hyale*／*Medicago sativa*
- *Nymphalis antiopa*／*Alnus incana*

48地点×3指定蝶＝144地点×蝶行。2001–2010年の現地対象寄主索引がある地点×蝶は24行。うち先行蝶索引がなく2011–2022年に後年蝶索引が発生した種別一致は**6行（港5・非港1）**。先行蝶索引なしの検出リスク行に限定すると、港は先行適合寄主がある13行中5、非港は6行中1に後続蝶索引がある。港・蝶・島内の非独立性、寄主の現地歴史的外来性不明、後年蝶の採集努力差のため、**5:1を港の定着促進率とは解釈しない**。

## 主張できること／できないこと
1. **観察できたこと：** 港では一部の外来寄主「候補」の索引が多く、具体的な3組には先行植物と後年蝶の同一地点索引例がある。一方、全植物の記録数も港寄りであり、寄主固有の超過とその後の蝶の港優位の一般的関連は未支持。
2. **未確認：** 島ごとの真の外来原産区、2001–2010年の移入年、実際の卵・幼虫の食性／繁殖成功、船舶の搬入、真の蝶定着、非港対照の完全な生息地・都市化・記録努力マッチング。
3. **査読への線引き：** この17島の探索結果は全球225種×51島や全球1,596港の別母集団結果と足したり、主要肯定結果の検証成功／失敗に読み替えたりしない。地域外転移可能な港効果の確証はまだない。
