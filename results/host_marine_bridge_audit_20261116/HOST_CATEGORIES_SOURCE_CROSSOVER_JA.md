# 2026-11-16｜在来・外来寄主の港周辺記録と後年の蝶GBIF索引

**判定**：同じ蝶種×島で、在来寄主が2001–2010年に港周辺で記録された組合せほど、2011–2022年に蝶が再索引される正の関連が残る。外来候補寄主のみの組合せでは、1700–2010年の蝶の索引履歴を調整した後、明確な正の関連は確認できない。これは**索引記録の連関であり、実際の幼虫利用、個体群定着、植物の移入履歴ではない**。

## データと設計

- 固定225種×51原GSHHG陸塊 = 11,475種×島。元の蝶リスト・地理は変更していない。
- 植物：2001–2010年の原WPI港5km GBIF植物索引、HOSTS既知幼虫寄主対応、WCVP現代地域区分での在来・導入候補・未解決。地元の移入年や実際の給餌を表さない。
- 蝶：独立保存済み1700–2000年の全11,475組の歴史索引（2026-11-14 Actions #43586278558）＋2001–2010年の索引を、先行記録の有無として調整。
- 応答：2011–2017年、2018–2022年のどちらかに一度でも蝶GBIF索引があったか。**真の定着・新到着ではない**。
- 主解析：港植物索引のある36島（植物記録10件以上）×225種＝8,100組。蝶種・島固定効果と先行蝶索引の有無を含む線形確率モデル。島・蝶種の二方向クラスタによる近似的区間。
- 参照群は「既知寄主が港の索引にない」。実際に寄主が**不在**と確認された群ではない。

## 元の肯定結果との接続

1. 全球239種、既知食草の人為再分配に伴う潜在的資源機会+54.9%、島の相対+118.9%はそのまま保持する。資源の「利用可能性」は真の蝶記録ではない。
2. 155種の既知蝶種で寄主情報を追加するとGBIF記録予測誤差が+4.12%減った別解析と、本解析の**在来寄主記録が後年の蝶記録に対応する**という結果は整合する。ただし155種のモデルは在来・外来別に寄与を分けておらず、効果量の加算や一つの追認とは扱わない。
3. 港の多い地域で外来植物相全体が豊富である正の関連を保持する。ただし港の植生による導入寄主の特異的集積や、船による幼虫移送を新しく立証したことにはならない。
4. 51島の海洋・寄主モデルの条件付き予測情報は保持する。一方で交互作用2項を足したMSE改善 +0.343% は保存済み島foldの区間 −2.798〜+3.219% と不安定で、**寄主×海アクセスの相乗作用は未確認**。

**生態学的な位置づけ**：既知寄主植物の広域移動が生み出す「潜在的資源機会」と、GBIF蝶索引で見える「利用・生息の痕跡」を同一視できない。港の外来寄主のみの記録では明瞭な再記録増分が出ず、在来寄主の文書化された場所との非対称性が数量化された。ただし蝶による利用・繁殖の現地証拠は未取得。統合GEB論文の補足・解釈境界として用い、主体を新規植民の因果主張に置き換えない。
