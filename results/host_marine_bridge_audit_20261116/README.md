## 51島・5モデル・2応答の再計算

入力: [元の保存済み島別MSE](../island51_host_circuit_joint_20261106/model_fold_losses.csv)、Git blob SHA: d2df6457895091a3652c6cdad3fd081238dfdcf4。

G = 海洋幾何の基準、H = G+候補外来寄主類似度、C = G+AIS/風に基づく海洋指標、HC = HとCの説明変数を統合、I = HC+寄主×海洋指標の2交互作用項。

51島×5モデルに完全な保存済みMSEがあることを確認し、LCG乱数種20261116で島を単位に9,999回ペア再標本化（百分位法）を行った。以下は**記述的区間**で、モデルの再学習も独立した島での再現実験も行っていない。各foldは島間のペア・学習組を共有する。

先行蝶群集Jaccardの同モデル比較では、H→HCは**−1.334%**（−3.168〜−0.203%）、HC→Iは**−0.124%**（−4.113〜+3.367%）。海洋指標の追加価値は先行期と後期で同じではない。

予測誤差の非加算性の補助診断は (HC−H−C+G)/G×100 = **+0.666%**（−0.296〜+1.502%）。符号は追加予測利得の重なりを示すにすぎず、**生態学的な負の相互作用を意味しない**。

## 判定と次の識別条件

1. **肯定結果として保持:** 特定の保存済み51島データにおいて寄主・海洋地理は条件付き予測情報を含む。特に後期のAIS/風追加は島再標本化でも正方向。
2. **相乗・因果への昇格はしない:** 明示的な交互作用の改善は小さく、区間はゼロをまたぐ。別の225種×51島の統一歴史リスク解析でも導入寄主×海アクセスの正の交互作用は支持されず、当該寄主記録のある新索引イベントは2011–2017年3件・2018–2022年5件のみ。[長期履歴結果](../port_host_ocean_long_history_20261114/README.md)。
3. **真の移入と混同しない:** もとの2001–2010基準で新索引とされた317件のうち145件は2001年以前にも記録済み。[全11,475セルの歴史監査](../pre2001_full11475_risk_20261114/README.md)。
4. **次の生物学的証拠:** 同一の蝶種×島に対して、導入寄主の島内導入年代、幼虫による寄主利用、独立に確認された新定着・繁殖、記録努力、到達可能性を整合させる必要がある。現在は港・都市・下水を含む媒介連鎖の因果効果は未同定。
