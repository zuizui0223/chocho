# Published AIS source quality addendum

**The large AIS values are present in the published native TIFF. The sampled derived 0.5° values reproduce the specified overview means accurately.** This source-only audit changes no frozen input, protocol, biological model or prediction result.

## Findings

- The checksum-pinned commercial ZIP's native `int32` band has scale **1**, offset **0**, and NoData **2,147,483,647**. Its original auxiliary metadata reports maximum **62,652,999** and mean **266,363.705**. These values were not generated by the new circuit workflow.
- The audit sampled **39 fixed geographic locations**, comprising ten diagnostic locations and a five-latitude by six-longitude grid with one duplicate removed. Across **638,976 native pixels**, the maximum was **57,394,320**, and **43,370** exceeded one million. No negative values or NoData sentinel appeared among the valid sampled pixels.
- All **159,744** compared first-overview pixels exactly matched the top-left native pixel of the corresponding 2×2 block, with **zero mask disagreements**. The sampled overview therefore behaves as nearest-neighbor selection, not 2×2 averaging: **41,099** compared values differed from their native block mean.
- For each of the **39 sampled 0.5° cells**, independent arithmetic weighted the original overview pixels by their exact rectangular overlap with the destination. All saved coarse values agreed within float32 precision: maximum relative error **4.6823×10⁻⁸**, maximum absolute error **0.36875** on million-scale values. This check used no GDAL resampling call.

### What the check does and does not establish

The pipeline faithfully calculates an **overview-derived published AIS density index**. It does not independently establish the physical calibration of the source's very large values. The official [World Bank catalogue](https://datacatalog.worldbank.org/search/dataset/0037580/global-shipping-traffic-density) and [source readme](https://datacatalogfiles.worldbank.org/ddh-published/0037580/5/DR0084213/readme.txt) define the data as hourly AIS position reports accumulated per native 0.005° cell, including moving and stationary vessels, during January 2015–February 2021. Neither the inspected raster scale/offset tags nor these definitions supplied an alternative scaling rule. No unverified rescaling, bit manipulation or value clipping was applied.

Nearest-neighbor overviews also approximate the native spatial average. Among the **35 sampled coarse cells with a positive native mean**, the median absolute relative difference between the overview-derived and directly averaged native values was **19.39%**; signed differences ranged from **−100% to +300%**, including sparse cells. Examples were Singapore **+0.34%**, English Channel **+1.01%**, Tokyo Bay **−0.57%**, and the sampled open South Pacific cell **−40.17%**. The saved coarse grid is therefore not claimed to equal a full-native-cell average. This addendum measures that approximation without selecting a new biological model or retrospectively rewriting the frozen protocol.

The auxiliary histogram totals **2,147,483,645**, whereas the native raster contains **2,448,059,988** pixels. The receipt preserves this metadata discrepancy; the sampled pixel checks alone do not establish its cause or identify a pixel-data defect. Checks at sampled locations do not certify every source pixel or satellite reception coverage.

## Evidence and reproduction

- [Machine-readable receipt](published_AIS_source_quality_receipt.json): original tags, source checksums, archive-member CRCs, sampled distributions, and all 39 native/overview/coarse comparisons.
- [Portable source-only reproducer](audit_published_AIS_source.py): accepts the verified ZIP, its extracted native TIFF and overview, and the frozen coarse grid. It does not load any biological outcomes.

The native and external overview files require approximately **13.1 GB** of temporary extracted storage. Extract the original archive with a CRC-validating ZIP reader before running the audit. From the repository root, with the analysis dependencies installed:

```bash
mkdir -p /tmp/chocho-ais-source-quality
curl -fL \
  'https://datacatalogfiles.worldbank.org/ddh-published/0037580/5/DR0045405/shipdensity_commercial_.zip' \
  -o /tmp/chocho-ais-source-quality/shipdensity_commercial_.zip
unzip -q /tmp/chocho-ais-source-quality/shipdensity_commercial_.zip \
  -d /tmp/chocho-ais-source-quality/source
python results/island51_observed_ocean_circuit_20261106/ais_source_quality/audit_published_AIS_source.py \
  --source-zip /tmp/chocho-ais-source-quality/shipdensity_commercial_.zip \
  --extracted-dir /tmp/chocho-ais-source-quality/source \
  --coarse-grid data/exploratory/island51_observed_ocean_20261106/ais/commercial_AIS_mean_0p5deg_2015_2021.npz \
  --out /tmp/chocho-ais-source-quality/reproduced_receipt.json
```

The audit first checks the archive SHA256 `0cfdce41d9934982bbc8f16bd92ce7545cc088839327cbaa9b0ed1469dda31e8`. Native comparisons explicitly disable discovery of the external overview; the overview is opened separately. The receipt records the frozen coarse-grid hash, source metadata and sampling locations. Original large rasters are not committed with this addendum.
