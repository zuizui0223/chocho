# LGM資源連結性の寄主特異性：v0.8陰性対照の独立識別可能性監査

**2026-10-20 / 解析状態：探索的・陰性／支持不足。** 寄主の歴史的分布、昆虫の氷期存在地点、分散実現、遺伝的分断の確認ではない。過去のTTF「既知の実寄主 vs 現代気候を揃えた別植物」v0.5陰性対照は、今回も凍結したまま変更しない。

## 問い

元の現代昆虫採集地点を0BP・21kaのPMIP4氷床／陸地と在来寄主植物の潜在気候適地へ仮に置いたとき、**本当の記録寄主の適地連結性の変化は、現代気候だけで事前に選んだ別植物よりも体系的に大きいか。**

比較単位は各種の**同じ元の地理的地点ペア**である。実寄主・別植物のそれぞれ0BPと21kaの計4条件すべてで、ペア両端が同じ物理的陸地連結成分にある潜在適地へ50/100/150 km以内に対応づけられる場合に限って比較した。対応不能ペアは「分断」としない。

## 動かしていない原本

- TTFで以前に**0BPの観察気候だけ**を使って選んだ別植物2,108組（335昆虫のうち、既知寄主と別植物の在来域・現代気候モデルが揃う292昆虫を結果開封前に認定）。
- WCVP在来域内の現代観察で学習した416植物の凍結0BP・21ka予測マスク、原本PMIP4 ICE-6G_Cの0/21ka氷床・陸地マスク。
- 同一種について2時代・2気候外挿仕様・3距離の比較。元の凍結出力は植物群別12,648行と昆虫種別1,752行。
- 原本全ファイルSHA256検証：群別 `2574cd7c6b346720733c232b2044e9c4d88407b0d597264b5ffcf115ef7cb261`、種別 `d5e5e374e89eeac701c449e05edd775e7b0f0014c714b965a03378af0c7fa4b4`、まとめ `7fcd67aa367d138960aa7d94e6482139a5678a1c2a4be08a38dcbe4264bc55`。
- 今回追加したv0.9監査は**上記の確定済み結果を再集計しただけ**で、宿主選択、氷期の新しい格子予測、遺伝データ、p値最適化は行っていない。

## 100 km主解析：実寄主固有の優位性はない

| 種別・群別の状態 | 件数 |
|---|---:|

| 4条件すべてで同じ地点ペアが少なくとも1組ある昆虫 | **226種** |
| 検証できない昆虫 | **66種** |
| 実寄主のほうが大きく同一成分への接続を失う昆虫 | **62種** |
| 別植物のほうが大きく同一成分への接続を失う昆虫 | **79種** |

比較可能な226種は**173種類の記録寄主植物組合せ**と181属に属する。さらに「5ペア以上の対照群が4組以上」の**事後的な安定性記述**では176昆虫種・133寄主組合せが残り、実寄主の喪失が大きい56、別植物が大きい67、差0が53。**種別効果の中央値はいずれも0。**

気候外挿を許した100 km感度分析でも、比較可能227種のうち実寄主の喪失が大きい61、別植物が大きい81、差0が85で、種別中央値は0。50 km、150 kmの条件でも元の陰性対照の方向が反転して寄主固有の正の主張になることはない。

## 「0」は生物学的な等価性の証明ではない

共通する地点ペアを1組も持たない608群は、**情報なし（評価不能）**である。比較可能群でも563/1500群に差がなく、地点ペア数の中央値は13である。つまり、格子が0.5°と粗いことや比較ペアの厳しい条件による離散的な0が相当ある。これらを「寄主特異性が存在しない」という効果量0の証明へ置き換えない。

種別の実寄主−別植物のLGM連結性差と、実寄主−別植物の**現代0BPの連結性差**はSpearman **ρ≈−0.532**で相関した。ただし「LGM−0BP」を計算する式に現代ベースラインが共通して含まれるため、この負の相関を独立した生態学的メカニズムや回帰への回帰として説明することはできない。また当初の植物群のマッチング対象は**現代の観察気候の平均・ばらつき**であり、適地パッチの0BP連結性自体を完全に揃えたものではない。

属を単位に再標本化した**説明用**2,000回ブートストラップでは、226種の種別平均差の95%区間は**−0.0208〜+0.0353**、中央値差の区間は**0〜0**。166種等の都合よい部分集合へのしきい値変更は行わない。この区間は植物モデルや対照植物の属を越えた共有依存を表現せず、検証的な信頼区間ではない。

## 生態学の現在地

今回までに支持されるのは、**PMIP4の古地理とCHELSA気候の条件下で、潜在的な植物資源景観の大きさ・まとまり・採集地点間の接触に種間差が生じること**までである。実寄主と、あらかじめ現代気候を合わせた**別植物を区別する歴史的連結性の利得は示されなかった。** この陰性対照を閾値や植物群の後付け変更で肯定へ戻さない。

氷期の寄主占有史と植物別分散能力を復元できておらず、実際の昆虫の氷期存在地点や遺伝的分断に対応させていない。元のTTFの遺伝的応答は `NOT_EVALUABLE_EMPIRICAL_RESPONSE` のままであり、次に投稿を目指す場合はこの**潜在気候景観の比較マクロ生態**として限定するか、別の独立データ（考古植物／花粉化石・地域在来域・古気候下占有の不確実性、および新規遺伝データ）を事前資格認定して別研究として検証する。
