# chocho — Synthesis and source archive index (2026-11-18)

**One active paper direction:** human-assembled plant communities reorganize *potential* known-host resources for butterflies; the low native-host baseline amplifies relative island gains. Ports, island sea geometry, larval host use, and independent butterfly records supply distinct ecological evidence layers. A ship→plant→larva→new-population causal mediation has **not** been identified.
