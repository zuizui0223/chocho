**2026-10-27. Original-source exploratory extension of chocho PR #85, now PR #86 (draft).** A source-bounded reanalysis and two external case-evidence validations were **executed successfully** in [GitHub Actions #40522850143](https://github.com/zuizui0223/chocho/actions/runs/40522850143), six independent synthetic tests passed. ## 1. A widespread resource condition hides very different local host portfolios

Input is a *fixed source-verified* 18 exact chocho-239 butterflies × 35 Zenodo 2024 independently alien-established species×receiving-zone positive records intersected with original accepted host WCVP wild botanical footprint. Its original source-only aggregate JSON SHA256 `5ef806a12f8750572c5303bce40ea5ffa58ad56138ae8cdb75806ff7cbbb8efc` is checked before any calculation, and previous 35/24 strict/3 Okinawa-botany-proxy/8 unmappable geographic status remains immutable.

Of **24 strict botanical source-comparable positive recipient records** (14 distinct butterflies, seven independent named receiving geographic zones), **all 24** have some **introduced-wild WCVP source host** within the recipient, but the number of accepted plant species per butterfly ranges from **1 to 27**, median **8**. Of those original 24: **1** has only one such introduced-wild host, **4** have ≤2, **8** have ≤3, **10** have ≤5 and **15** have ≤10. **Nine** have at least one source native-wild host as an additional potential resource; 15 have only source introduced-wild host species (not evidence the butterfly biologically cannot feed on native or cultivated-only plants).

Among all 24 butterfly×receiving-zone source portfolios, there are **237 accepted introduced-wild host plant memberships** out of **872 original accepted globally documented HOSTS plant memberships** (a membership-weighted **27.18%**); the median *per-receiving-zone original accepted larval host repertoire* retained as regionally introduced-wild WCVP sources is **30.51%**, with minimum **5%** and maximum **71.43%**. These source counts are membership/taxon numbers, **not plant biomass, consumer diet fraction, field occupancy or species-specific resource density**. A globally accepted host missing from a WCVP zone can still be cultivated, transient or taxonomically differently named locally; don't call it impossible to use in the wild.

Five original butterflies have ≥2 **strict** independently recorded alien established receiving-zone cases. The exact same original accepted worldwide HOSTS pair list is used in every receiving zone, so differences below are geographical source flora filtering (and record sampling), not among-species global host-breadth trait differences:

| Butterfly | Source-global accepted hosts | Source positive receiving zones | Recipient introduced-wild host count range |
|---|---:|---:|---|
| *Pieris rapae* | 53 | 5 | **3–23** (7.67-fold) |
| *Lampides boeticus* | 38 | 3 | **5–11** (2.20-fold) |

| *Pieris brassicae* | 28 | 3 | **10–12** (1.20-fold) |

For *Pieris rapae*, source Ogasawara has three documented introduced-wild host species while source Japan-country union has 23; these spatial source grains differ significantly (small islands versus larger country, and Japan country includes many islands). This is **not** an island-specific causal plant host bottleneck unless normalized for source flora size, cultivation and local encounter abundance and observed wild larvae.

## 3. The independently observed arrival-channel case: *Calpodes ethlius*, Galápagos

[Charles Darwin Foundation Galápagos Species Database](https://datazone.darwinfoundation.org/en/checklist/?species=7118) lists:
- Butterfly `Calpodes ethlius`, **introduced-established**, first record **1987**, introduction mode **accidental**;
- original introduction pathway: **contaminant on plants, including seeds and plant-associated material**. This is a **generalized categorized pathway**, NOT an exact 1987 interception of an egg or larva on a known live nursery host;
- within original chocho, globally documented accepted larval host plant list **five** plant species, **three** recorded by original WCVP as introduced-wild in the exact GAL botanical region, **zero** native-wild. The Galápagos 1987 source positive and original WCVP wild host geography are the same botanical recipient (not inferred from Ecuador mainland).

Independently, the CDF [Galápagos *Canna indica*](https://datazone.darwinfoundation.org/en/checklist/?species=870.) plant entry lists it as **introduced-established via intentional agriculture/horticulture**, first reported in that database **1991**. The plant entry cites some historical botanical sources older than 1991, so chronology should NOT be interpreted as if Canna was demonstrably absent in 1987. The mismatch first butterfly record 1987 versus botanical source first record 1991 is a concrete **warning that modern host distribution and first report date are not historic resource availability**. The source entry does not confirm that any specific *Canna indica* consignment carried the butterfly, nor that this exact plant species is one of the three WCVP/accepted worldwide HOSTS combinations without direct botanical name check.

Independent broad host literature [University of Florida *Calpodes ethlius*](https://ask.ifas.ufl.edu/publication/IN289) documents larval hosts in Cannaceae (*Canna*) and Marantaceae (arrowroot); a [Galápagos Lepidoptera ecological account](https://orca.cardiff.ac.uk/id/eprint/56156/3/U584917.pdf) discusses *Calpodes* associated with Cannaceae. The original Galápagos larva+named individual plant and **egg-on-imported-commodity** pair have NOT been independently traced. Hence this is **an invasion involving a plant-contaminant pathway category and recipient-introduced potential host resources**, not an empirically verified single plant taxon coupling both arrival and realized larval feeding.

## 4. Contrasting recipient-native larval host route: *Leptosia nina* in the Nansei/Okinawa proxy

The original established-alien 2024 source reports `Leptosia nina` in Okinawa from **1988**. Since the original botanical Nansei-shoto unit (NNS) is broader than political Okinawa, this case remains **botanical proxy only**, outside strict 24 (one of original three Okinawa proxy cases). The source original globally accepted ten host taxa yield **two native-wild WCVP NNS hosts, zero introduced-wild host taxa**.

A historical Japanese [Iriomote 2003 host photograph](https://syokusou.choumusubi.com/07gyoboku.html) describes wild *Leptosia nina* larva on a local plant called ギョボク (`Crateva religiosa` in that archive). Modern botanical sources such as [Kew POWO](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:1014207-1) identify the recognized indigenous Nansei Crateva taxon as `Crateva formosensis`, but the photographed individual has **no documented voucher taxonomically reconciled to that accepted species**. It is evidence at the original local *Crateva* plant name/taxon grade, not an audited modern species-specific host pair.

The butterfly's arrival route is **unknown**; natural long-distance butterfly dispersal could generate a local arriving consumer independent of any horticultural carrier. Thus this case can show actual local wild larval use on a plausibly recipient-native plant genus, but **cannot prove its evolution, vector or dependence on solely native hosts**.

## 5. Mechanistic decision

The independent sources demonstrate that **arrival and postarrival resources can be measured at separate biological stages**, and source insect pathways are not identical to the plant propagation status. More specifically:
- geographically restricted host portfolios may be much narrower than globally documented dietary breadth even in independently alien-established positive butterflies;
- an external authority can provide an accidental plant-associated *arrival pathway class* for an alien butterfly, but without a traced shipment-to-actual-host-larval link it is a source pathway, not proof of causal host co-transport;
- a colonizing butterfly's actual local larval resource **may be recipient-native** (Okinawa botanical proxy case) rather than an introduced plant; still no direct consumer arrival route is known;
- CDF introduced Canna plant and introduced Calpodes butterfly *first-report years* cannot be used as if host introduction chronology or consumer arrival chronology were verified experimental treatment timing.

At present the two mechanistic cases deliberately have **different geography verification tiers** (exact Galápagos vs Okinawa→Nansei proxy) and **are not used to estimate a global resource–arrival coupling coefficient, frequency of orphan opportunities or butterfly competition**. Source accepted HOSTS larval host name identity, plant country distributions and introduced butterfly status are each separate evidence layers.

**Next decisive data requirement:** trace at least one verified original plant-species-specific carrier import (plant/cargo type, insect egg/larval taxon, origin-destination, year) preceding recipient wild-larval reproduction, and find a matched independently observed imported insect without subsequent establishment at similar commodity inspection effort. Only then can the arrival × available-host interaction be estimated rather than postulated.
