## 1. 最も強い生態学的な問い

> ホソオチョウが加わると在来ジャコウアゲハの次世代生産が落ちるのは、単なる幼虫個体数増加や時間的な食草不足によるのか。それとも、同数の同種幼虫を追加した場合とは異なる影響が、食草を補充しても残るのか。

比較対象：
- 在来蝶 **ジャコウアゲハ（Atrophaneura alcinous）** を固定した初期コホートの焦点種とする。
- 異種 **ホソオチョウ（Sericinus montela）**、同種追加ジャコウアゲハ、追加なしを比べる。
- 共通寄主は**在来の Aristolochia debilis（ウマノスズクサ）**。これは移入「蝶」の効果であり、移入「寄主植物」の実験ではない。

先行研究：
- Nakahara et al. 2020, `10.1111/ens.12399`: ジャコウアゲハの食物量×同種幼虫密度で、追加脱皮・共食い・病気・蛹休眠などが異なることを既報。
- Hashimoto & Ohgushi 2023, `10.1002/ece3.10164`: 異種密度によるジャコウアゲハ生存の抑制と終点食草量の非自明な関係を既報。
- Takagi & Miyashita 2008, `10.1603/0013-8746(2008)101[392:HPQIDI]2.0.CO;2`: 同じ蝶における葉質と休眠の先行実験。
- 前段階の2026-10-14京都原データ監査は、両種の齢期を揃えた摂食曲線の重なりが約88%であり、時間差だけに新規性を依存する設計の優先順位を下げた。

## 2. 6処理の無作為化（2 × 3）

| 補充処理 | 追加なし | 追加ジャコウアゲハA | 追加ホソオチョウS |
|---|---|---|---|
| 自然の食草供給 | NATURAL_NONE | NATURAL_ADD_A | NATURAL_ADD_S |
| 補充葉へアクセス可能 | SUPPORTED_NONE | SUPPORTED_ADD_A | SUPPORTED_ADD_S |

- **無作為化単位：ケージ全体**。一つのケージに複数の鉢がある場合も、全鉢で1つの反復。
- 各ケージの「元からいる焦点A幼虫数」を固定し、区別可能な個体IDを与える。**追加同種Aと焦点Aを混同してはならない**。確実な識別・追跡手段がない場合は実施前のNO-GO。
- 同種追加と異種追加はまず同じ**個体数**とする。ただしAの総摂食量はSの約2.6倍なので、同じ個体数は同じ消費重量を意味しない。真に質や直接干渉を識別するには、別に消費重量マッチの処理または独立に操作した植物傷害・葉質対照が必要。
- 事前に適格とした実在のケージだけを投入し、食草のバッチ・母系・実験開始日（可能なら独立した個体群）ごとに、6処理を等数含む**完全ブロック**で割付。
- 現在の無作為化コードは、実データがない状態では結果を生成しない。適格ケージ数や実現可能な独立ブロック数から検討し、**先行30ケージを新しい6処理の反復と偽装しない**。

## 3. 食草を操作するときの注意

最初の仮説は**一時的な実際の可食組織不足**である。試験終了時の落葉・食痕の程度では検証できない。

補充の有無にかかわらず、3〜5齢期を含む予め決めた観測機会に、ケージ内で実際に食べられるウマノスズクサ葉の面積・重量・組織段階・供給量を記録する。閾値の `food_floor_cm2` は初期コホートの摂食量と新鮮葉面積・乾重の関係から**独立パイロットで較正**する。原著の総摂食 mg を単に適当な cm² に換算してはならない。

最も強い実験対照は、自然供給処理にも**同じ由来・葉齢・量の補充候補葉を、食べられない状態で置く**などして、作業・新葉の揮発成分・葉齢を可能な限り合わせる方法。ただし障壁が移動・湿度・利用面積を変える可能性もあり、完全な質の対照とはいえない。

個別の `donor/source` 台帳で、寄主植物の由来、**株自体の成熟度**、採葉した節位、葉齢、採取時刻、鮮重・乾重、可能ならN・C/Nやアリストロキア酸関連測定を保存。補充が若葉の質まで変える限り「葉の量だけの効果」とは呼ばない。

**資源達成の事後的選別は禁止。** 結果として補充に成功しなかったケージ、幼虫が全滅したケージも、割付通りのITT集団に残す。3〜5齢期の生存者がいなくなったケージで「高齢幼虫期の食草不足なし」と記録しても、以前の不足を否定できない。

## 4. 主要・副次的推定量

ケージcに最初に割り付けた**焦点A幼虫**のうち、事前固定した追跡期間に飛翔可能な成虫が確認された割合を `Y_c` とする。各割付ブロック内で各処理のケージ割合を等重みで平均し、次いで独立ブロックを等重みで平均する。幼虫や寄主鉢を独立の実験反復にしない。

予定した**唯一の主対比**：

```text
D_identity×support =
    (Y_SUPPORTED_ADD_S - Y_SUPPORTED_ADD_A)
  - (Y_NATURAL_ADD_S - Y_NATURAL_ADD_A)
```

- `D > 0` は「食草補充によって、S追加の影響がA追加の影響より相対的に好転する」ことを意味する。ただし摂食量の違いも含む総介入の効果。
- `D = 0` は資源媒介効果が存在しない証拠とはならず、同種・異種への補充効果が等しい可能性もある。
- `D < 0` も適応的な排除とは呼ばず、補充処理による組織品質・行動・病原体などを候補にする。

**重要な副次対比**：`Y_f,S-Y_f,none`（同じ食草条件内の異種追加の総効果）、`Y_f,A-Y_f,none`（同種追加の総効果）、`Y_f,S-Y_f,A`（個体数一致の追加種の差）。各食草条件での**6処理の絶対成虫生産率**、全初期個体数、ケージ数と原始データのまま報告する。

**欠測と生きている休眠蛹の扱い**：追跡終了時点に飛翔成虫でない蛹を一律「死亡」にしない。確認死亡、飛翔不可能成虫、生存休眠蛹、生存して羽化待ち、追跡不能を分離。将来的な羽化可能性の上限・下限を6処理すべてで計算し、符号付き主対比の**真の最悪ケース区間**を得る。期間内の羽化率と生涯の羽化率を混同しない。蛹の越冬後の追跡期間・温度・日長・診断法は事前固定が必要。

## 5. サンプルサイズと解析の停止規則

- ブロック単位で出力する点推定は**記述**である。10独立ブロック未満では参考のブロック再標本化区間を表示せず、10以上でもその区間は検出力保証ではない。真正の推論は独立パイロットのケージ間分散に基づくサンプルサイズ計画と誤差構造の検討が必要。
- 10ブロックはCIの**表示上の下限**に過ぎず、「60ケージで十分な検出力がある」という主張ではない。同一母系・単一個体群から10ブロックを作っても個体群一般化はできない。
- **GO:** 同じ育齢・個体数のケージで実際に食草可食量を追跡でき、焦点・追加Aの識別が検証され、適法なホソオチョウの完全な封じ込め飼育と全蛹の追跡が可能で、独立したブロック間変動をパイロットで評価できる。
- **HOLD:** 食草補充で可食量や葉質の分布が交絡し、段階ごとのデータ欠測が多い。ITTは計算可能でも生態的媒介は特定できない。
- **STOP:** 追加同種と元の焦点幼虫を区別できない、異種蝶の封じ込め・許可がない、休眠蛹を含む元コホートの行方を追えない場合。生存者だけでの解析に置換しない。

## 6. 実行・ファイル形式（新規の観察データがある場合のみ）

`scripts/randomize_kyoto_six_arm_identity_food.py` に事前承認済み実在の適格ケージ一覧を渡す。

```bash
python scripts/randomize_kyoto_six_arm_identity_food.py \
  --inventory eligible_cages.csv \
  --allocation randomized_cages.csv \
  --receipt randomization_receipt.json \
  --seed <事前に記録した整数>
```

入力列の順序：`cage_id,block_id`。6処理のバランスが不可能なブロックは拒否する。seedと元一覧・割付CSVのSHA256を保存。

解析には以下の4つの実測CSVを**列の順序を固定して**渡す：

```text
randomized_cages.csv
cage_id,block_id,treatment,food_support,added_group,random_seed,design_version

assignments.csv
cage_id,block_id,treatment,food_support,added_group,recipient_a_initial_n,added_larvae_initial_n,food_floor_cm2,expected_n_resource_visits,donor_source_batch_id,study_season

fates.csv
cage_id,larva_id,cohort_role,species,fate

resource.csv
cage_id,observation_datetime,recipient_a_alive_n,recipient_a_late_instar_alive_n,added_a_alive_n,added_s_alive_n,accessible_leaf_area_cm2,edible_fresh_mass_g,accessible_leaf_area_added_cm2,leaf_stage,added_leaf_stage,leaf_source_batch_id,sham_handling_done
```

`cohort_role` は厳密に `focal` または `added`。同種追加の個体も `added` として記録し、焦点Aの分母に混ぜない。元から割り付けた**全幼虫**を入れる。状態は `flight_capable_adult`, `dead_immature`, `pupa_confirmed_dead`, `adult_nonflight`, `diapause_alive`, `pupa_alive_pending_emergence`, `lost_to_followup`, `other_documented` のいずれか。

`resource.csv` の日時は必ずUTCオフセット付きISO8601。真の葉面積ゼロは文字列 `0`、観測できなかった場合は空欄。補充した若葉の面積は実際に**食べられるように追加した**面積のみを記録し、対照ケージの食べられないsham葉とは分ける。観測回数が欠ける場合は入力不適格として止め、任意の個体・ケージだけ削除しない。

```bash
python scripts/analyze_kyoto_six_arm_identity_food.py \
  --allocation randomized_cages.csv \
  --assignments assignments.csv \
  --fates fates.csv \
  --resource resource.csv \
  --receipt results/kyoto_six_arm_v01.json
```

コードとCIのテストでは**合成の非生物学的なCSV行のみ**を使い、生きた昆虫の割付や羽化実績は一件も作成しない。

## 結論と原稿の線引き

これは「食草の供給量・利用可能性が同種競争と異種競争の**効果の差**を変えるか」を検証する京都の**実験生態学**であり、「寄主が存在する範囲」を比較するGEB論文とは独立させる。食草補充と追加種の効果が明瞭でも、質・摂食量・接触を独立に操作しない限り、それらを「競争者特有の直接干渉」や「外来寄主がチョウを増やす証拠」とは言わない。
