# 京都の共通寄主：若葉が「存在」から「摂食できる資源」になるまでの検証ゲート

**2026-10-14｜原著本文に基づく実験前 feasibility pilot。飼育実験・葉重量測定の新規結果はゼロ。**

**位置づけ:** Draft PR #40 の検証前提を一段だけ具体化する。GEB論文PR #38／`main`には触らず、既存の「S追加×食草アクセス補充」を主仮説から勝手に入れ替えない。京都の若葉・成熟葉組成による競争修飾は独立した代替仮説・後続実験候補として扱う。

## 1. 原著で確認できる決定的な制約

Hashimoto & Ohgushi (2023), *Ecology and Evolution*, DOI [10.1002/ece3.10164](https://doi.org/10.1002/ece3.10164), Discussion §4.2:

> ホソオチョウ *Sericinus montela* の孵化直後の幼虫は成熟葉をほとんど食べず、ジャコウアゲハ *Atrophaneura alcinous* は若葉と成熟葉の両方を利用できると、原著の preliminary bioassay に記載されている。

これは**既報の質的観察**であり、このリポジトリの新発見ではない。原著の2016年個別給餌量実験は `A. debilis` の伸長枝上部第6〜9節から採った葉を与えており、若葉 vs 成熟葉の割付試験ではない。過去の予備試験について、年齢別の摂食率・成虫産生率を今回新しく推定するための元データは確認できていない。

同論文 Methods §2.3 は**10棟の温室×各3ケージ＝30ケージ**で実施したと明記。各ケージに4つの鉢植え `A. debilis` が含まれるが、鉢は独立したケージ反復ではない。原著の `S. montela` は全処理で幼虫死亡が50%超だったと報告。原著の物理配置をそのまま使うと「同じ温室内で4処理以上を揃える完全ブロック」は不可能なので、いま利用できる施設の実際の容量を測定するまで、4処理・6処理とも**実施可能と推定してはならない**。

追加先行研究：
- Hashimoto & Ohgushi (2017), DOI [10.1007/s10144-016-0568-8](https://doi.org/10.1007/s10144-016-0568-8) は同種/異種の被食後の寄主生長・バイオマスと反復食害を既に実験した。単なる「寄主は再生する」「被食は品質を変える」という一般論を新発見にしない。
- Takagi & Miyashita (2008), DOI [10.1603/0013-8746(2008)101[392:HPQIDI]2.0.CO;2](https://doi.org/10.1603/0013-8746(2008)101[392:HPQIDI]2.0.CO;2) は同じジャコウアゲハにおいて別種寄主 `A. kaempferi` の**葉の硬さ**が若齢生存・蛹休眠を左右することを実証済み。
- Jeong et al. (2023), DOI [10.3389/fpls.2023.1145363](https://doi.org/10.3389/fpls.2023.1145363) は韓国の別種寄主 `A. contorta` で**寄主株の年齢と季節**によりホソオチョウの成長が変わることを示した。**株年齢**と**枝上の葉齢**を同じ値と呼ばない。

## 2. 生態学の新しい問いの位置

寄主があるかを `B = young_leaf_biomass + mature_leaf_biomass` の単一スカラーで表すと、`B` が同じ場合の2種の実質的な資源可用性を区別できない可能性がある。

比較的単純なスクリーニング構造を

```text
E_species,instar = sum_{leaf_stage} (
  stage-specific host biomass × premeasured feeding-access fraction
)
```

と置ける。**これは定義上の利用可能量**であって生態学的な結果ではない。新規性を得るには、異なる葉齢混合物・競争者割付で独立に観測された**元コホート当たり幼虫生存・休眠・飛翔可能成虫**が、単なる合計 `B` を超えて予測・因果変化することを示す必要がある。

### 別の本実験候補（現在の主仮説から昇格させない）

`A. debilis` の**全供給乾重を同一にし**、「若葉の多い構成 vs 成熟葉の多い構成」を割り付け、そこへ `S. montela` の追加 `なし／あり` を交差した4処理。各処理のジャコウアゲハの飛翔可能成虫率を測り、

```text
D_stage =
  (young-rich, S present - young-rich, S absent)
 - (mature-rich, S present - mature-rich, S absent)
```

をケージ単位で推定する。若葉割合は**別パイロット後、主要応答を見ずに凍結**。同じ葉量でも若葉・成熟葉で物理的摂食可能性・栄養・化学組成が異なるので、この操作は**組織段階という複合処理**である。たとえ `D_stage ≠ 0` でも、物理的アクセスと栄養品質の単一媒介原因は識別されない。幼虫が孵化直後から利用できるかを現地で別に計測することが必要。

## 3. 本実験前に行う最小限の二段階パイロット

### Phase 0 — 葉のみで乾重・可食面積の独立較正

同じ `A. debilis` の複数**実在する別個の寄主ドナー株**から若葉と成熟葉を対で採取し、葉バッチごとに鮮重・乾重・面積（可能なら硬さ・節位・株年齢・採取日）を記録。別種 `A. kaempferi` の硬葉閾値1.5/2.0 Nを `A. debilis` にそのまま流用しない。

**特に重要:** 古い2016年の葉鮮重→乾重換算は葉齢を層別していない。若葉と成熟葉は含水率・単位面積当たり乾重が違いうるので、全体式のみで「総乾重を一致させた」と宣言しない。葉齢別の実測ドナー単位較正をパイロットで作成し、介入中の供給葉からも検証する。消費後の乾重推定には乾燥による自然減量を測った**無幼虫の対応対照**が必要。

### Phase 1 — 葉齢×蝶種の給餌可否を独立に検証

**基本4セル:** 蝶種（S/A）×供給葉齢（若葉/成熟葉）。特に孵化直後（L1）を主対象とし、L3は追加の段階別検証とする。親系統・採取日・葉ドナーの独立な反復を確保する。1つのカップ内の複数幼虫を複数の独立反復とせず、**カップを給餌介入単位**とする。

- 各カップの割付、種、齢期、供給葉齢、最初の幼虫数、給餌証拠の判定時刻、観測時間、摂食痕・個体別の死亡確認、観測不能を元のまま保存する。
- **「摂食した証拠がない」は「食べなかった」とは限らない。** 画像撮影・観察機会の不足はunknownとし、明確な拒食判定は観測スケジュールを守ったときだけ許可。
- 無幼虫対応葉の重量変化を同条件で取り、給餌後の葉重量減少を無条件に「摂食乾重」とみなさない。
- 母系の複数独立反復がなければ、カップ内の多数の幼虫がいても**種一般に成立する葉齢差**を主張しない。

**GO:** Sの若齢期における葉齢による摂食可否の差を、独立な親系統と寄主ドナーで繰り返し観測でき、必要な若葉・成熟葉の継続調達と野外相当の環境・封じ込めが達成可能である。

**HOLD:** 1系統・1ドナーだけの結果、葉齢別乾重換算が未較正、葉の自然乾燥が摂食量から分離できない、Sの死亡が初期で多く同所での競争機会を測れない。処理していない植物データで欠損を埋めない。

**STOP:** 法的・施設上の飼育/輸送/封じ込め確認がとれない場合、または孵化後の初期死亡・不明個体が多すぎて給餌可否の判定ができない場合。野外への放飼は行わない。

## 4. 実際のパイロットデータがそろった場合の監査

`scripts/audit_kyoto_leaf_stage_pilot.py` は本研究に特化した**観測記録の整合性確認**であり、生きた蝶を操作せず、標本測定値を生成せず、統計的な生態学的発見を判定しない。

3つの実測CSVを使う。実際のデータがない現在はこの監査を**フィールドで実行済みとはしない**。コードのテストに使うCSV行は100%人工的な整合性フィクスチャである。

**`leaf_calibration.csv`** — 1行は本当に採集・乾燥測定した葉バッチ：

```csv
donor_plant_id,leaf_batch_id,host_species,leaf_stage,sample_date,shoot_node,whole_plant_age_years,leaf_area_cm2,fresh_mass_g,dry_mass_g
```

- `host_species` は `Aristolochia debilis`、`leaf_stage` は `young`／`mature` のみ。株年齢の真値が不明なら空欄、架空の植え付け年で埋めない。
- 同じ株から両葉齢を取って**株内ペア**にし、鮮重・乾重・葉面積から葉齢別の乾物比および単位面積当たり乾重を、**ドナー株を等重み**として集計する。何枚もの葉を同じ株から採って独立株数を水増ししない。
- `dry_mass_g > fresh_mass_g` や同一バッチIDの重複、日付不明、葉齢不明は入力エラー。2株以上で若葉・成熟葉がともに採取できて初めて**構造的なペア較正が可能**と判定する。ただし2株で充分な統計的精度があるという意味ではない。

**`feeding_assay.csv`** — 1行は独立に割付したカップ／密閉飼育容器：

```csv
cup_id,source_block_id,maternal_family_id,species,instar_class,assigned_leaf_stage,source_donor_plant_id,assay_leaf_batch_id,initial_larvae_n,alive_end_n,observation_minutes,feeding_confirmed
```

- `species` は `Atrophaneura alcinous`／`Sericinus montela`、`instar_class` は `L1`（主）／`L3`（追加）。
- カップは一度しか数えず、同じ母系のカップを別母系とみなさない。母系とドナー株は別々の識別子。
- `feeding_confirmed` は `yes`／`no`／`unknown`。**unknown は no の分母へ入れない**。`no` は予め確保した観測の機会に食痕を確認できないという操作上の分類で、真の長期拒食の証明ではない。
- 葉較正のバッチは乾燥後摂食させられないので、`assay_leaf_batch_id` は**新しい供給用生葉**のIDとし、同じ株 `source_donor_plant_id` にある較正情報へ結びつける。較正に使って破壊したバッチと同一視しない。
- 主な4セル（2蝶種×L1×若葉/成熟葉）に各々別の母系2以上＋別ドナー2以上の実記録が存在するかを構造チェックするが、これは**確認的な生態効果判定、十分な検出力を意味しない**。

**`facility_inventory.csv`** — いま**実際に使える**温室ごとに1行：

```csv
greenhouse_id,eligible_whole_cages
```

- 値は、その時点で無作為化に必要な飼育・封じ込め・給餌条件を満たした**ケージ全体の数**であり鉢数や幼虫数ではない。
- 4または6処理の**温室内完全ブロック**を作れる数をそれぞれ `sum(floor(cages_in_greenhouse / 4))`、`sum(floor(cages_in_greenhouse / 6))` で報告。温室効果を無視して単に30ケージを寄せ集めた統計反復にはしない。
- 2012年論文の温室3ケージを10棟に割った構造は、この関数では4・6処理の温室内完全ブロック数がどちらもゼロになる。しかし**現在の設備が2012年と同じかどうかは未確認**である。

```bash
python scripts/audit_kyoto_leaf_stage_pilot.py \
  --leaf-calibration leaf_calibration.csv \
  --feeding-assay feeding_assay.csv \
  --facility-inventory facility_inventory.csv \
  --receipt results/kyoto_leaf_stage_pilot_v01.json
```

出力は生の行を推測・補完せず、観測した母系・株の数、葉齢別乾物換算、カップで確認された食痕、unknown数、独立温室容量、ファイルのSHA256を出す。レコードがなければ実測の差は**不明**であり、0%や100%と捏造しない。葉の自然乾燥を差し引いた真正の摂食量、個体群の定着、飛翔成虫までの機能を計算するものでもない。

## 5. 既存のPR #40への影響

1. **4処理（S追加×葉へのアクセス補充）を最初の候補として維持**。新しい若葉率実験は、Phase 0–1 を越えた場合だけ比較検討する未実施の独立案。
2. 6処理の同種追加を本実験に採用するには、焦点Aと追加Aを生涯追跡して区別できることを別パイロットで実証する。できないなら**6処理は中止し4処理に縮小**する。追加同種の個体数一致は食草需要一致ではない。
3. 2023年の「10温室×各3ケージ」を現在の施設容量と取り違えない。**現有施設の棚・温室容量を実測**するまで、温室を4/6処理の完全ブロックにする既存コードをそのまま運用しない。選択肢は施設拡張、独立した複数期の完全処理ブロック、あるいは温室効果を明示的に扱う不完全ブロック設計の**新たな事前解析仕様**であり、単に温室IDを無視してケージを擬似反復にしない。
4. 実施可能性の確認から本実験のサンプルサイズを確定する。PR #40の従来の精度例は**仮定的**であって検出力や実施保証ではない。
5. 研究の核心は依然として「寄主がそこにある」から「飛翔可能な次世代を生む」へどの段階で転換するか。若葉構成はその中の独立に測定・操作できる生態的フィルター候補だが、既に知られる若葉選好を再包装して新発見と呼ばない。
