# オオカバマダラ：外来寄主植物の羽化成功は温度に依存しうるが、交互作用には区間不確実性がある

**2026-10-15｜独立した原著者公開データの事後再解析／既報の生態現象を適切な実験単位で再確認。新しい実験・生態学的発見ではない。**

## 研究上の位置づけ

世界のチョウ239種の既知寄主資源域を推定した `chocho` の全球研究は、**寄主が存在する地理的な機会**を扱う。一方、実際の次世代生産は、寄主**植物の種同一性・発育段階・気候・寄生者**に依存しうる。その区別を卵数や植物分布だけで示すのではなく、**全割付幼虫から成虫までを追った独立した実証資料**で点検した。

原著：Ragonese et al. (2025), *Ecological Entomology*, DOI [10.1111/een.70010](https://doi.org/10.1111/een.70010)。

- 実験実施年は **2021年**、米国Georgia州Athensの1地点。
- 温室型の加温処理／非加温処理を**30区画（各温度15区画）**に割付。
- 各区画には**4寄主植物株**：熱帯トウワタ *Asclepias curassavica*（Georgiaでは非在来の栽培植物）と湿地性トウワタ *A. incarnata*（Georgia在来）、各種にOE感染処理／対照を組み合わせる。
- **1株に2幼虫、計240幼虫、120株**。処理の反復を240幼虫と呼ぶと、温度を区画単位で操作している設計を壊す。
- OEは原著で設定した**接種処理**であり、あとから得た感染陽性/陰性だけで条件化しない。原著Methodsでは蝶の**母系（遺伝系統）を植物へランダム割付した**ことは明記する一方、温度処理を30区画のどこへ設置したかのランダム化については明記していない。

本研究では原著者のGitHub `IRagonese/MilkweedWarming2024`、commit `74e3e2cd8079401c9ccd4359f9e39e2d52d1f7d2`、元CSV `MWwarming_comp_May16.csv` を直接取得し、Git blob SHA1 `e7a625911d8dc9b871a52d7657314a5d05472216` を照合。CSVのSHA256は `dc7373e28f836c8da6d3a57754d13fbd965bbfa7c6132b7b7d2b90f569e596e2`。

**元の240幼虫**のうち239で成虫運命の0/1が記録され、219が羽化、20が成虫に至らず。残り1個体（原著ID `22b`）は飼育時の事故を理由に成人運命が欠測。**死亡と決めつけず**、未羽化として扱った下限と「もし羽化していたら」の上限の両方で感度解析する。

**既知239個体では、`Surv_pupa` と `Surv_adult` の成功個体数がどちらも219、二値の実験成否が全員一致。** つまりこの原実験で観測された非成虫への移行損失は、少なくとも記録上は蛹化前に発生した。野外の自然幼虫死亡原因を判定したわけではなく、蛹は外部容器に移した後に羽化追跡された。**成虫羽化は飛翔・交尾・再生産の観測と同じではない**。

## plot単位の差分の差分（主な計算）

各区画で熱帯寄主4幼虫と湿地寄主4幼虫が置かれた。OE感染／対照の各寄主植物株に2個体ずつ。感染処理の比率を50:50に保ったまま、区画内で宿主種間の羽化率を引き、温度間の差を求めた。

```
D = (tropical−swamp adult emergence | elevated)
  − (tropical−swamp adult emergence | ambient)
```

- **ambient**：熱帯 `54/60=90.0%`、湿地 `55/60=91.7%`。寄主種間差 `−1.67` パーセントポイント。
- **elevated**：熱帯 `51/60=85.0%`、湿地 `59/60=98.3%`。寄主種間差 `−13.33` ポイント。
- **温度×植物種の差の差**：不明1個体を観測未羽化の下限とすると `−11.67` ポイント、もし羽化したという上限感度なら `−13.33` ポイント。

温度処理に対し妥当な**集計・再標本化単位は各温度15区画**なので、同じ温度の区画丸ごと復元抽出する9,999回**階層の再標本化**を行った。個別幼虫を再抽出して見かけの反復数を増やしてはいない。

| 指標 | 下限感度（不明者を未羽化） | 上限感度（不明者を1羽化） |
|---|---:|---:|
| 点推定：寄主×温度 | −11.67 ppt | −13.33 ppt |
| **plot-bootstrap 95%区間** | **−30.0〜+5.0 ppt** | **−30.0〜+3.33 ppt** |
| ambient内の寄主差95%区間 | −16.67〜+15.0 ppt | −15.0〜+15.0 ppt |
| elevated内の寄主差95%区間 | **−21.67〜−6.67 ppt** | **−21.67〜−6.67 ppt** |
| 1区画ずつ除いた主対比の範囲 | −16.90〜−6.19 ppt | −18.69〜−7.98 ppt |

`ppt`＝百分率の差の**パーセントポイント**。

**実験割付の重要な制限：** 温度処理の**区画位置自体の無作為化は原著Methodsで明示されていない**。今回の区画単位bootstrapは幼虫の擬似反復を防ぐ一方で、潜在的な空間配置の交絡を除去した厳密な因果検定ではない。OE処理・植物の種同一性・温度割付の推論を「外来植物という性質の純粋な無作為化効果」に昇格させない。

**重要：交互作用のplot-bootstrap 95%区間はゼロを含む。** したがって「加温で外来寄主が他種より必ず羽化に不利になる」と厳密に結論したり、一般的なトウワタ全種に拡張するのは不適切。原著でも温度×milkweedの成虫生存交互作用は `z=-1.85, p=0.064` として報告し、一方で加温区での寄主種間比較は `p=0.028` として報告している。今回のplot単位bootstrapは原著のAICc/GLM解析の直接再現ではないので、数字が違っても原著の誤りとは断定しない。

**既報の主な生態学的知見**は、寄主植物の同一性と温度/寄生虫処理によってオオカバマダラの成長、寄生虫耐性、生存成績が変わること。今回の固有の作業成果は**適切な区画反復単位、1不明者の扱い、羽化成功の条件別実数、交互作用区間を独立監査したこと**であって、新しい生物学的過程を実証したことではない。

## 全球資源地理への慎重な接続

既存の凍結HOSTS/WCVP再構成ではオオカバマダラの受理済み寄主植物は40種、潜在資源域は在来181・現代263 WGSRPD3地域、追加のみ82地域。さらに、**この実験で使われた高品質寄主 `A. curassavica` 自体が元のHOSTS受理済みリストに欠落**するという独立のソース問題も指摘されている（`MONARCH_HOST_QUALITY_SOURCE_CHECKPOINT_V01.md`）。

「ある寄主が羽化を支える」ことは局所実験で確かめられる一方、その羽化成績は温度、寄主植物の種、OE処理などに依存する。だから「追加地理的資源地域82」は**82地域の野外成虫産生や80%以上の羽化保証ではない**。また、欠落した高品質寄主を単に地図に加えることが、今回の温度条件別羽化曲線を地域へ外挿する根拠にもならない。

特に *A. curassavica* はGeorgiaで非在来だが、地理的な外来/在来状態と**この2植物種の固有の化学的・形態的差**は完全に交絡する。これは「外来植物一般に生態学的な罠がある」という二値の原因比較ではない。原研究は熱帯植物が実験区で**利用できる状態**で供給されたことを保証するが、任意の都市公園での野外寄主発見率・産卵成功・移住定着率は測っていない。

## 投稿判断と今後の独立実験

- この単一資料をもう一度GLMで有意にして独立論文として出すことは勧めない。**2025年の原著の主張と重複する**。
- 新しい現象が必要なら、単なる寄主の地理的存在ではなく、**同じ地域・同じ母系で、非在来寄主への産卵選択と、温度・感染状態別に独立に追った幼虫→飛翔可能成虫の生産を実際に連結**する調査が必要。
- 京都の在来寄主上での異種蝶競争とは別の研究。両研究から受け取る一般仮説は「可食資源の量・質・自然敵・温度を越えて、次世代の生産へ到達する分岐」であり、**両研究を独立な因果的効果量として無条件にメタ解析しない**。
- GEB投稿済み主論文の主張・図表・`main`／PR #38は変更しない。既報の機構を、全球潜在資源地理の新しい因果検証として扱わない。
