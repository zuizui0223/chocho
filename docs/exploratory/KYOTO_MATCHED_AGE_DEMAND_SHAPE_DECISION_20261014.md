# 京都の2種の摂食時間窓 — 新しい解析結果と研究方針（2026-10-14）

**Status:** 実際の著者公開データに基づく、1つの飼育由来群ごとの**事後的記述解析**。新規操作実験はなく、競争逆転・羽化成功・野外個体群への影響は**未検証**。初回のGlobal Ecology and Biogeography投稿PR #38とmainは変更しない。

## 1. 検証した問い

同じ孵化後日齢で比べると、ジャコウアゲハ (*Atrophaneura alcinous*) とホソオチョウ (*Sericinus montela*) の3〜5齢期の摂食需要は、本当に大きく異なる時期に集中するのか。もし需要時期が明確に異なれば、寄主組織の供給時期だけが競争上の不利益を逆転させる可能性を検討できる。

比較は原著 Hashimoto & Ohgushi (2023), DOI https://doi.org/10.1002/ece3.10164 と、元CSV https://doi.org/10.6084/m9.figshare.23170898 に限定した。2012年の**30ケージ×23回の幼虫齢期記録**と、2016年の**別実験の個別給餌量**は、同一の時系列ではないことを保った。

原著の湿葉→乾葉換算式による3〜5齢期の累積摂食量は今回の再計算で A=1,011.00 mg（原著1,003.23 mgとの差+0.77%）、S=395.86 mg（原著394.25 mgとの差+0.41%）。これは*原著の値の再現*であり、新しい実験結果ではない。

## 2. 完全に観測された同じ6期間の比較

両種の飼育開始日には16日の差がある。そのため絶対暦日を使わず、各種の10幼虫集団飼育開始から8、10、12、14、16、18日後という、両種の個体別摂食記録がほぼ揃う**共通6期間**に限った。

各幼虫の6期間の累積摂食量を100%に正規化してから、個体の重みを等しくして種内平均を出した。開始時点で追跡したA 10個体のうち、8日目の有効摂食記録がない1個体を除外し、A 9個体・S 9個体の厳密な完全観測セットを比較した。

| 6期間の各終了日齢 | Aの期間別摂食割合 | Sの期間別摂食割合 |
|---:|---:|---:|
| 8日 | 5.96% | 5.16% |
| 10日 | 3.60% | 4.69% |
| 12日 | 14.69% | 11.60% |
| 14日 | 7.87% | 13.34% |
| 16日 | 24.99% | 17.21% |
| 18日 | 42.90% | 48.01% |

この時間分布の**重なりは88.33%**、全変動距離（total variation）は**11.67%**。累積摂食量で重みづけしても重なりは**89.19%**。摂食時期の重心は **A=15.421日、S=15.536日**、差はAが0.115日早いに過ぎない。

一方、8〜12日目の割合は **A=24.240%、S=21.441%、差+2.798パーセントポイント**。個体を一個体ずつ外しても同じ符号で、差の範囲は**+1.843〜+3.437ポイント**。これは*一つの飼育由来群内の頑健性*であり、母親・個体群を独立に複製した誤差区間ではない。

### 観測期間の境界感度

- 8〜16日（5期間）：重なり85.35%、重心A−S=**+0.214日**。
- 10〜18日（5期間）：重なり90.29%、重心A−S=**−0.035日**。
- 8〜18日（6期間）：重なり88.33%、重心A−S=**−0.115日**。

**重心の差の符号が観測期間を変更すると反転する**ので、「ホソオチョウの食期が確実に2日遅い」との一般化は不適切。前の「半分の摂食量に達する中央値の2日差」と「最大2日間平均摂食量の4日差」は、記録期間の長さ・尾部の少数個体の影響を含むと解釈する。

共通6期間で観測される需要の差は**小さいが完全な同一形ではない**。したがって、既存データは「京都の2種は摂食ピークが大きく異なるから資源供給タイミングを変えれば勝敗が反転する」という強い前提を支持しない。

## 3. 理論モデルとの接続は可能だが条件が狭い

共通6期間の前半（8、10、12日）の総需要割合をA=`a=0.242396`、S=`b=0.214414`と固定し、各種の累積需要をそれぞれ1に正規化したとする。先に明示した**仮想的**な比例配分・資源持ち越しなし・指数型羽化応答モデルでは、供給不足の時期によって相対的な不利益が逆転し得るのは

```
0.8846 < (不足の大きさに対するAの羽化感受性 k_A) /
         (不足の大きさに対するSの羽化感受性 k_S) < 1.0369
```

という狭い範囲だけになる。

この数値は**実験で推定された羽化感受性ではない**。原論文の「Aの総摂食量はSの約2.6倍」は、決して`k_A/k_S=2.6`を意味しない。2種とも摂食量の大部分を後期に要求し、平均的な不足時期が近い以上、「供給時期だけで種間競争の非対称性が逆転する」と楽観する根拠は限定的である。

また、既に Sato (2016), *Journal of Animal Ecology*, DOI https://doi.org/10.1111/1365-2656.12516 は、補助資源の**総量を固定し供給時期だけを操作する**野外実験で消費者の成長や成熟の違いを示している。一般論の「資源の時期が重要」は、それ自体では新規性にならない。

## 4. GO/NO-GOの現時点の判定

**主結果:** この2種で時期の大きなずれは確認されず、**理論上の逆転が実際に起きた証拠はない**。したがって、京都システムを「競争上の不利益が供給時期で逆転する」という主軸の**確認的な論文へ昇格させない**。

**独立予備実験は可:** 複数母系を用い、孵化を同期化した2種の摂食需要曲線を、同一時刻に入手できる*Aristolochia debilis*の葉面積・乾重・若齢/成熟葉・質とともに計測し、再現性が得られれば時間操作実験を検討する。比較すべき実証応答は始めに割り当てた幼虫コホートからの**飛翔可能な成虫数**。生存休眠蛹を死亡として誤分類しない。反証条件は実験開始前に固定する。

**優先順位の修正:** 現在の京都データから、むしろ確かな未解決点は「ホソオチョウ密度が在来ジャコウアゲハの生存を低下させるのに、試験終了時の食草減少では説明しきれない」という**一時的な食草不足・植物組織の質・直接/間接干渉**の区別である。既存の予備実験計画にある **摂食可能量の継続的測定と供給補充 × 競争者なし/同種追加/異種追加** を優先候補とする。総幼虫数と食料要求量は別の交絡なので、同個体数の追加だけで純粋な競争相手種の効果が分離できると主張しない。

**本質的な一般問題:** 「寄主があるか」ではなく「その時期に使える葉・蕾・花の量と質が、幼虫の需要および競争相手・天敵の時期にどれだけ合うか」。京都の単一実験だけでこの一般問題は解けない。chochoの全球潜在資源域論文は継続し、別研究の操作実験・生活史検証とは統合しない。
