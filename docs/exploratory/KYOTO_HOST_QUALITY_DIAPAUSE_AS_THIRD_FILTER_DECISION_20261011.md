## 1. 実際に新しく見つけた独立の日本産蝶研究（既報）

Takagi S & Miyashita T (2008). *Host Plant Quality Influences Diapause Induction of Byasa alcinous (Lepidoptera: Papilionidae)*. *Annals of the Entomological Society of America* 101:392–396. DOI [10.1603/0013-8746(2008)101[392:HPQIDI]2.0.CO;2](https://academic.oup.com/aesa/article/101/2/392/8474).

**同一蝶である根拠：** [NCBI Taxonomy ID 85299](https://www.ncbi.nlm.nih.gov/Taxonomy/Browser/wwwtax.cgi?id=85299) は `Byasa alcinous` の homotypic synonym として `Atrophaneura alcinous` を記載。異種に対する類推ではなく同じ分類群（別属名の組み合わせ）に関する先行実験だが、**母集団と食草種は京都の2023年研究と異なる**。

- 2006年千葉の大学演習林に由来する成虫母親**3個体**の子を、***Aristolochia kaempferi*** の柔らかい葉（穿孔力 **<1.5 N**）と硬い葉（**>2.0 N**）に分けて飼育。
- 条件は**20°C、光周期16時間明/8時間暗**。葉を交換し、若齢幼虫生存、幼虫期間、蛹重量、蛹休眠の有無を調べた。
- **硬い葉**は若齢の生存率を低下させ、幼虫期間を長くした。蛹重量に有意差はなかった。
- **蛹休眠**は硬い葉で有意に高く（原著検定 **p=0.005**）、硬葉処理で蛹になった個体は**1個体を除きすべて休眠**した。生存していても季節内に羽化しない状態は、実証済みの可塑的応答の一つ。
- 現地の植生刈払いで柔らかい若葉が再生し、刈払いされた林縁では**若葉57・成熟葉21**、刈払いされていない林内では**成熟葉177・若葉0**が記録されていた。この自然史的操作・観察の結論は**すでに2008年に発表済み**。
- 食草硬度は葉のC/N比とも関連するので、効果を硬度**分子レベルの固有効果**へ直結させられない。3母系と地域の違いも一般化を制限する。

**重要：** これは京都の *A. debilis* に外来 *Sericinus montela* が侵入して休眠を誘導した証拠ではない。京都の2017・2023年研究とは違う食草、異なる野外個体群での**同じ蝶の生活史可塑性**の既報。

## 2. GEB/chocho との関係：相互作用を三段階に分ける

```text
移入寄主の供給（潜在的な食草利用可能性）
      ↓
実際の同一時刻・同一食草での利用と競争者との出会い
      ↓
幼虫の採餌・死亡・発育期間・蛹休眠
      ↓
羽化する季節とその後の交配／次世代への加入
```

従来の `regional host opportunity`、韓国の局所 `encounter`、京都の `larval competition payoff` に加え、食草の質による `diapause-mediated temporal displacement` がありうる。ただし**時間的棲み分けが適応的か、競争回避に寄与するかは未検証**。過去の休眠効果自体は絶対に新発見と書かない。

より反証可能な新しい仮説は：

> *Sericinus* による早期の食害または共存によって、*A. debilis* 葉の質が変化すると、同じジャコウアゲハが仮に幼虫死亡を免れても、休眠蛹になる確率が変化し、年内の成虫出現がずれるか。

帰無仮説：競争者の存在や植物履歴が、総生存・休眠・実際の羽化時期に関係せず、光周期・温度・食草の成熟度によって説明される。対立仮説は方向を定めることができるが、2008年の柔葉/硬葉の個体群結果を京都にそのまま代入してはならない。

**新しい実験の必須識別条件**：競争者有無 × 計測された質を揃えた可食葉アクセス、全ケージ同じ光周期・温度の無作為化、親/母系と寄主由来のブロック化、幼虫死亡・蛹化・休眠・休眠解除・最終的な成虫出現の識別。食害履歴が休眠に効いた場合でも、原因を“適応的競争回避”と呼ぶには季節ごとの生存・交配・翌世代再生産の検証が追加で必要。

## 3. 本日 GitHub で実装した具体的な修正

旧 `scripts/analyze_kyoto_food_clamp_outcomes.py` では `pupa_no_adult` を死亡・羽化不成功に含める可能性があり、生存して休眠中の蛹を偽の「死亡」にできた。

**修正版でその曖昧なコードを入力エラーとして拒否**し、次の状態を分離する：

| 新しい状態 | 判定 |
| --- | --- |
| `pupa_confirmed_dead` | 生物学的に死亡と確認された蛹のみ |
| `diapause_alive` | 生きている休眠蛹。成虫出現は未解決で、**死亡ではない** |
| `pupa_alive_pending_emergence` | 生存しているが休眠診断・羽化待ちの蛹 |
| `flight_capable_adult` | 実際に羽化し飛翔可能だった成虫 |
| `adult_nonflight`, `dead_immature` | 別種の観測結果、休眠とは別 |

`diapause_alive` は成虫出現の可能な最大割合（upper bound）に入るが、**羽化成功としても、確認死亡としても数えない**。観測期間内の成虫出現割合と、越冬後を含む最終的な成虫出現割合は別の estimand。最終成功数には長期フォローアップが要る。ケージ内の全初期割当幼虫は両者とも母数から除かず、結果の不明個体は潜在的成功の下限/上限で評価する。

- 当該コードと合計 **15/15のユニットテスト**（以前10件＋新5件）を [GitHub Actions](https://github.com/zuizui0223/chocho/actions/runs/38107459855) で実行確認。
- `KYOTO_FOOD_CLAMP_ANALYSIS_CONTRACT_V01.json` で正しい蛹状態・生存/休眠・年内羽化と最終羽化の分離を凍結。
- `KYOTO_HIDDEN_BOTTLENECK_FIELD_SCHEMA_V01.md` に蛹化時刻、休眠診断方法、診断/観察時刻、追跡・羽化/死亡確認日時の元データ辞書を追加。
- 同じモデルのテストは**人工的なコード整合性確認用**であり、実験結果をシミュレーションして新しい生態学的効果と主張していない。
