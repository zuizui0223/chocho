# Temporal resource mismatch decision note v0.1

Status: **EXPLORATORY / KEEP OUT OF THE GEB SUBMISSION MANUSCRIPT UNTIL THE FULL-HISTORY TEST IS RESOLVED**

## Why this branch exists

The static resource reconstruction shows large anthropogenic expansion of known larval-host geography. A temporal extension is scientifically useful only if it asks something that is not fixed by the amount of added resource opportunity.

The nontrivial temporal question is:

> **Does the identity and timing of redistributed known hosts predict when butterfly consumers subsequently realize that geographic opportunity, beyond broad geography, accessibility, sampling effort and the background chronology of alien plants?**

## 1. Snapshot hindcast is not valid historical evidence

The frozen 53,434-record butterfly occurrence set is a capped API snapshot, not an exhaustive 2010–2017 history. A post-hoc audit of all 20 apparent 2018–2025 outcome cells found that 13 already had older GBIF records before 2018 (8/11 controls and 5/9 introduced-host cells).

Therefore the raw snapshot contrast (Host+ 9/589 versus control 11/1171) must not be interpreted as a colonization or first-detection hindcast.

The correct test is the full-history audit of **every candidate cell**, not only apparent outcome cells.

## 2. Apparent host-first lag is intriguing but not yet a biological lag

For the nine post-hoc Host+ event cells, symmetric 1800–2025 GBIF searches gave an earlier known-host record in 8/9 cells and an apparent median host-to-butterfly first-record difference of 86 years.

This is not yet evidence for delayed consumer tracking because:

- the nine cells were selected after seeing the apparent butterfly outcome;
- 23/24 earliest host records were preserved specimens;
- first record is not establishment;
- plant and butterfly record histories have different sampling processes.

Call this an **apparent record lag**, not a colonization lag or ecological debt.

## 3. Independent host chronology is feasible but spatially coarse

SInAS 2.5 recovers all 16 focal host taxa represented in the nine event cells (926 alien-region records; 282 dated records between 1500 and 2025).

This independently confirms that many focal hosts have long documented alien histories, but SInAS locations are often country/island scale rather than WGSRPD level 3. It is therefore a useful chronology sensitivity source, not a direct local clock for New York, Minnesota, Tennessee and many other focal units.

## 4. What would count as a nontrivial temporal result

A temporal mismatch result is publishable only if the actual known-host chronology performs better than a null in which the same amount and age structure of alien-plant opportunity is reassigned.

Preferred test:

1. freeze butterfly × region candidate cells without using future butterfly outcomes;
2. estimate the earliest defensible local record of actual introduced known hosts;
3. sample pseudo-host alien plants from the same region, matched for record intensity, residence-time distribution and geographic prevalence;
4. preserve the number of resource plants assigned to each butterfly × region cell;
5. compare whether actual known-host timing better predicts butterfly first detection than pseudo-host timing.

This extends the project-wide nontriviality rule from space to time: **holding the amount of added opportunity fixed, could a different identity/timing of additions have produced a different consumer response?**

## 5. Decision tree

### A. Full-history Host+ enrichment survives
Proceed to a response-blind temporal resource-tracking analysis. Treat the full-history result as evidence that actual resource placement predicts later documented occurrence, while host timing remains a separate question.

### B. Full-history enrichment disappears
Do not rescue the original hindcast. The result becomes **static opportunity–realization decoupling**: large resource expansion does not imply rapid consumer tracking. Test temporal lag only with an independent host clock and matched pseudo-host controls.

### C. Actual host timing beats matched pseudo-host timing
This is the strongest temporal result: a candidate **resource-realization lag** or **resource-tracking debt**, distinct from generic alien-plant/insect invasion debt because butterfly–host interaction identities are held fixed.

### D. Actual host timing does not beat pseudo-host timing
Interpret the apparent multi-decade lag as collection-history / invasion-history structure rather than a butterfly resource-tracking mechanism.

## Stop rule

Do not add competition-alpha sweeps, future-naturalization scenarios, or further homogenization metrics to compensate for a weak temporal result. The GEB main manuscript remains unchanged unless a full-history, identity-specific temporal result passes the relevant null.
