# 京都の蝶：10温室×3ケージを全部使う準釣り合い型の4処理実験

**2026-10-14 | 実験前の統計的・生態学的デザイン監査。新たな植物・幼虫・成虫の測定はゼロ。**

Working branch: `experiment/kyoto-30cage-nearbalanced-v01` → `experiment/kyoto-4arm-three-cage-bibd-v01`. GEB用 `main` と論文PR #38には変更しない。

## 1. 理論に戻らず、具体的な生態学的問いを残す

**主仮説**：*Sericinus montela*（ホソオチョウ）を加えたときに在来 *Atrophaneura alcinous*（ジャコウアゲハ）の**元の幼虫集団当たりの飛翔可能成虫生産**が落ちる原因に、一時的な**実際に食べられる `Aristolochia debilis` 葉組織の不足**が含まれるなら、食草への継続的アクセス補充がその抑制を軽減する。

4処理：`NATURAL_NONE`, `NATURAL_ADD_S`, `SUPPORTED_NONE`, `SUPPORTED_ADD_S`。既報の Hashimoto & Ohgushi (2023), DOI [10.1002/ece3.10164](https://doi.org/10.1002/ece3.10164) は、**2012年に10棟の温室それぞれに3ケージ、合計30ケージ**で2種の密度操作を行った。これは**過去の物理配置の記述**であり、本研究に使える現在の施設一覧ではない。

この対照の核心は、「食草が最後に残っていた」という情報だけでは、幼虫が死亡する前の**葉齢別の可食量**を識別できないこと。実験の目的は2023年の競争効果を見直すのではなく、介入によって生じる差を新しく測ることにある。

## 2. 30ケージの準釣り合い設計が優れる理由

前のPR #41は厳密なBIBD：
- `8 greenhouse × 3 whole cages = 24`;
- 各4処理6反復、各温室では3処理だけを割り付ける;
- 処理の対比（係数+1,−1,−1,+1）は温室固定効果で識別可能;
- 独立・等分散の**ケージ**残差が `sigma²` なら、`Var(D-hat)=0.75 sigma²`。

新しい設計：**10 greenhouse × 3 whole cages = 30**。各温室では同様に1処理だけを省略する。ケージを使い切るため厳密BIBDはできない：30/4=7.5は整数でない。各処理を7回または8回割り付ける**準釣り合い型不完備ブロック**を使う。

**一例（これは実験に割り当てたラベルではない）：**

| 温室 | 省略する処理 | 残り3ケージに入る処理 |
|---|---|---|
| G1/G2/G3 | NATURAL_NONE | NATURAL_ADD_S, SUPPORTED_NONE, SUPPORTED_ADD_S |
| G4/G5 | NATURAL_ADD_S | NATURAL_NONE, SUPPORTED_NONE, SUPPORTED_ADD_S |
| G6/G7 | SUPPORTED_NONE | NATURAL_NONE, NATURAL_ADD_S, SUPPORTED_ADD_S |
| G8/G9/G10 | SUPPORTED_ADD_S | NATURAL_NONE, NATURAL_ADD_S, SUPPORTED_NONE |

この配置で `NATURAL_NONE=7`、`NATURAL_ADD_S=8`、`SUPPORTED_NONE=8`、`SUPPORTED_ADD_S=7`。ホソオチョウ追加あり/なしは**各15ケージ**、食草補充あり/なしも**各15ケージ**になる。任意の2処理が同じ温室に現れる回数は4、5または6であり、**BIBDのようにすべて同数ではない**。

### 主対比に合わせた設計の最適化

```text
D = (SUPPORTED_ADD_S - SUPPORTED_NONE)
  - (NATURAL_ADD_S - NATURAL_NONE)
```

4処理の**省略回数を2,2,3,3に限定**すると、どの2処理を3温室ずつで省くかには `C(4,2)=6` 通りある。主対比を重視した `c' C⁺ c`（`C` は温室調整済み処理情報行列）を、独立した行列演算で**全6通り列挙**すると：

- 主対比の **+1側同士**（`NATURAL_NONE`, `SUPPORTED_ADD_S`）、または **−1側同士**（`NATURAL_ADD_S`, `SUPPORTED_NONE`）をそれぞれ3回ずつ省く **2通りのみ `0.600000 × sigma²`**。
- 残る4通りは **`0.606061 × sigma²`**。

ゆえに**7/8反復の6種類の配置に限定した場合**、2候補が主対比分散を最小化する。理論モデルへの最適化であり、蝶の生態効果を仮定して最適化したものではない。将来は母系・寄主株・微気象を偏らせる選択を事後的にしないこと。

どちらの省略パターンにするかは事前記録したseedで**等確率に無作為選択**し、その省略ラベルを10温室にランダムに割り付け、さらに温室内の3つの独立ケージへ残り3処理をランダムに割り付ける。結果を見る前に固定する。

## 3. 効率改善の正確な範囲

ケージ水準の独立・等分散・温室効果の加法性を仮定した、**モデルの式として**：

| 数学的条件 | 8温室24ケージ | 10温室30ケージ |
|---|---:|---:|
| 厳密なBIBDか | YES | NO（準釣り合い） |
| 各処理反復 | 6 | 7, 8, 8, 7 |
| 温室数と残差自由度 | 8温室／13df | 10温室／17df |
| 主対比の分散／`sigma²` | 0.75 | **0.60** |
| 同じ残差SDの時の標準誤差比 | 1 | **0.8944** |
| *仮に*残差SD=0.20の95% t区間半幅 | 約±0.374 | **約±0.327** |

30ケージで、24ケージ案より **分散−20%、標準誤差−10.6%**。仮定的なt区間の半幅も約12.7%縮まる。計算の残差自由度は `30 − 10 greenhouse indicators − 3 treatment indicators = 17`。

このSD=0.20は**仮定の数値**である。2023年の30ケージの羽化・温室別データから推定したものではない。また、温室が**同一母系**や共有した株由来を介して相関する可能性、温室ごとの処理効果の違い、幼虫内の生存/休眠の依存、葉質のバッチ差、蛹の追跡不能は、これらのt近似式の妥当性を崩し得る。**30ケージで検出力を満たすと主張しない。**

### 理論上の無作為化の公平性

2通りの省略パターンを等確率で選び、温室とケージの位置を完全にランダムに割り付けたとき、元の各独立ケージがそれぞれの4処理を受ける**周辺確率は1/4ずつ**である。この性質は処理割付の公平性であり、処理間の汚染や共有母系の独立性を保証しない。

## 4. 未来の実データを必要とするプログラム

コード：
- `scripts/randomize_kyoto_30cage_nearbalanced.py`
- `scripts/analyze_kyoto_30cage_nearbalanced.py`
- `tests/test_kyoto_30cage_nearbalanced_randomization.py`
- `tests/test_kyoto_30cage_nearbalanced_analysis.py`

無作為化に必要な実在・事前適格の全30ケージのインベントリ（温室10棟で各3ケージ）の列は：

```csv
cage_id,greenhouse_id
```

```bash
python scripts/randomize_kyoto_30cage_nearbalanced.py \
  --inventory original_eligible_30cages.csv \
  --allocation randomized_30cages.csv \
  --receipt original_randomization_receipt.json \
  --seed <animal_outcomesを見ずに記録した整数>
```

元の割付は**入力SHA256・割付SHA256・seed**とともに固定。解析時にseedを再生し、**処理の反復数や温室内配置が数学上釣り合っていても、事後的に処理を交換した割付は拒否**する。

アウトカム解析は独立ケージを1観測単位とし、3つの温室ごとの処理の入れ替えではなく**10個の温室固定効果**で調整する。元のジャコウアゲハ幼虫全員と追加Sの蛹/羽化をそれぞれIDで追跡。生存休眠蛹を死亡と呼ばず、欠測された葉面積をゼロとして補完しない。実現した食草アクセス量で実験ケージを事後的に除外しない。

必要な4つのCSVはPR #41と同じヘッダ（`randomized_30cages.csv`、`assignments.csv`、`fates.csv`、`resources.csv`）だが、`design_version` は `kyoto_10greenhouse_30cage_nearbalanced_v01` として**24ケージと混用禁止**。

```bash
python scripts/analyze_kyoto_30cage_nearbalanced.py \
  --allocation randomized_30cages.csv \
  --assignments assignments.csv \
  --fates fates.csv \
  --resources resources.csv \
  --receipt results/kyoto_30cage_original_fate_analysis.json
```

全ケージの元の幼虫数、羽化した飛翔可能成虫、生きている休眠蛹、未解決の羽化、対比の上下限、温室を1棟ずつ外した記述的感度分析、温室調整モデルが出力される。加えて、ケージ残差の**HC3不等分散ロバスト分散による感度診断**と、温室1棟を外す**jackknife標準誤差の記述的感度診断**を付す。これらは小標本の正確なランダム化検定や、温室間の処理効果異質性を完全に補正したCIではない。標準誤差の小ささを新たな生物学的証拠とは解釈しない。ただし**新たな実データなしでは本プログラムから生態学的な効果は出ない**。

## 5. 生態学的主張を昇格する条件

1. 実際の10温室の**現有ケージと封じ込め**の適格性を確認する。旧論文の温室をそのまま利用可能と決めない。9温室しかない場合、30ケージ用のコードを使って欠損温室を削除せず、試験前に別の設計を検討する。
2. 葉齢別の乾重・可食面積の独立較正、元のジャコウアゲハの個体ID・蛹の長期追跡、寄主ドナーおよび母系の複数ソースを収集。特に2023年の「ホソオチョウの孵化直後は成熟葉をほぼ食べない」という**既報**を、*A. debilis* の若葉・成熟葉を対象とした新しい独立パイロットで再検証する。
3. 介入が葉面積・量だけでなく品質・接触を変えるので、主対比が有意であっても即座に「葉量が媒介」と断定しない。温室特有の交互作用や病原体も別実験で扱う。
4. 真の残差ばらつきと追跡不能率が見えたらサンプルサイズ・主要実験の精度/検出力を事前に確定。**統計実装が先に完成しても論文の新規生態学的発見はまだゼロ**。
5. GEB投稿主論文で扱う**移入した寄主植物による潜在分布**と、本計画の**移入したチョウによる在来寄主植物上の競争**を統合して因果証拠にしない。

**Scientific decision:** 10温室が実際に利用可能なら、6ケージを使わない8温室BIBDより、10温室を全て使い主対比の推定精度を上げる設計を優先候補にする。ただし、1期30ケージで十分という証拠は存在せず、独立した予備調査を必須とする。
