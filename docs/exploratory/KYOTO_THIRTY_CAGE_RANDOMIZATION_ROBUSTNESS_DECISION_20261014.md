# 京都・全30ケージ設計の交互作用推定は、温室間で競争効果が違っても安定するか

**2026-10-14｜仮想的な潜在結果による方法検証。幼虫・蝶・葉量の新しい実測データはゼロ。**

研究の主問いは変えない：共通寄主 *Aristolochia debilis* の可食組織への継続アクセスを補うことで、移入ホソオチョウ *Sericinus montela* が在来ジャコウアゲハ *Atrophaneura alcinous* の次世代**飛翔成虫数**に及ぼす悪影響は軽減されるか。

背景：Hashimoto & Ohgushi (2023), DOI [10.1002/ece3.10164](https://doi.org/10.1002/ece3.10164)。先行試験は10温室×3ケージで幼虫密度と生存を調べたが、異種の追加×継続可食葉補充の無作為化、実際の葉齢別可食量の経時、休眠解除後の飛翔成虫を同時には測定していない。

## 1. 交互作用の帰無仮説を取り違えない

計測するケージ別の元焦点Aコホートの飛翔成虫割合を `Y` とし、

```text
D = (Y_supported+S - Y_supported+none)
  - (Y_natural+S  - Y_natural+none)
```

を主対比とする。

- **H0-interaction:** 食草補充自体の効果やS追加自体の効果は非ゼロでも、**それらの交互作用の集団平均がゼロ**。
- **H0-global-sharp:** *どのケージにどの処理を割り付けても結果が同じ*、すなわち主効果も交互作用も全くない。これは**より強い別の仮説**。

全処理のラベルを再シャッフルする単純なFisher sharp-null p値を、弱い交互作用ゼロの検定としてそのまま解釈することはできない。Wu & Ding (2021), [DOI 10.1080/01621459.2020.1750415](https://doi.org/10.1080/01621459.2020.1750415) などは、弱い帰無仮説とシャープ帰無仮説、学生化や別の補完推論法を区別している。Muralidharan et al. (2020), [DOI 10.3386/w26562](https://doi.org/10.3386/w26562) は主効果・交互作用がある因子実験で、解析モデルを結果に応じて選ぶことの問題も示した。

**実装方針:** 現在は正式な無作為化p値を出さない。まず、本来の割付過程（10温室・温室内3ケージ・省略パターン2候補）を正確に繰り返すことで、主効果があるのに交互作用なし、温室ごとに効果が異なる、などの事例でも推定値が何を意味するか診断する。

## 2. 完全に仮想的な潜在結果（5シナリオ）

同一30ケージについて4処理すべてに対する成功率 `Y_c(s,f)` を、意図的に**人工的な数式**で与えた。実験では一ケージには処理が一つしか割り当てられず、他3処理の潜在結果は観測できないが、人工例ならその真値を検算できる。

```text
Y_c(s,f) = baseline_c + alpha_greenhouse*s
          + beta_greenhouse*f + gamma_greenhouse*s*f
```

`s` は異種幼虫追加、`f` は食草アクセス補充。両者0/1。`baseline_c` に任意の温室差・ケージ内差を設け、可能な成功率が0〜1に収まるよう仮定した。**実際のジャコウアゲハの生存率に当てはめたものではない**。

各シナリオで**全30ケージの潜在結果**を固定し、各温室で3処理だけを割り付ける無作為化を256回繰り返す。毎回10温室への省略パターンと温室内3ケージへのラベルを無作為化し、温室固定効果付きの主対比を再計算する。

| 人工シナリオ | 仮想の真の平均D | 256回平均の温室調整推定値 | 真値からのRMSE | 温室を無視したRMSE |
|---|---:|---:|---:|---:|
| すべての処理効果なし | 0 | -0.0035 | **0.0270** | 0.0346 |
| S追加と補充に非ゼロの主効果、**交互作用なし** | 0 | -0.0035 | **0.0270** | 0.0346 |
| S追加と補充の主効果が温室ごとに違う、**交互作用なし** | 0 | +0.0003 | **0.0548** | 0.0651 |
| 交互作用の符号が温室ごとに違い、全温室平均では0 | 0 | +0.0018 | **0.0776** | 0.0872 |
| 一律+0.15の**架空の**補充による競争軽減 | +0.15 | +0.1465 | **0.0270** | 0.0346 |

**すべて人工データ**。256回のMonte Carlo平均は有限サンプル誤差を持つ。絶対差が小さいことは独立の蝶個体群でも推定が正しいという証拠ではなく、各温室に母系/寄主株を共有する場合の相関もこの人工設定から一般化できない。

上記の等分散・ケージ独立を仮定した**モデルの**95% t区間が、与えた真の架空Dを含む割合は順番に **93.75%、93.75%、96.88%、99.22%、93.75%**。特定の固定された5つの玩具モデルでの頻度に過ぎず、いかなる現実の実験でも誤判定率5%が保証されたわけではない。

### 特に重要な反証上の知見

1. **主効果は交互作用ではない**：`S追加=-0.11`、`補充=+0.12` で交互作用が本当に0の人工例では、温室調整交互作用の各無作為割付推定値は、双方の主効果を0にした例と一致した（線形の加法モデル）。「食草を増やすと全群の生存が上がるだけ」では、競争による損失が相対的に回復したことにならない。
2. **温室による効果異質性のコスト**：温室ごとに主効果を変えた人工例ではRMSEが0.027→0.055、温室ごとに交互作用が正負変わるとRMSEは約0.078に増加。従って温室差は切片だけでなく**処理反応の変化**として計測対象にすべき。
3. **温室を無視することは改善ではない**：5ケースすべての人工例で、温室調整のRMSEが無調整より小さい。ただしこのパターンがすべての実験に普遍的な証明ではない。
4. **成虫と生きた休眠蛹は別々**：人工潜在成虫成功率のストレステストは、実際に生きていて来季に羽化する蛹を扱わない。元コホートの実測追跡が不明な限り、蝶の次世代生産への効果は未測定。
5. **時間窓そのものの強い逆転は中心から外す**：同じ京都公開給餌データで揃えた日齢（8〜18日）の摂食曲線は88%程度重なることを前段の検証で確認済み。ここでの新規性の見込みは、**量・葉齢・競争相手が生存／羽化へ作用する経路の操作的切り分け**であり、摂食時間窓の差の自明な再発見ではない。

## 3. コード・再現性

- `scripts/calibrate_kyoto_30cage_randomization.py` は人工的な全潜在結果30×4を作り、配分seedが変わるたびに**2つの正しい温室省略パターンも含めて**すべて無作為化する。温室固定効果付き推定量／単純差／実験モデルの仮定的な95%区間を記述する。**p値は出さない**。
- `tests/test_kyoto_30cage_randomization_stress.py` は、主効果を足しても交互作用が発生しないこと、温室異質性を入れたときに真の全30ケージ平均交互作用が0であること、確率の0〜1制約、seedの再現性などを検証。
- [GitHub Actions原実行](https://github.com/zuizui0223/chocho/actions/runs/38525162751) は5仮想シナリオ×256配分を再計算し、31個のソフトウェアテストが成功。
- 数値を改変せず保存した記録：`provenance/reviewer_defenses/results/kyoto_30cage_synthetic_randomization_calibration_20261014.json`。ここに**仮説検証成功・生態効果は含まれない**。

```bash
python scripts/calibrate_kyoto_30cage_randomization.py \
    --draws 256 --seed 20261014 \
    --receipt results/kyoto_30cage_SYNTHETIC_randomization_calibration_v01.json
```

## 4. 生態学的なGO/NO-GOと次の進行

### GO：独立に測定できれば本実験を検討

最優先の独立パイロットは、下記の**実際の変動幅**を捉えるもの：
- 温室ごとのジャコウアゲハの元コホート生存・蛹休眠・飛翔成虫産生と、母系/寄主株による変動。温室は「切片」の違いだけでなく、実際の競争者追加への**反応差**を測る。温室毎にSあり/なしの対比を作るには、同一温室内で両処理が共存する期間とケージが必要。
- ウマノスズクサの若葉・成熟葉別の生産量・可食葉面積・鮮重・乾重・株年齢・供給元。特にホソオチョウの孵化直後幼虫に対する成熟葉の利用の難しさは**原著の予備試験で既に報告済み**であり、実際に入手できるドナー/母系で再現するかを確認する。
- 真の介入が可食量だけを変えているか、葉質・温室微気象・幼虫の接触頻度も一緒に変えているか。
- 生きている休眠蛹を死亡として誤分類しない、越冬後までの追跡計画。

### HOLD

現施設で10温室×3ケージの適格性が分からないまま30ケージ設計に実際の動物を割り付けない。2012年の論文のケージ配置は2026年の現有設備の証明ではない。人工的なSD・RMSEを実際のサンプルサイズ・検出力として使わない。

### STOPまたは別路線

もし独立パイロットで温室間の競争反応差が大きく、食草の継続供給や長期蛹追跡が実現できないなら、30ケージという数字を守るために不十分な本実験を強行しない。その場合は、**葉齢×蝶種の給餌可能性**とその発育成功の実測を独立研究として評価し、食草補充に起因する「競争回復」は未検証として保留する。

## 5. 投稿の線引き

この実装によって、設計がより明示的に反証可能になった。しかし公開済み資料のモデル計算やソフトウェア試験が増えても、**新しく支持された生態学的な現象は増えていない**。

- GEB `main` と既存投稿用PR #38を守る。
- 京都の移入**蝶**による在来寄主植物上の競争は、移入**寄主植物**の全球地理論文の因果証拠として再利用しない。
- 操作実験まで一貫して自分が作った「仮定」による逆転・救済を**実証結果や新規性**に昇格させない。

**Current conclusion:** 30ケージ設計の**交互作用に対する情報量**は改善したが、温室間の生物学的反応異質性が次の実測すべき主な不確実性である。
