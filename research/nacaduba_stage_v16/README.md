# v16 — Flowering-calendar coverage is not flowering-resource density

Post-hoc evaluation of Kato et al. (2012), `A. auriculiformis` field/common-garden Table 4/5/7, *Silvae Genetica* 61:228–236 ([DOI](https://doi.org/10.1515/sg-2012-0029)). No matched butterfly phenology or survival data; the GEB submission has not been changed.

The input is the **exact, SHA-checked source CSV** already pinned in `../nacaduba_stage_v15/data/`, not a new or independently collected butterfly sample. 23 clones, 39 ramets, 8 seed-source groups and 3 flowering seasons, binned in 10-day categories.

**New identification result:** All ramets together flower in 19/17/21 seasonal 10-day categories, 57 flowering bin-years total. Three clones (**146, 148, 152; 5 ramets**) reproduce this exact binary flowering union of the full 39 plants. Yet 3 clones have only **139 flowering ramet×10-day incidences**, versus **397** in all 39; the number of bin-years with **at least five ramets** flowering is **0 vs 40**. The three-clone full-calendar solution is unique among all 1,771 possible three-clone subsets. A group of only 7 clones (12 ramets) from **seed sources g+h** covers every bin-year as well, but with 249 flowering-ramet bin-years and 29 bin-years at five-ramet threshold.

Among **28 seed-source pairs**, only **g+h** together span all original 57 bin-years. The g group contributes **9, 6 and 8** bin-years uniquely in the respective seasons. Among **2,520 size-matched** selections of 4 clones/6 ramets, this g group has the greatest removal effect; its exact combination is the sole 23-bin-year maximum. Among **91,728 size-matched** selections of 7 clones/12 ramets, **2,184 (2.38%)** span the same 57 bin-years. These are exact **retrospective combinatorial counts**, *NOT random assignment or hypothesis-test p-values*.

**What this means:** A binary phenological resource envelope can be exactly the same while simultaneous flowering ramets differ strongly. The threshold five is a transparent arbitrary proxy sensitivity, *not* a measured larval food requirement, bud mass, larval survival, adult emergence or geographic colonization. The common-garden plant data were collected on Iriomote, not with *Nacaduba biocellata* larvae in Singapore. Source g early flowering and provenance differentiation were already reported by Kato et al.; we are not claiming discovery of that original main effect.

`python research/nacaduba_stage_v16/audit.py` computes the compact source-locked analysis using only Python standard library, then `cd research/nacaduba_stage_v16 && python -m unittest discover -s . -p 'test_*.py' -v` verifies six regressions. The standalone v16 ZIP includes full enumeration CSV files, an independent NumPy ramet×108-bin reconstruction, the entire data snapshots verified against v15 Git blob SHA, user-facing Japanese report, PNG/SVG and a local test log.

**Next empirical discriminant:** Measure density of usable buds/flowers on the same trees at two-to-three-day intervals, plus wild egg–larva–pupa–eclosed adult fate. A real test of a floral resource gate must match insects and host trees in time and space and control for weather, natural enemies and observation effort.
